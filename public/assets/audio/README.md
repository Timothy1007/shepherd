# Shepherd web audio placeholders

Drop licensed audio files in this folder using these exact names:

- `bgm-wilderness.mp3` — looping background music
- `play-card.mp3` — normal resource/card placement sound
- `miracle.mp3` — miracle play accent
- `disaster.mp3` — disaster play accent
- `round-end.mp3` — round transition / settlement accent
- `fire-gain.mp3` — fire gain accent

The web audio system is intentionally tolerant of missing files, so development can continue before final audio is chosen.

For release builds, only use audio you created or have commercial redistribution rights to use.
