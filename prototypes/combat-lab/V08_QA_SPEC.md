# v0.8 續航 QA 規格（獨立場景）
此文件只定義 reboot 測試，不改 main 或既有 v0.1。
- 耕耘：播種觸發就恢復理智1；5層恢復2、10層恢復3，即使目標護盾吸收傷害也觸發。
- 守望：每玩家行動可主動消耗最多8護盾，造成等量傷害；限守望使用，每回合一次，不消耗AP。
- 收割：直接攻擊造成的實際生命傷害15%吸血（向下取整，每回合最多5）；理智不高於30%時直接傷害+25%，以行動開始理智判定。
- 播種、牧養、投資、護盾、堅守持續跨秘笈；各秘笈被動及主動技不跨秘笈。
- 專屬三連：耕耘三糧+1播種，守望三羊+6護盾，收割三錢必爆且倍率2。
- 金牛之像：測試時每三回合力量+2，上限+8。
- QA：單獨頁面、不得污染一般對局；未通過真人測試。
