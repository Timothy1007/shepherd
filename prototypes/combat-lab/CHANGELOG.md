# Reboot 玩法實驗室｜版本與驗證紀錄

本檔記錄 **對話內互動原型** 與 GitHub HTML 原型的關係，避免把不同版本誤認為相同實作。

## 工作規則
1. 對話內原型用於快速測試；GitHub `reboot` 用於保存可追溯的程式與設計紀錄；不得覆蓋 `main`。
2. 每次修改先明確標記版本、測試假設、變動範圍、保留項目、測試結果與未完成項。
3. 使用者指定「只改 X」時，其他規則、數值、版面與互動維持不變；不得因重建畫面順手更動其他機制。
4. 對話內互動狀態未必能跨訊息或新對話保存；若需要重現某局，另記錄牌序、回合、手牌、敵方狀態與操作順序。
5. 未實際測試的功能不得標為通過。測試版本的簡化規則不得自動升格為正式設計。
6. 正式 Reboot 規則以 `docs/REBOOT_GAME_DESIGN.md` 為優先依據。
