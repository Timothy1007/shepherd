# 《牧羊人：荒野之歌》第一人稱即時戰鬥方向 v0.1（設計決策與探索框架）

> 2026-11-12。**新版方向優先；不是已完成的玩法實作規格。** 參考 [Issue #11](https://github.com/Timothy1007/shepherd/issues/11)。若與 `UNITY_BATTLE_V0.1_SPEC.md` 的「固定第三人稱卡牌戰鬥」衝突，以本文關於**未來方向**的決策為準；舊文件仍描述歷史已實作原型。

## 1. 已確認、不可誤讀的決策

1. 探索與戰鬥均為**第一人稱**，在同一個 3D 異域場景中進行即時施法與攻擊；不再以切換到固定第三人稱卡牌戰術鏡頭作為新版本目標。
2. 近距離沉浸感優先：畫面主要呈現手部／工具，低頭可見身體；室內鏡頭與碰撞要適合狹窄空間。
3. 低操作門檻：不以精準 FPS 槍法或高反應操作作為核心；輔助瞄準、寬容判定需實際測試。
4. 戰鬥要和調查、空間異變、環境物件形成同一套體驗；能力可干預敵人與環境，不只是抽象扣血。
5. 不預設元素相剋；敵人可有各自的弱點、恢復循環、特殊附著或解除條件。
6. **保留舊程式與規格作非約束性參考，不直接繼承任何機制。** 舊卡牌、抽牌、3 AP、回合制、三連、承接、三學派與「印」都必須經重新設計與玩家測試才可採用。不得以「舊版有」作為保留理由。
7. 未經確認不得刪除或改壞 `CombatLab3D`、Case01 既有戰鬥 QA、測試、數值或正式流程；新戰鬥先建立**獨立 QA**。

## 2. 創新原則：從玩家行為出發，而不是把卡牌映射成技能按鈕

先設計「觀察環境 → 選擇干預 → 即時施放 → 世界／敵人產生可觀察改變 → 形成下一次操作機會」的循環，再檢查舊概念是否能自然服務它。

例如（**僅供原型探索，不是已定案技能**）：使木箱浮起 → 面向敵人投擲（輔助追蹤與大判定）→ 命中產生局部缺失 → 以另一種干預阻止其恢復。此處核心樂趣是**改變世界的運作方式**，不是先排列三張牌。

## 3. 候選機制（需測試與使用者審核）

- 環境互動：拾起／懸浮／投擲家具或物件，合理碰撞與遮擋，支援輔助瞄準。
- 敵人反應：局部缺失、恢復循環、被打斷／限制、不同敵人的特別解除條件。
- 擬態錨定：可部署的範圍護盾裝置，裝置本身可能被敵人破壞。
- 施法組合：舊「印／共鳴／術式」可以作靈感，但不預設三張、固定學派或 AP。
- 第一人稱身體：手部施法演出、低頭可見身體、施法時視線與移動不被無謂剝奪。
- 美術技術：成熟暗黑歐美風格化半寫實、電影式局部光影；可評估 URP 與授權清楚的免費素材（CC0 等），轉換管線前須獨立驗證。

## 4. 尚未決定的正式規則

- 施法輸入、選術／切換方式、鎖定、連續施放、冷卻／消耗、取消／中斷與移動限制。
- 是否仍使用「印」等世界觀名詞，以及它們是否具備實際機械作用。
- 生命／防護／異常狀態、敵人 AI、玩家受擊、勝敗與探索銜接。
- 物件可互動範圍、投擲軌跡、場景破壞程度、性能預算與手把／手機控制。
- 第十七號門哪個空間適合首戰，以及是否需要重新安排家具與動線。

## 5. 建議開發順序（尚未授權直接取代舊場景）

1. **玩法紙上原型**：先列 3 種玩家可做的「干預行為」與 2 種敵人反應，說明輸入、回饋、連鎖玩法，排除只換皮的卡牌設計。
2. **獨立 Unity 灰盒 QA**：一個小型但可迴避與繞行的房間、單一敵人、可操作物件、準星與輔助瞄準；不接舊卡牌 Core。
3. **真人手感驗證**：測試鍵鼠與手把（之後再評估手機）、視角眩暈、瞄準容錯、敵人可讀性、玩法是否真有趣。
4. **第二輪系統選擇**：只把被證明有用的舊概念重新引入；明確決定保留、轉化或淘汰。
5. **再整合 Case01**：在既有住宅探索／劇情系統中接入，不提前破壞舊 QA。

- **尚未完成**：正式即時戰鬥規則、獨立第一人稱即時戰鬥 QA、真人試玩、與 Case01 整合。
