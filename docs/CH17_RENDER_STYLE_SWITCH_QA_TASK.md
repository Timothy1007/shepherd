# 第十七號門｜三種實機渲染即時切換 QA（待 Claude 實作）

> 2026-11-15 使用者需求。**這是下一階段的實作任務規格，尚未實作。** 先等正在進行的餐廳美術修改完成並同步，避免兩個 session 同時改相同場景/材質/Shader。

## 目的
使用者不要靜態比較圖作為主要交付；**要一個能親自走動、按鍵即時切換 A/B/C 三種 Unity 真正渲染風格的獨立測試環境**，藉由遊玩判斷是否達到正式 3D 遊戲質感。不是 AI 重繪，不是切換三張圖片。

## 測試環境
- 以**最新完成的餐廳美術版本**為唯一基底，做獨立 QA 入口/場景；不可污染正式探索場景、全域畫質預設、其他房間。
- 保留第一人稱移動、滑鼠鏡頭與可觀察家具的近距離走動；不要覆蓋另一個正在處理滑鼠控制的 session。
- 使用**同一份場景、同一批模型、相同位置與攝影機**；切換渲染模式時玩家位置、朝向、互動狀態不重置，不重新載入場景，不換家具或改格局。
- **鍵盤 `F6` 循環切換 A → B → C → A**（若與現有快捷鍵衝突，改用未佔用鍵並清楚說明）；另加小型畫面角落按鈕/標籤 `A / B / C`，可用滑鼠直接選。按鍵與按鈕應切換同一個狀態。
- UI 明確顯示目前模式的名稱；可選擇隱藏標籤以便沉浸體驗；不使用大型遮罩覆蓋場景。
- 切換應立即可見，盡可能同一幀/短時間完成；若需要非同步反射更新或預熱，顯示明確狀態，不能把未完成效果稱為已切換。
- 提供可操作的啟動方式、Unity 場景/選單路徑與測試步驟。若有 Build 可用，說明實際可用版本；不可編造網址。

## 三種模式（皆保留真實 3D 深度）
- **A｜Cinematic Semi-Realistic**：自然 PBR、可信材質、反射、接觸陰影與空間光照；作為立體感基準，不套繪畫濾鏡。
- **B｜Painterly Semi-Realistic**：在 A 的體積/光影基礎上加入克制的繪畫質感材質、細微色彩變化；**優先候選**，不把物體壓平成 2D、不用強烈卡通描邊或全畫面油畫濾鏡。
- **C｜Stylized Cinematic**：更鮮明的冷暖、明暗分區與視覺焦點，仍保留可信形體、材質厚度與三維空間，不做強烈賽璐璐化。
- 三種應有**可感知且實際實作**的差異，不可只是改一個全畫面色調/飽和度數值就聲稱三種不同渲染。可以共享材質/Shader 核心，但須清楚列出各模式改了什麼（例如材質、光源、Volume、shader 參數）。
- 不要求三種各自換整套模型；相同內容比較才有意義。

## 提燈與雙狀態
- 依 `docs/CH17_LANTERN_DUAL_STATE_EXPLORATION.md`，褪色態為預設，提燈局部記憶顯現；QA 必須保留現有可用的提燈操作，確認 A/B/C 不破壞光內/光外的同時顯示。
- 不能為了美術比較擅自把雙態改成全屋切換，不能改動碰撞、謎題或門洞。

## 技術及風險
- 使用現有 Unity 2022.3 / URP 14、`LanternReveal.shader` 雙態功能；不切 HDRP、不直接開舊的全螢幕繪畫濾鏡。
- 不要改全域相機、輸入、房屋尺寸、家具擺設或正式場景預設值。用獨立 QA 設定、局部 Volume/材質實例與可還原的切換管理器，避免共享材質被永久污染或跨場景洩漏。
- 先檢查最新 `main`、現有 QA 入口、快捷鍵與美術修改進度；若目前美術 session 未完成，等待其成果再開工，不要與它並行修改同一檔案。
- 有效能差異時在同一硬體、同一位置比較；如某效果成本過高，清楚註明，不假稱商用品質已達成。

## 完成標準與交付
1. 使用者可直接進入獨立 QA 餐廳並自由走動。
2. 按 `F6` 或點 A/B/C 可即時切換，畫面有清楚目前模式名稱；切換不重置視角與位置。
3. A/B/C 不是靜態截圖，實際運行時材質/光影呈現有可見差異。
4. 三種模式皆確認提燈與褪色態的相容性，並做通行/互動回歸。
5. 提供 QA 場景/入口、按鍵、實際測試結果、變更檔案及 commit SHA；未執行的實機測試不得宣稱通過。
6. **使用者親自試玩後才決定正式渲染方向**；本 QA 不自動替換正式場景。
