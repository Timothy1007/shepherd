> 本文件為神蹟與災難的正式規則來源。後續數位版開發挑卡、實作與測試，應先以此文件核對卡名、標籤與效果；若聊天中的舊版本與本文件不同，以本文件為準，除非之後明確更新本文件。
>
> **2026-09 V2 狀態：24 張神蹟與 18 張災難皆已完成第一輪 V2 整合；程式尚未全面同步 V2。**

## 神蹟（PvP V2）

### 標籤補充

- 【使命】：直接影響使命進度、使命條件或使命完成判定。
- 使命類神蹟僅作為補助，不應取代物資作為完成使命的主要來源。

### 神蹟 V2 平衡註記

以下數值暫時保留，需在人物與祝福 V2 一併完成後做整體 Playtest，而非視為最終競技數值：

- 《於水中重生》：大量手牌時的整手重抽強度與死亡觸發風險。
- 《分杯之火》：6點火種成本是否足以換取政治轉移與抽牌價值。
- 《空墳墓》：每3點火種換1抽、最多2張，需配合新版火種傷害尺度。
- 《焚而不毀的荊棘》：返還上限4點需配合新版火種傷害尺度。
- 《第二次生命》：刻意排除輪末使徒 Jackpot 作為觸發來源，避免輪末突然抽牌干擾跨輪手牌張數結算。

## 災難（PvP V2）

### 設計原則

- 災難優先干擾玩家「完成使命的路徑」，而不是直接大量扣除既有使命進度。
- 數字增減若未特別說明，只影響出牌判定，不改變物資對使命提供的原始數字。
- 火種型災難應打亂經濟與迫使玩家做取捨，不以把低火種玩家永久踢出經濟系統為目標。
- 一般災難與一般牌庫操作不能移動、越過或處理死亡牌，除非牌面明確寫出例外。

| 名稱 | 標籤 | 效果 |
|---|---|---|
| 方舟之外 | 群體｜掠奪 | 每名玩家選擇自己手中的1種物資種類並保留該種類的物資牌，然後從其他種類的物資牌中棄置2張；若不足2張，則全部棄置 |
| 謊言與試探 | 多體｜掠奪 | 你選擇2名其他玩家。這2名玩家各自選擇1張手牌並展示，你選擇其中1張取得；另一張由原持有者收回手牌 |
| 告別舊時代 | 群體｜重構 | 所有有手牌且未免疫此災難的玩家，各隨機選擇1張手牌，並依出牌方向同時給予下一名符合條件的玩家。若符合條件的玩家不足2名，此效果不生效 |
| 半朽蜜果 | 單體｜掠奪 | 你選擇1名其他玩家。該玩家棄置手牌，直到棄置2張或只剩1張手牌；每少棄置1張，該玩家失去3點火種 |
| 瞳中倒影 | 多體｜掠奪 | 手牌數量最高與次高的玩家，各棄置1張手牌；若有並列，並列玩家皆棄置 |
| 蟲災 | 單體｜重構 | 你選擇1名其他玩家，將此牌置於該玩家的效果區。本輪內，該玩家打出的糧食牌在出牌判定時數字-2，最低為0。本輪結束時，棄置此牌 |
| 灰與燼 | 群體｜熄滅 | 每名玩家失去4點火種。直到本輪結束，所有玩家因神蹟效果獲得的火種減少2點，最低為0 |
| 積財寶在地上 | 單體｜熄滅 | 你選擇1名其他玩家。該玩家每持有5點火種，則失去2點火種，最多失去12點。若該玩家持有的火種不足5點，則不受此效果影響 |
| 瘟疫 | 單體｜蔓延 | 【負面】放置於任意玩家的效果區。本輪內，你成功打出的群羊牌在出牌判定時數字-2，最低為0。成功打出群羊牌後，依出牌方向將此牌移至下一名玩家的效果區。本輪結束時，棄置此牌 |
| 染血銀幣 | 單體｜重構 | 【負面】你選擇1名其他玩家，將此牌置於其效果區。本輪內，你每次獲得火種後，將其中1點火種給予1名其他玩家。本輪結束時，棄置此牌 |
| 盜火 | 單體｜熄滅 | 你選擇1名其他玩家。該玩家選擇：失去7點火種，你獲得等同其實際失去數量的火種；或給予你1張手牌 |
| 哈米吉多頓 | 群體｜崩解 | 每名有物資牌的玩家棄置自己手中數字最高的1張物資牌。然後從已出牌區隨機棄置5張牌；若不足5張，則全部棄置。死亡牌不受此效果影響 |
| 破碎玻璃海 | 群體｜重構 | 將此牌置於你的效果區。直到本輪結束，所有單體與多體神蹟、災難在選擇玩家為目標時，改為從合法目標中隨機選擇。群體與擴散效果不受影響 |
| 愛慾之種 | 單體｜蔓延 | 你選擇1名其他玩家，將此牌置於其效果區。本輪內，當2張以上正常牌因同一效果同時加入你的手牌時，你選擇其中1張給予另一名玩家，然後將此牌移至該玩家的效果區。本輪結束時，棄置此牌 |
| 焚城之火 | 多體｜崩解 | 你選擇2名其他玩家；若其他玩家不足2名，則選擇所有其他玩家。這些玩家各棄置其效果區中的1張【增益】或神蹟牌；若沒有可棄置的牌，則失去6點火種 |
| 虛謊之舌 | 應對｜重構 | 【應對】當一名玩家即將因神蹟效果抽牌、獲得火種或增加使命進度時打出：若其即將抽牌，則少抽1張；若其即將獲得火種，則少獲得5點；若其即將增加使命進度，則該次進度增加量-2，最低為0。若同時符合多項，由該玩家選擇其中1項受到影響 |
| 三分之一的星辰 | 群體｜崩解 | 依序將牌庫頂最多15張正常牌移出本輪。若死亡牌因此成為牌庫頂，立即停止此效果，不移動死亡牌。本輪結束時，將因此移出的牌洗回牌庫 |
| 倒塌的帳幕 | 群體｜崩解 | 所有玩家棄置自己效果區中的所有神蹟牌。若因此棄置至少1張神蹟牌，則獲得5點火種 |

### 災難 V2 平衡註記

以下數值為第一輪 V2 整合結果，仍需與人物、祝福與完整火種經濟一併 Playtest：

- 《半朽蜜果》：每少棄置1張改為失去3點火種，需確認前期壓力是否過高。
- 《灰與燼》：群體失去4點火種，需確認2～4人局總經濟壓縮是否合理。
- 《積財寶在地上》：上限提高至12點，需觀察是否對高火種玩家過度針對。
- 《盜火》：火種選項提高至7點，需確認「給牌」與「失火」兩項是否仍都有選擇性。
- 《焚城之火》：無可棄置效果時失去6點火種，並補上2人局合法目標處理。
- 《虛謊之舌》：新增使命進度反制，需要與使命神蹟一併測試。
- 《三分之一的星辰》：不得越過死亡牌，可能形成主動把死亡推到牌庫頂的高風險效果。

## 開發原則

- GitHub repository 是目前程式進度與規則的唯一準則。
- V2 規則設計以 `docs/PVP_CORE_RULES_V2.md` 為核心母規則；本文件提供特殊牌正式文本。
- 已實作卡牌目前仍可能是 V1 行為；在 V2 程式改造前，不得因文件已更新就宣稱程式已同步。
- 新卡優先依「機制母版」順序開發，不按卡號逐張硬做。
- 完成人物與祝福 V2 平衡後，再整體改寫核心程式、卡牌定義、AI、UI 與 tests。
- 測試用強制發牌／初始火種等 QA scaffolding 必須與正式規則隔離。
