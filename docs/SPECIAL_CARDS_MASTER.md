# 《牧羊人：荒野之歌》神蹟／災難正式卡表

> 本文件為尚未／已實作神蹟與災難的正式規則來源。後續數位版開發挑卡、實作與測試，應先以此文件核對卡名、標籤與效果；若聊天中的舊版本與本文件不同，以本文件為準，除非之後明確更新本文件。

## 神蹟

| 名稱 | 標籤 | 效果 |
|---|---|---|
| 回轉歸向 | 新生 | 改變出牌方向，然後你抽1張牌 |
| 行曠野之路 | 新生 | 將此牌置於你的效果區。你下一張成功打出的物資牌數字+3，且可超過原本的數字上限。成功打出物資牌後，你棄置此牌 |
| 荊棘冠冕 | 新生 | 將此牌置於你的效果區。你下一張成功打出的物資牌無視出牌限制。成功打出物資牌後，你棄置此牌 |
| 於水中重生 | 流轉｜新生 | 你棄置全部手牌，然後抽取等量的牌 |
| 如風吹來 | 流轉｜火種 | 你選擇：棄置1至3張手牌，然後抽取等量的牌 或 不棄置手牌，獲得3點火種 |
| 所望之實底 | 洞察 | 你查看牌庫頂3張牌，選擇其中1張加入手牌，其餘牌以任意順序置於牌庫底 |
| 行向水深之處 | 洞察｜新生 | 你依序展示牌庫頂的牌，直到展示出3種不同牌型或共展示5張為止。選擇其中1張加入手牌，其餘牌以任意順序置於牌庫底 |
| 拆毀後重建 | 洞察｜新生 | 你棄置1張手牌。若如此做，你查看棄牌區最上方5張牌，選擇其中1張加入手牌。若你選擇的是神蹟或災難，你再棄置1張手牌 |
| 勝利歸於我們 | 共鳴｜火種 | 你選擇1名其他玩家，並將此牌置於你的效果區。本輪結算時，若你或該玩家成為使徒，你與該玩家各獲得4點火種，然後你棄置此牌 |
| 恰如飛鳥經過 | 共鳴｜流轉 | 你選擇1名其他玩家。若你與該玩家皆有手牌，你們各選擇1張手牌並同時展示。若雙方皆同意，則交換這2張牌；若任一方不同意，則收回展示的牌。若交換的牌型不同，你與該玩家各獲得3點火種 |
| 窄門與窄路 | 共鳴｜火種 | 你將3張手牌給予任意其他玩家。若如此做，你抽2張牌並獲得5點火種 |
| 分杯之火 | 共鳴｜火種 | 你支付6點火種。若如此做，選擇1名其他玩家，使其獲得3點火種，然後你抽1張牌 |
| 在黎明前叩門 | 洞察｜新生 | 將此牌置於你的效果區。你下一次因效果抽牌時，抽牌數量+1。抽牌後，你棄置1張手牌，然後棄置此牌 |
| 杯滿盈溢 | 共鳴｜火種 | 你選擇1名其他玩家。然後你選擇：抽1張牌 或 獲得5點火種。該玩家獲得你未選擇的另一項效果 |
| 三股合成的繩子 | 共鳴｜新生 | 你選擇2名其他玩家。你們三人各選擇1張手牌並同時展示。若三張牌的牌型皆相同，你們三人各獲得4點火種；若三張牌的牌型皆不同，你抽1張牌，另外兩名玩家各獲得2點火種 |
| 越過長夜 | 應對｜庇護 | 【應對】當你即將受到災難效果時，你可以打出此牌：你免疫該次效果 |
| 替罪羊 | 應對｜共鳴 | 【應對】當另一名玩家成為災難目標時，你可以打出此牌：將該災難對他的效果轉移給你，且你不能免疫。若你因此失去火種或棄置手牌，將此牌置於你的效果區。你下一次受到災難時，少失去4點火種或少棄置1張手牌，成功後你棄置此牌 |
| 空墳墓 | 應對｜新生 | 【應對】當你即將因災難效果失去火種時，你可以打出此牌：正常失去火種後，你每實際失去3點火種，你抽1張牌，最多抽2張。 |
| 拆毀堅固營壘 | 應對｜新生 | 【應對】當你即將受到具有2項及以上效果的災難時，你可以打出此牌：選擇其中1項效果，使其對你無效；其餘效果正常結算。結算後，你棄置1張手牌，然後抽1張牌 |
| 勝過死亡 | 應對｜新生 | 【應對】當你的手牌數量或火種即將因效果從1以上降至0時，你可以打出此牌：你可選擇使其保留1 |
| 焚而不毀的荊棘 | 火種｜新生 | 將此牌置於你的效果區。本輪你下一次因災難效果失去火種後，獲得等同此次實際失去火種一半的火種，向下取整，最多獲得4點，然後棄置此牌 |
| 雨幕之下 | 庇護｜新生 | 你選擇1名玩家，棄置其效果區中的1張持續災難牌，或清除其1個【負面】。若成功，該玩家獲得2點火種 |
| 第二次生命 | 共鳴｜流轉 | 將此牌置於你的效果區。你下一次獲得火種時，先棄置此牌，然後抽1張牌；若抽到物資牌，再獲得2點火種 |
| 劫後餘生 | 火種｜流轉 | 從你開始，依出牌方向，每名玩家可選擇：支付4點火種，然後抽1張牌 或 棄置1張手牌，然後獲得3點火種。若成功選擇並完成其中一項，首名如此做的玩家額外獲得2點火種。無法支付代價的玩家不執行任何效果 |

## 災難

| 名稱 | 標籤 | 效果 |
|---|---|---|
| 方舟之外 | 群體｜掠奪 | 每名玩家選擇自己手中的1種物資種類並保留該種類的物資牌，然後從其他種類的物資牌中棄置2張；若不足2張，則全部棄置 |
| 謊言與試探 | 多體｜掠奪 | 你選擇2名其他玩家。這2名玩家各自選擇1張手牌並展示，你選擇其中1張取得；另一張由原持有者收回手牌 |
| 告別舊時代 | 群體｜重構 | 所有有手牌且未免疫此災難的玩家，各隨機選擇1張手牌，依出牌方向同時給予下一名符合條件的玩家。若符合條件的玩家不足2名，此效果不生效 |
| 半朽蜜果 | 單體｜掠奪 | 你選擇1名其他玩家。該玩家棄置手牌，直到棄置2張或只剩1張手牌；每少棄置1張，該玩家失去2點火種 |
| 瞳中倒影 | 多體｜掠奪 | 手牌數量最高與次高的玩家，各棄置1張手牌；若有並列，並列玩家皆棄置 |
| 蟲災 | 單體｜重構 | 你選擇1名其他玩家，將此牌置於該玩家的效果區。本輪內，該玩家打出的糧食牌數字-2，最低為0。本輪結束時，棄置此牌 |
| 灰與燼 | 群體｜熄滅 | 每名玩家失去3點火種。直到本輪結束，所有玩家因神蹟效果獲得的火種減少2點，最低為0。 |
| 積財寶在地上 | 單體｜熄滅 | 你選擇1名其他玩家。該玩家每持有5點火種，則失去2點火種，最多失去10點。若該玩家持有的火種不足5點，則不受此效果影響 |
| 瘟疫 | 單體｜蔓延 | 【負面】放置於任意玩家的效果區。本輪內，你成功打出的群羊牌數字-2，最低為0。成功打出群羊牌後，依出牌方向將此牌移至下一名玩家的效果區。本輪結束時，棄置此牌 |
| 染血銀幣 | 單體｜重構 | 【負面】你選擇1名其他玩家，將此牌置於其效果區。本輪內，你每次獲得火種後，將其中1點火種給予一名其他玩家。本輪結束時，棄置此牌 |
| 盜火 | 單體｜熄滅 | 你選擇1名其他玩家。該玩家選擇：失去5點火種，你獲得等同其實際失去數量的火種 或 給予你1張手牌 |
| 哈米吉多頓 | 群體｜崩解 | 每名有物資牌的玩家棄置自己手中數字最高的1張物資牌。然後從已出牌區隨機棄置5張牌；若不足5張，則全部棄置 |
| 破碎玻璃海 | 群體｜重構 | 將此牌置於你的效果區。直到本輪結束，所有單體與多體神蹟、災難在選擇玩家為目標時，改為從合法目標中隨機選擇。群體與擴散效果不受影響 |
| 愛慾之種 | 單體｜蔓延 | 你選擇1名其他玩家，將此牌置於其效果區。本輪內，當2張以上牌同時加入你的手牌時，你選擇其中1張給予另一名玩家，然後將此牌移至該玩家的效果區。本輪結束時，棄置此牌 |
| 焚城之火 | 多體｜崩解 | 你選擇2名其他玩家。這2名玩家各棄置其效果區中的1張【增益】或神蹟牌；若該玩家的效果區中沒有可棄置的牌，則該玩家失去5點火種。 |
| 虛謊之舌 | 應對｜重構 | 【應對】當一名玩家即將因神蹟效果抽牌或獲得火種時打出：若其即將抽牌，則少抽1張；若其即將獲得火種，則少獲得5點。若兩者皆有，由該玩家選擇其中一項執行 |
| 三分之一的星辰 | 群體｜崩解 | 將牌庫頂15張牌移出本輪。本輪結束時，將這些牌洗回牌庫 |
| 倒塌的帳幕 | 群體｜崩解 | 所有玩家棄置自己效果區中的所有神蹟牌。若因此棄置至少一張神蹟牌，則獲得5點火種。 |

## 開發原則

- GitHub repository 是目前程式進度與規則的唯一準則。
- 已實作卡牌仍以程式定義與 tests 驗證實際行為；若發現程式與本正式卡表不一致，應先指出差異再修正。
- 新卡優先依「機制母版」順序開發，不按卡號逐張硬做。
- 每次只實作／驗收一張新的代表卡，確認 Game State、UI、AI 與 tests 後再複用。
- 測試用強制發牌／初始火種等 QA scaffolding 必須與正式規則隔離，該卡驗收後移除或切換至下一張測試卡。
- 已驗收但 UI 粗糙的選擇玩家／手牌互動介面，統一留待神蹟／災難功能完成後進行 UI/UX polish。
