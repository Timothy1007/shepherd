# 第十七號門｜提燈、褪色態與記憶顯現：探索設計規範

> 狀態：設計共識紀錄（2026-11-15）。本文件描述預期玩法，不代表 Unity 場景或程式已實裝。不得將舊卡牌版的規則混作本章探索規則。

## 一、世界狀態

1. **褪色態**是玩家踏入異域後預設看見的世界，代表失序後的「現在」。不是單純把正常房間去飽和或套灰色濾鏡；它應有獨立的物件、線索、互動與謎題。
2. **提燈照出的記憶態**是可能曾經存在的「過去」或記憶版本，不保證是客觀、完整的真相。它不是全屋切換後的固定正常場景。
3. **只有提燈開啟且光線實際照射到的局部範圍**，記憶態才會顯現；光照範圍外始終維持褪色態。提燈關閉或光線移開後，該處記憶顯現即消失。
4. 兩種狀態可在玩家視野中同時存在（光內記憶態、光外褪色態），不是整個房間或整張地圖一鍵切換。
5. 兩態的物件不必同位置、同數量或同用途；允許只存在於一態的物件、移位的家具、不同的門洞或通路。不能只改顏色、材質、破損程度。

## 二、雙態探索與互動

- **褪色態必須能獨立探索、互動及解謎**，不可把所有線索和有效互動都集中在提燈照亮後，否則玩家只會常駐開燈。
- 記憶態同樣提供獨立資訊、物件和探索價值；兩態應互補，不能把提燈設計成「永遠更完整、更正確」的升級視野。
- 例：褪色態存在的紙條，照燈後可能消失，換成過去的便條；也可能有僅褪色態可見的通道或機關。
- 玩家需要觀察、比較、移開或重新照射提燈；**不以燃料或電量限制作為主要強迫關燈手段**。
- 褪色態必須有足夠的環境可讀性與美術表現，不可因過暗、資訊不清而迫使玩家一直開燈看路。

## 三、門與空間

- **可見的門不一定是真門；看似完整的牆也不代表沒有門。**
- 門可以隨靠近、觀察角度、提燈光照或其他明確設計的觸發條件顯現；不是所有隱藏門都必須靠提燈。
- 一般隱藏門的「發現」本身就是探索成果：**原則上發現後即可使用**，不要每扇門再附加一道解謎或任務門檻。
- 需要額外條件的門只少量使用，主要保留給關鍵任務或重要敘事節點。
- 可有普通門、褪色態獨有門、記憶態顯現門、虛假門、錯位門及少量關鍵條件門，但每種行為須有玩家可理解的回饋。
- 空間可以有「感受可信、幾何不合理」的設計：生活細節真實可信，室內深度、連通關係、遮擋與門的位置可呈現失序；不必完全遵循現實英國住宅平面尺度。
- 但不可犧牲操作清晰度：可通行與不可通行的狀態要可辨認；避免門或牆在光移開時把玩家卡住。**記憶態門的通行、碰撞與光離開後的安全處理仍待實作方案確定**，不得擅自當成已定案。

## 四、關卡與 QA 原則

- 房間不能只靠新增家具填滿；設計「第一眼看到什麼、移動後發現什麼、兩態各自揭露什麼」，讓玩家不能一次看完所有探索資訊。
- 不是每個房間都要迷宮化；可以讓玩家看見房間全貌，但不能第一眼看完所有故事、互動與隱藏空間。
- 建立**獨立的提燈／雙態／門顯現 QA 場景**，不要直接污染一般對局或其他已確認 UI。
- QA 至少檢查：光內與光外同時顯示；光移開後消失；兩態獨有物件與互動；褪色態可解謎；隱藏門的發現與直接通行；門與牆切換時玩家碰撞安全；從入口到各角落的探索視線。
- 目前若場景只是同一批家具在兩態更換色彩或材質，應標示為**尚未完成的視覺原型**，不可視為上述玩法已落地。
