# Case01〈第十七號門〉一樓獨立 3D 資產清單與 GPT 出圖規格 v0.1
> 2026-11-16｜供使用者另一個 GPT 對話產生概念圖、Claude／Blender 建模、Unity 整合。**資產規劃，不代表已建模或已實作。**正式依據：`docs/design/SHEPHERD_GAME_DESIGN_MASTER.md` §10–12、`docs/level/CASE01_SHOP_LAYOUT_QA.md`、`docs/level/CASE01_GROUND_FLOOR_ESCAPE_ROOM_V0_1.md`。後者含舊提案，衝突以最新總綱為準。

## 使用方式／交接
- 此清單是**待製作資產規格**，不是要求 Claude 現在批次建模。使用者目前正交給 Claude 開發電箱、縫紉機；**不要同時修改相關程式**。每張圖先經使用者確認，再進行多視圖與建模。
- 「已在灰盒／舊美術中存在」不等於正式資產已完成；是否需要替換須盤點 Unity 現況。新資產不改現有房間拓樸、店面 A 布局、謎題條件或記憶年齡節點。
- 先以灰盒驗證玩法；正式模型的尺度、Pivot、可動部件、碰撞與互動錨點需可替換，不把玩法寫死在某個 Mesh。每項獨立 QA 驗收。
- **三視圖的 AI 幾何可能不一致**，不能當精確工程圖；尺寸由 Unity 灰盒／現有場景實測回填，不可由生圖自行臆定。重要道具的字跡／照片人物／故事線索要用後續可編輯材質，不把隨機 AI 文字烙進模型。
- 褪色態／記憶態優先用同一幾何資產搭配材質、Shader、燈光與必要的狀態部件，避免為每個物件無端重做兩套模型。

## 共同美術母規格
Stylized Semi-Realistic 3D Game Asset；介於成熟動畫電影與半寫實 3D 遊戲之間。大形體、輪廓清楚、自然曲面、細節概括，木／布／金屬材質可辨識；有適量生活使用痕跡，不是照片寫實、玩具塑膠、低多邊形碎切面或平面插畫。現代英倫舊式連棟住宅與家庭改衣店的生活脈絡；低飽和基調但保留亮暗對比與焦點。**以使用者當次附上的已確認風格參考圖優先**，不擅自改風格。單一物件完整入鏡、純色中性背景、無人、無場景擺設、無裝飾文字或尺寸數字（尺寸另在規格記錄）。45° 用清楚的 3/4 視角；正／側／背／俯視用正交投影，維持同一件物件及零件數量。禁止把 2D 生圖當作可直接匯入 Unity 的 3D 模型。

## GPT 每次出圖固定模板
參考附圖風格，幫我設計《牧羊人：荒野之歌》的【物件名稱／資產 ID】。
用途：【場景／房間／功能；玩家如何互動】
輸出：【45° 定稿圖／正側背俯視多視圖／可動拆解圖；一次只做指定階段】
規格：【材質、配色、尺寸感（如有實測數值則照用）、主要輪廓、固定與可動零件、Pivot／碰撞／操作空間、是否適合 Blender 建模】
特徵：【此物件的故事特徵、可觀察面、需要開合／拆卸／旋轉的部位】
限制：【不可新增或改動的元素；不得虛構文字、人物與線索】
背景：純色背景，單一物件完整入鏡。以附圖風格與已確認定稿為準。
流程：先產生 45° 定稿圖 → 使用者確認 → 再以**同一張定稿**生成正交視圖 → 需要時補可動拆解／開關狀態。未確認前不自動連做多張。

## 每件資產交付給 Claude 的欄位
`AssetID / 房間 / 功能 / 是否已在 Unity 有原型 / 尺寸(寬深高, m, 實測或待測) / 45°定稿圖片路徑 / 多視圖圖片路徑 / 可動拆解圖路徑 / 材質色票 / 子物件與 pivot / Collider 需求 / Interaction anchors / 狀態(待盤點→出圖中→外觀已確認→建模中→Unity QA→已驗收) / 備註`。

## 製作先後與驗收
1. **目前進行中（Claude）**：SH-001～004 的縫紉機／椅子／電箱／木箱；這份清單只供美術規格，不要求重開同一功能。
2. **下一批**：SH-005/006、YA-001、HA-002/003；樓梯與地下室先量現有幾何／灰盒確認，不直接按概念圖改建築。
3. **調查物件**：照片、訂單簿、日曆、答錄機、冰箱、保鮮盒、鐵盒、信封、便條；優先做「拾取→第一人稱旋轉／翻面→放回」通用互動系統。
4. **環境裝飾**：模組化家具可共用材質／結構，無須每件都做完整拆解圖。
5. 每件先由使用者確認 45° 定稿；正交多視圖需與定稿同一設計；Claude 先檢查尺寸與分件再建模；Unity QA 必須實測第一人稱近距離觀看、幼年／青春期／成人可及性、碰撞、動畫、褪色／記憶雙態及不影響其他房間。
