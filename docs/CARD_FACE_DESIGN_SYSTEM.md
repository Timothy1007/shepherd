# 卡面設計系統

本文件記錄《牧羊人：荒野之歌》神蹟與災難卡面已確認的視覺規則；卡牌效果與標籤的正式文字仍以 `docs/SPECIAL_CARDS_MASTER.md` 為準。

## 已確認的排版原則

- 所有卡牌尺寸固定為 **63 × 88 mm**；神蹟與災難以不同卡背／框色辨識，不靠更換卡片尺寸。
- 卡名使用最強字級，置於上方、視覺置中；位置依實際底圖的重心微調，**不可只依座標幾何置中**。
- 若有時機標籤（例如「應對」），置於卡名下方、視覺置中；不使用膠囊框或底線。
- 效果正文的起排基準，是左上深色弧框（或相應底圖裝飾）的**下緣**；中、長文不可整段垂直置中而留出上方大空白。
- 左上與右下深色弧形是卡面的**邊框**，不是文字底色；正文必須保留內縮安全區，不可壓到弧框。長文優先內縮欄寬、上移起排點、縮短同義字句與調整字級，而不是讓文字碰框。
- 所有中長文卡的正文起排，統一對齊左上弧框下緣所標定的「紅線高度」；不可只針對單張卡例外處理。
- 效果很短的卡（例如〈迴轉歸向〉）可在正文可用區內雙軸視覺置中，但要依非對稱卡面上移或下移，不硬套幾何中心。
- 依文字量建立短／中／長三種版面；字級、行距、正文起點與換行均可不同。目標是卡面視覺平衡，不是每張都用同一組座標。
- 優先讓每行文字有合理長度；避免大段行末留白、標點符號單獨成行，以及句子末尾的「。」被擠到下一行。必要時可將短尾語與標點設為不可拆分。
- 換行以語意為準：先在條件、結果與例外的句界判斷是否分段；不可因硬性字數上限，造成最後只剩短片段、連接詞或標點獨占一行。長文先維持已驗收的欄寬，再依實際文字量個別安排分段。
- 效果正文的每一行維持相同行距；句子分段、手動換行與不同段落都不得額外拉開垂直距離。
- 效果文字統一保留句號：每個完整效果句以「。」結尾，卡面只處理避免句號孤立換行，不任意刪除標點。
- 數字、專有名詞與帶圖示的術語加粗；一般敘述不加粗。例：**效果區**、**免疫**，以及明確列出選項的 **選擇：** 是專有名詞，應加粗；「選擇 1 名玩家」、「選擇其中 1 張」與「若你選擇的是」不加粗。
- 表述採「越乾淨越好，但不能影響語意或閱讀」：例如 **3火種**，不寫「3點火種」。

## 圖示規則

- 火種、災難、無效等已定義的核心術語，以「小圖示＋文字」表示；文字與圖示一併加粗。
- 牌圖示只在抽牌、棄牌、取得／加入手牌等**實際改變牌量或牌位**的敘述使用；不在「此牌、手牌、其他牌」每次出現時重複放圖示。
- 數字與牌圖示的順序為「數字在前、牌圖示在後」。
- 卡面沒有插圖時，保留乾淨留白；效果資訊本身、標籤圖案與框面裝飾就是主要視覺層級。

## 標籤定義（2026-10 校準版）

標籤描述的是一張牌**主要改變什麼**，不是只看它是否包含抽牌或火種數值。

| 層級 | 標籤 | 定義 |
|---|---|---|
| 神蹟主題 | 新生 | 使玩家脫離既有的限制、損失或停滯，重新取得選擇、保護或突破機會；包含重抽、突破出牌限制、災難後回復、保留臨界資源與清除負面。 |
| 神蹟主題 | 流轉 | 使卡牌、火種或權益在玩家、區域或型態之間移動、交換、重分配或轉換；包含棄抽、交換、給予與以火種換牌。 |
| 神蹟主題 | 洞察 | 查看、展示、篩選、搜尋、回收或重排牌庫／棄牌區資訊，讓玩家以資訊做選擇。 |
| 神蹟主題 | 庇護 | 免疫、承受、轉移、解除或清除負面效果，保護自己或他人免受災難影響。 |
| 神蹟主題 | 共鳴 | 明確連結其他玩家的選擇、結果或資源；強調合作、談判、互惠與桌面政治。 |
| 神蹟主題 | 火種 | 直接改變火種的取得、支付、轉移、返還或以火種作代價的經濟選擇。 |
| 神蹟主題 | 使命 | 直接改變使命進度、使命選擇、使命條件或使命完成結果。 |
| 災難主題 | 熄滅 | 直接削減火種、壓低火種獲得，或破壞玩家的火種經濟。 |
| 災難主題 | 掠奪 | 強制棄牌、奪取、扣留或破壞手牌結構；自願交換／共同重新分配優先歸流轉或共鳴。 |
| 災難主題 | 重構 | 重排或改寫既有場面結構、玩家關係、目標選擇或出牌規則；包含強制傳遞、持續規則改寫與目標隨機化。 |
| 災難主題 | 蔓延 | 效果會持續、延遲，或隨條件在玩家／區域之間傳遞與擴散。 |
| 災難主題 | 崩解 | 直接破壞效果區、已出牌區、牌庫可用性或其他已建立的場面結構，而非主要攻擊手牌或火種。 |
| 時機 | 應對 | 僅在指定事件即將發生或正在結算時可打出；不占一般行動。 |
| 範圍 | 單體／多體／群體 | 分別表示一名目標、指定數名目標、所有符合條件的玩家。 |

## 已確定的標籤圖案

| 標籤 | 圖案語彙 | 使用方式 |
|---|---|---|
| 新生 | 深綠、圓角的實心菱形 | 右上與左下角成對出現；不以「新生」文字再重複標示。 |

## 多標籤卡的顯示原則

- 雙標籤卡：兩個標籤各使用一個角落圖案。與該牌核心效果**關聯較大**的標籤放在右上；次要標籤放在左下。
- 「關聯較大」依卡牌實際主要玩法判斷，不以標籤在資料中的先後順序決定。
- 三標籤以上卡：日後只顯示權重最高的兩個圖案；第三標籤不塞進角落，仍可在長按詳細資訊中完整查看。〈恰如飛鳥經過〉預定顯示「共鳴」（右上）與「流轉」（左下），不顯示使命。
