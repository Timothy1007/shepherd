# Case01 餐廳｜空間層次與探索構圖 QA 實驗

> 2026-11-15 設計提案，**未實作**。目標不是再加家具、調 Shader，而是用可觀察的空間改造測試「房間是否不再像平整方盒子」。Claude 實作前應讀 `docs/level/CASE01_DINING_ARCHITECTURE_V1.md`、`docs/CH17_3D_ART_DIRECTION_AND_PIPELINE.md`、`docs/CH17_LANTERN_DUAL_STATE_EXPLORATION.md`，並以最新 main 程式與已完成美術為準。

## 已知約束
- 餐廳室內 5.80 × 6.31 m、淨高 3.25 m；東牆走廊門與北牆廚房門位置不變。
- 既有橫樑與兩側短牆、共用牆封閉壁爐與壁龕、餐桌東西向、南側小型起居角都應保留其建築與生活邏輯；不是重新堆疊更多裝飾。
- 保留十月十九日月曆、晚餐、推開的椅子、門的既有敘事與動線；主要通道至少 0.85 m，原設計更寬的區域盡量維持。
- 褪色態、提燈局部記憶、輸入/相機與其他房間不在本次修改範圍。

## 要驗證的空間假設
1. 入口第一視角不應一次攤開四面牆與全部家具；要有**前景框景—中景生活區—背景發現點**。
2. 餐桌可以是主生活區，但不能是唯一視覺重心。壁爐/相片、南側起居角、北側通廚房區域應各有不等強度的次焦點。
3. **牆面層次要有真實深度**，不是只在牆上貼線板：利用已存在的煙囪胸牆、壁龕、短牆與深淺不一的櫃體、窗簾、局部遮擋形成側視視差。
4. 擺設是**生活行為群組**，不是牆邊一圈等距展示架：用餐、壁爐家庭記憶、南側短暫休息。物件轉角、椅子方向、局部不對稱必須有使用原因，不能亂數擺放。
5. 光線作為**注意力節奏**：先吸引至用餐區，再引導壁爐與起居角；次焦點應可探索但不全部同亮。黑暗不得破壞行走可讀性。

## 最小可試方案（獨立 QA）
- 建立獨立「餐廳空間構圖 QA」，能在**現況 A / 構圖改造 B** 間切換或使用兩個可明確進入的 QA 場景。不得覆蓋正式場景或原有渲染 A/B/C QA。
- **第一輪只做一個改造版本**，不要一次製作三個風格版本。優先重新配置既有物件、調整物件朝向與群組；必要時增加少量有敘事用途的遮擋/牆面深度物件，禁止用大量無意義小物填空。
- 建議測試：入口附近以既有短牆、門框或合理位置的櫃體形成部分前景遮擋；餐桌不再在每個入口視角都完全居中暴露；壁爐及壁龕利用深度、光照與局部物件組合成可走近觀察的次焦點；南側扶手椅/邊桌/電視/書櫃組成非對稱小型生活角；保留廚房門的清楚可達性。
- 若現有牆面/物件無法形成可感知的視差，可試一段**有建築理由的**局部進深或厚實框景，但不可移動外牆、門洞、承重樑或破壞既定建築敘事。
- 第一輪不重做模型、UV、材質、Shader 或整體後製；光照僅做**局部焦點引導**，不要用整體變暗假裝增加深度。
- 對照 A/B 的**玩家身高、FOV、入口起點、時間/環境光、畫質**必須一致。若需要局部焦點燈光差異，另列明並提供「只改擺設」與「加光照引導」兩段結果，避免歸因混淆。

## 交付前必做
1. 先畫一份**標註實際方位與現有門洞的俯視配置圖**：入口、主/次焦點、前中後景、遮擋、視線、路徑；列出每件移動/新增/刪除物件及其生活理由。不要先改程式才想原因。
2. 提供**入口第一眼、餐桌側面、壁爐側面、南側起居角**四個同機位 A/B 截圖；並提供實際可走動的 QA。
3. 玩家從入口能辨認至少三個空間區域，但不會在原地看盡所有線索；側移時有清楚前後視差；壁爐、壁龕與起居角有靠近觀察的理由。
4. 檢查門口、桌邊、壁爐前、廚房門、起居角路徑的碰撞與通行，保留至少 0.85 m 淨寬；不可讓裝飾遮住既有互動。
5. 完成後回報變更檔案、QA 入口/操作、截圖位置、實際測試結果、commit SHA；沒有在 Unity 實測的項目不得稱通過。

## 決策原則
使用者試玩後才決定是否採用 B 或再進一步改造。**目標是空間的節奏與自然感，不是更滿、更亂或更暗。**
