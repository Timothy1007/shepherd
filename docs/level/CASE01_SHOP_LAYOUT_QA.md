## 怎麼進入

1. Unity 選單 **Shepherd → 提燈原型（正式遊戲）**（唯一的主要入口；沒有新增入口或場景）。
2. 遊戲中按 **Shift+F2**：進入「服飾店布局測試」，傳送到店門內側，右上角出現說明。

| 按鍵 | 功能 |
|---|---|
| **J** | 切換布局：現況 → A → B |
| **K** | 成人／孩子記憶視角（只降低攝影機） |
| **U／I** | 孩子眼高 −／＋ 0.05 m（QA 參數，預設 1.12 m，範圍 0.85～1.40） |
| **1～5** | 觀察點：入口、櫃台前、工作區（縫紉機旁）、衣架後方、住宅入口（往店裡看） |
| **Shift+F2** | 離開（回到現況、成人視角） |

測試模式不改其他操作；E、F、空白鍵（聚光）、Tab 筆記等都照常，可以直接在 A／B 裡解 S1、S2、S4。

## 一、現況盤點（最新 main）

- **建築**：店面寬 6.5×深 5（平面單位，世界尺寸×1.3＝8.45 m×6.5 m），一樓淨高約 3.4 m。店門在前牆右側（x 4.6～5.6），前窗在左前（x 0.77～1.93），通往走廊（住宅）的門在後牆，**正對店門**（x 4.7～5.45）。
- **家具**：櫃台在最後面（x 1.29～3.51、z 3.82～4.38）、鈕扣櫃在左後角、左牆一座衣架、窗下縫紉機（S4）＋凳子＋燙衣板、右牆布料架與鏡子、門邊傘架、客人椅。
- **互動**：S1 電箱在後牆（x≈1.85，高 1.43～1.72 m）；S2 外套與吊牌掛在左牆（z≈3.55）；S4 縫紉機在窗下；衣架後的照片在左牆（z≈2.6，只在提燈光裡）；影子殘影在右牆（z≈1.85）。
- **S3 抽屜訂單簿**：設計文件有，但**正式遊戲目前沒有實作**（程式註記「第二批再加」）。本次只在櫃台的店主側預留位置，沒有加物件或劇情。
- **玩家**：CharacterController 高 1.8 m、半徑 0.35 m；成人眼高 1.62 m；提燈與手照常。

**實際問題**
1. 前門和走廊門正對，中間整片空地：**進門一眼看完整間店，也直接看穿到走廊**，沒有逐步揭露。
2. 櫃台在最裡面：客人要走過整間店才能交衣服，接待不合理。
3. 沒有試衣間（只有鏡子和椅子）、沒有裁剪桌；工作區和接待區沒有分開。
4. 家具全部靠牆：沒有前景、中景、背景，遮擋與視線引導都靠牆面。
5. S3 尚未實作（見上）。

## 二、A｜生活機能優先

依真實家庭改衣店的營業邏輯排：**進門 → 接待／收件 → 試衣／量身 → 店主側的工作區 → 回住宅**。

- **接待**：櫃台移到進門左手邊，面向通道（客人一進門就能交衣服、取件）；收銀機、針線盒、暖色小燈跟著櫃台。
- **工作區**：櫃台後面是店主側。裁剪桌（量布、畫線、燙平，下層放布捲）放在店中段偏左；縫紉機留在窗下（自然光）。
- **試衣**：右後角加試衣間（布簾半開，裡面一張小凳），鏡子在試衣間前。
- **儲物**：布料架移到後牆（電箱右邊），紙箱移到鈕扣櫃旁，電箱前留出站的位置。
- **回住宅**：店主從工作區沿後段走到走廊門，不必穿過客人區。

## 三、B｜探索構圖強化

在同樣合理的營業邏輯下加強遮擋與層次：

- **前景**：進門左邊一座雙面成衣架（等客人取件的衣服），擋住左半邊。進門看不到窗下的縫紉機、照片那面牆與外套。
- **中景**：第二座衣架（待修改的衣服）橫在店中間偏左，和左牆衣架之間形成一條窄的「衣架後方」，照片就在那面牆上。這座衣架和縫紉機凳子之間留約 0.9 m 可以走。
- **背景**：櫃台往前移到店中段、面向門口，後面是店主區（電箱、布料架、鈕扣櫃）。**成人可以越過櫃台看到電箱，孩子看不到**。
- **試衣間**：右牆中段，鏡子移到它後面；影子殘影那面牆（右牆 z≈1.85）保持空著（測試確認看得到、能播放）。
- **通行**：主通道（店門→走廊門）仍是直線，寬度合格。遮擋只靠衣架、櫃台、試衣間這些營業本來就有的家具，不靠堆雜物。

從眼睛位置對每個物件的多個取樣點做射線檢查：在畫面內、沒有被碰撞體擋住才算看得到。照片只在提燈光裡出現，又在衣架與牆之間，所以三套都看不到。

**孩子視角觀察**
- A：櫃台高 1.13 m，孩子眼高 1.12 m，櫃台後面的東西都被擋住。從櫃台前看不到 S2 吊牌，成人可以。
- B：從櫃台前看，孩子只看到櫃台正面與左牆的外套，櫃台後的電箱看不到。
- B 的入口截圖：孩子視角裡前景衣架的衣服在頭頂上方、壓迫感更強，衣架下方能看到更多後面的地面；成人視角被衣服擋住的範圍比較大（未量測精確高度）。這可以作為之後孩子記憶段落的線索方向（例如藏在衣架下、櫃台下的東西），**本次沒有新增物件或劇情**。
