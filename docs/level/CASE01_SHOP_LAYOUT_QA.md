# Case01〈第十七號門〉服飾店（家庭改衣店）布局：A 正式＋記憶視角眼高

> 2026-11-16 使用者試玩後決定：**採用 A｜生活機能優先為正式布局**，B 移除；孩子視角改成跟著記憶門走的正式機制。
> 依《設計總綱》§5.5–5.7、§7。沒有改：餐廳 B、廚房 B、提燈與手、移動手感、房間連接、其他房間、全域 UI 與光照。

## 一、正式布局：A｜生活機能優先

依真實家庭改衣店的營業邏輯排：**進門 → 接待／收件 → 試衣／量身 → 店主側的工作區 → 回住宅**。

- **接待**：櫃台在進門左手邊，面向通道（客人一進門就能交衣服、取件）；收銀機、針線盒、暖色小燈跟著櫃台。
- **工作區**：櫃台後面是店主側。裁剪桌（量布、畫線、燙平，下層放布捲）在店中段偏左；縫紉機（S4）留在窗下（自然光）。
- **試衣**：右後角是試衣間（布簾半開，裡面一張小凳），鏡子在試衣間前。
- **儲物**：布料架在後牆（電箱右邊），紙箱在鈕扣櫃旁，電箱前留出站的位置。
- **回住宅**：店主從工作區沿後段走到走廊門，不必穿過客人區。
- 牆上的謎題與線索沒有動：S1 電箱（後牆）、S2 外套與吊牌（左牆）、衣架後的照片（左牆，只在提燈光裡）、影子殘影（右牆）。
- **S3 抽屜訂單簿**：設計文件有，但正式遊戲還沒有實作；櫃台的店主側預留了位置。
- **之後再看**：A 的後段（店主側、電箱、布料架一帶）要不要加東西讓它更豐富。
- **提案（未實作）**：可推動的箱子，小小孩推到桌子旁站上去，就看得到桌面上的東西。

## 二、記憶視角的眼高（正式；設計總綱 §10）

只改第一人稱攝影機的高度；碰撞體（高 1.8 m）、步行速度、提燈與互動都不變，牧羊人不是真的變成孩子。
**眼高跟著記憶進度走，不是跟著房間**，而且只會往前、不會倒退：

| 記憶進度 | 怎麼觸發 | 眼高 |
|---|---|---|
| 門外的街道、其他場地 | — | 1.62 m |
| **幼年** | 跨進第十七號門（店面、走廊、從走廊後門進的側院） | **0.85 m** |
| **青春期** | 第一次從走廊進到餐廳。之後回到走廊、店面、側院都維持；**廚房也維持青春期** | **1.12 m** |
| **成人** | 第一次**從廚房穿過恢復的通路走進側院**。之後到哪裡都是成人 | **1.62 m** |

**廚房↔側院的通路**（廚房東牆的門洞）：
- 一開始兩側都是完整的牆：沒有門框、走不過去，提燈也照不出來（補牆和整面牆是同一種材質）。
- 青春期之後第一次進到廚房，通路恢復；之後一直開著、兩邊都能走。
- **走廊→側院的普通後門**從頭到尾都能走；從這裡進側院不會提前變成人。
- 兩種探索順序都可以：A. 先從走廊後門去側院拿線、回店裡縫好，再進餐廳；B. 先進餐廳→廚房→通路→側院拿線→從走廊後門回店裡縫。
- 走過觸發點時約半秒平順過渡；傳送時直接到位。重新開始（房子重建）會回到幼年、通路重新封住。
- 截圖（Unity 實機，封住時開著提燈）：`docs/prototype/kitchen_yard_passage/`（`passage_sealed_kitchen.jpg`、`passage_sealed_yard.jpg`、`passage_open_kitchen.jpg`、`passage_open_yard.jpg`）。
- 0.85 m 是使用者試玩時按 U 調到的高度。U 的下限現在放寬到 0.60，之後還可以再試。
## 三、測試模式（沒有新增入口）

Unity 選單 **Shepherd → 提燈原型（正式遊戲）**，遊戲中按 **Shift+F2**：傳送到店門內側，右上角出現說明。

| 按鍵 | 功能 |
|---|---|
| **K** | 視角：自動（依記憶進度）→ 強制成人 → 強制小小孩 → 自動 |
| **U／I** | 小小孩眼高 −／＋ 0.05 m（0.60～1.40） |
| **1～5** | 觀察點：入口、櫃台前、工作區（縫紉機旁）、衣架後方、住宅入口（往店裡看） |
| **Shift+F2** | 離開（回到自動視角） |

不按 Shift+F2 時，正式遊戲本來就會依記憶進度套用眼高。測試模式右上角會顯示目前的記憶進度、通路有沒有開。

## 四、測試

- EditMode（提燈原型）67/67、PlayMode 1/1（2026-11-16 記憶進度版）。其他舊的測試組沒有重跑。
- 新增或改寫的測試：
  - **A 是正式布局**：S1 電箱（小小孩眼高也能互動）、S2 吊牌（聚光）、紅線、S4 穿針、店面修好、影子殘影都正常。
  - **A 的動線**：店門→接待→店主側→裁剪桌→外套→左牆衣架→窗邊縫紉機→電箱→往住宅的門，每一點都走得到；全屋動線淨寬合格；切回原本的擺法再套回 A，完全一樣。
  - **廚房↔側院通路**：一開始兩側都擋住（射線從廚房、側院打過去都打在補牆上）、沒有門框、和整面牆同一種材質；提燈照著也還是牆；幼年從側院走不進廚房。
  - **路線 A**：幼年從走廊後門到側院拿線（還是幼年）→ 回店縫好 → 進餐廳變青春期 → 回走廊、再從後門進側院仍是青春期、通路仍封著 → 進廚房通路出現、仍是青春期 → 穿過通路進側院變成人（每格眼高變化不超過平順過渡的上限）→ 走回廚房、餐廳、走廊、店面都還是成人。
  - **路線 B**：先進餐廳→廚房（還沒拿線也能開通路）→ 通路進側院變成人 → 拿線 → 走廊後門回店裡縫好；碰撞體與速度不變。
  - **其他**：街道是成人、K 的三段切換、重新開始回到幼年且通路重新封住、正式布局重建後仍在。
