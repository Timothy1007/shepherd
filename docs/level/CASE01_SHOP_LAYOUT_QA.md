# Case01〈第十七號門〉服飾店（家庭改衣店）布局：A 正式＋記憶視角眼高

> 2026-11-16 使用者試玩後決定：**採用 A｜生活機能優先為正式布局**，B 移除；孩子視角改成跟著記憶門走的正式機制。
> 依《設計總綱》§5.5–5.7、§7。沒有改：餐廳 B、廚房 B、提燈與手、移動手感、房間連接、其他房間、全域 UI 與光照。

## 一、正式布局：A｜生活機能優先

依真實家庭改衣店的營業邏輯排：**進門 → 接待／收件 → 試衣／量身 → 店主側的工作區 → 回住宅**。

- **接待**：櫃台在進門左手邊，面向通道（客人一進門就能交衣服、取件）；收銀機、針線盒、暖色小燈跟著櫃台。
- **工作區**：櫃台後面是店主側。裁剪桌（量布、畫線、燙平，下層放布捲）在店中段偏左；縫紉機（S4）留在窗下（自然光）。
- **試衣**：右後角是試衣間（布簾半開，裡面一張小凳），鏡子在試衣間前。
- **儲物**：布料架在後牆（電箱右邊），紙箱在鈕扣櫃旁，電箱前留出站的位置。
- **回住宅**：店主從工作區沿後段走到走廊門，不必穿過客人區。
- 牆上的謎題與線索沒有動：S1 電箱（後牆）、S2 外套與吊牌（左牆）、衣架後的照片（左牆，只在提燈光裡）、影子殘影（右牆）。
- **S3 抽屜訂單簿**：設計文件有，但正式遊戲還沒有實作；櫃台的店主側預留了位置。
- **之後再看**：A 的後段（店主側、電箱、布料架一帶）要不要加東西讓它更豐富。
- **提案（未實作）**：可推動的箱子，小小孩推到桌子旁站上去，就看得到桌面上的東西。

## 二、記憶視角的眼高（正式）

只改第一人稱攝影機的高度；碰撞體（高 1.8 m）、步行速度、互動能力都不變，牧羊人不是真的變成孩子。

| 位置 | 記憶時期 | 眼高 |
|---|---|---|
| 門外的街道、其他場地 | （現在） | 1.62 m |
| **店面、走廊、側院** | 很小的時候 | **0.85 m** |
| **餐廳**（含起居角，推開拉鋸的記憶門之後） | 上了初中 | **1.12 m** |
| **廚房** | 成年 | **1.62 m** |

- 走廊門、往側院（拿紅線）的側門都是**普通的門**，不改變身高。
- 走過記憶門時約半秒平順過渡；傳送時直接到位。
- 0.85 m 是使用者試玩時按 U 調到的高度（U 的下限原本就是 0.85，所以按到第 8、9 下之後都停在 0.85）。現在下限放寬到 0.60，之後還可以再試。
- 使用者試玩的感受：0.85 m 剛好看不到一些桌上的東西。S1 電箱（1.43～1.72 m）在這個高度仍然可以互動（測試確認）。

## 三、測試模式（沒有新增入口）

Unity 選單 **Shepherd → 提燈原型（正式遊戲）**，遊戲中按 **Shift+F2**：傳送到店門內側，右上角出現說明。

| 按鍵 | 功能 |
|---|---|
| **K** | 視角：自動（依記憶房間）→ 強制成人 → 強制小小孩 → 自動 |
| **U／I** | 小小孩眼高 −／＋ 0.05 m（0.60～1.40） |
| **1～5** | 觀察點：入口、櫃台前、工作區（縫紉機旁）、衣架後方、住宅入口（往店裡看） |
| **Shift+F2** | 離開（回到自動視角） |

不按 Shift+F2 時，正式遊戲本來就會依房間套用眼高。

## 四、測試

- EditMode（提燈原型）64/64、PlayMode 1/1。其他舊的測試組沒有重跑。
- 新增或改寫的測試：
  - **A 是正式布局**：S1 電箱（小小孩眼高也能互動）、S2 吊牌（聚光）、紅線、S4 穿針、店面修好、影子殘影都正常。
  - **A 的動線**：店門→接待→店主側→裁剪桌→外套→左牆衣架→窗邊縫紉機→電箱→往住宅的門，每一點都走得到；全屋動線淨寬合格；切回原本的擺法再套回 A，完全一樣。
  - **記憶眼高**：街道 1.62、店面／走廊／側院 0.85、餐廳 1.12、廚房 1.62；過渡是平順的；K 的三段切換；碰撞體與速度不變。
