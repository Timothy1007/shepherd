# Case01〈第十七號門〉住宅關卡設計 v0.1（使用者已確認方向）

> 2026-11-13，Claude 草擬。依據：提燈 QA v0.6 的現有機制，對照 GDC〈優秀關卡設計的 10 個原則〉（Dan Taylor）。
> 目的：機制已經夠了，接下來要讓**房子本身圍繞「提燈照出真實」來設計**。本文件是提案，標「待確認」的地方要使用者決定後才動工。

---

## 1. 問題：現在的房子只是「放線索的容器」

| 原則 | 現況 |
|---|---|
| 由機制驅動 | 整棟只有一面異域牆用到提燈；路線和光無關 |
| 不靠文字 | 靠房名牌、右上角提示清單、字幕告訴玩家去哪、做什麼 |
| 一路都在教 | 所有能力一開始全給，沒有「學 → 練 → 變化」 |
| 有效率 | 每間房做完一件事就沒用了，沒有捷徑、沒有回圈 |
| 簡單／中等／困難 | 沒有可選的難路線 |
| 意外、情緒 | 只有反撲時有起伏；房間之間平平的 |

## 2. 設計核心：**光就是路**

一句話：**廢墟擋住你的路，真實替你開路。**

| 異域（廢墟）裡 | 真實（光裡）裡 | 玩家要做的事 |
|---|---|---|
| 被木板釘死的門 | 開著的門 | 走近、用提燈照著穿過去 |
| 塌掉的樓梯、地板破洞 | 完整的階梯、地板 | 聚光照著前方，慢慢走過去（真實的地方才踩得到） |
| 倒下的書櫃擋住門口 | 書櫃立在牆邊 | 修好那個房間 → 永久打開這條路（捷徑） |
| 天花板塌下來的瓦礫堆 | 空的走道 | 射一發穩定能量，暫時打開一個泡泡，趁它還在時鑽過去 |
| 從牆裡長出來的異域牆 | 牆後的角落 | 聚光照著它 |

> 技術上需要新增：**依「真實／異域」切換的碰撞體**。現在的 `LanternAnomalyBlocker` 只處理「異域牆」，要擴充成兩種：只在真實裡存在的地板／階梯，以及只在異域裡存在的路障。

**修好的房間＝安全的據點（待確認）**：整間房變回真實後，它的燈在停電時也亮著（溫暖的光從門口漏出來），失序體不會進入真實的房間。反撲時玩家可以選擇「退回據點」或「留在暗處打」。這樣修房間就不只是集點數，而是在**改變地圖**。

## 3. 動線：一個樞紐＋兩個回圈

```
                  ┌──────────── 二樓 ────────────┐
                  │  母親的房間   艾琳的房間   書房 │
                  │      └──── 走廊（繞樓梯井一圈）┘
                  └──────────────┬──────────────────
                                 │  樓梯（廢墟裡塌了一半 → 聚光照著走）
  門外 ── 玄關（樞紐）───────────┤
            │  電箱（紅燈）        │
            ├── 客廳 ══(修好後的捷徑)══ 餐廳 ── 廚房 ── 後廚 ── 側院（可選）
            │                                    ║
            └═════════(修好後的側門，回到玄關)══════╝
```

- **樞紐**：玄關。從這裡看得到三個方向（客廳門、樓梯、走廊盡頭）。
- **一樓回圈**：玄關 → 客廳 → 餐廳 → 廚房 → 側門回玄關。一開始只有玄關 → 客廳的門開著，其他段要靠修房間打開。
- **二樓回圈**：走廊繞樓梯井一圈，三間房的門都面向走廊。
- **順序自由**（使用者已決定）：一樓三個線索任意順序；二樓兩個線索任意順序。限制前進的是**能力與路線**，不是線索順序。

## 4. 教學節奏（每一步只教一件事）

| # | 地點 | 教什麼 | 怎麼教（不用文字） |
|---|---|---|---|
| 0 | 門外 | 光裡才是真的 | 門牌在暗處是 16，提燈一靠近變 17；前門在暗處被木板釘死，光裡是開著的門 → 玩家自己發現「提燈能開路」 |
| 1 | 玄關 | 按住 E 復原 | 全黑的玄關裡唯一亮著的是電箱的紅燈（地標）。推回拉桿 → 燈亮了，但照出來的是廢墟（情緒：這個家怎麼了） |
| 2 | 玄關 → 客廳 | 聚光 | 從玄關就看得到壁爐上的全家福（視線設計），但太遠、一般光照不到；按住 Space 光變細長、照得到它 |
| 3 | 客廳 | 修好 → 整間變回真實 → 第一次反撲 | 第一波只有 1 隻；客廳剛變回真實、燈亮著，是安全的練習場。倒下的書櫃立回去，露出通往餐廳的門（第一條捷徑） |
| 4 | 餐廳 | 射擊的另一個用途 | 椅子壓在塌下來的瓦礫後面：射一發，泡泡裡的瓦礫消失，趁它收回去之前把椅子扶正 |
| 5 | 廚房、後廚 | 牽引、搬運、丟 | 後廚門口卡著東西要用丟的撞開；藍坐墊椅子要搬到凹痕上。提示是牆上那張「女孩踩椅子拿罐子」的舊照片，不是文字 |
| 6 | 樓梯 | 組合：聚光＋走路 | 廢墟裡樓梯塌了一半；聚光照著前方，光裡的階梯才踩得到；聚光會走得慢，二樓傳來聲音（緊張）。走上去後，按住 E 修好樓梯口的欄杆柱 → 樓梯永久完整（捷徑） |
| 7 | 二樓 | 在窄空間裡應付反撲 | 走廊窄、轉角多；第二、三波各 2 隻；可以退回已修好的房間 |
| 8 | 書房／艾琳的房間 | 最後的線索 → 崩壞 | 兩個都完成時進入最終戰（已實作） |

## 5. 拿掉文字，改用環境引導

| 現在的文字 | 改成 |
|---|---|
| 房名牌 | 每個房間有自己的**地標物件與光的顏色**：客廳＝壁爐的暖光、廚房＝冷白的磁磚、艾琳的房間＝檯燈與書堆 |
| 右上角提示清單 | 改成**可以打開的筆記本**（母親的手寫筆記，按鍵打開），不打開就不會看到。待確認：完全拿掉，還是保留成可開關的筆記 |
| 「用聚光照它」 | 線索靠近時發出細微的「真實的聲音」（像收音機調頻），提燈越靠近越清楚 |
| 「該放回廚房高櫃前」 | 舊照片、地上的凹痕、拿起椅子時凹痕發光（已實作） |
| 反撲時的字幕 | 燈閃、低鳴、遠處傳來腳步聲 |

**地標**（任何地方都能定位自己）：壁爐上的全家福（從玄關看得到）、電箱紅燈、樓梯井、二樓走廊盡頭那幅畫（暗處是一隻眼睛）。

## 6. 可選的難路線（簡單／中等／困難）

- **側院**：要從後廚的窗戶出去，窗戶在異域裡釘死、要用射擊泡泡穿過。高處放著一片記憶碎片，要把木箱疊起來才拿得到。
- **樓梯下的儲藏室**：門在異域裡不存在，只有聚光照著時看得到門把。裡面是母親收著的東西（艾琳的舊外套）。
- **母親衣櫃頂上**：要把椅子牽引上去當墊腳。

獎勵是**記憶碎片**（故事），不是數值。不拿也能通關。

## 8. 需要的實作（確認後才做）

1. 依真實／異域切換的碰撞體（只在真實裡存在的地板、階梯；只在異域裡存在的路障）。
2. 灰盒重排：客廳 ↔ 餐廳的門、廚房 → 玄關的側門、樓梯下儲藏室、側院出口。
3. 樓梯：塌了一半的廢墟版本＋聚光才踩得到的階梯＋修好欄杆柱變永久。
4. 修好的房間＝據點（若確認）：停電時燈仍亮、失序體不進入。
5. 移除房名牌與提示清單；加上線索的「真實的聲音」與母親的筆記本（若確認）。
6. 門外的開場（門牌 16/17、前門）。
7. 測試：每一段的路線是否走得通（NavMesh＋玩家），以及沒有提燈時確實過不去。

## 9. 使用者已決定（2026-11-13）

1. **採用「光就是路」**：整棟房子圍繞提燈設計；廢墟擋路、真實開路，修房間開捷徑。
2. **修好的房間＝安全據點**：停電時燈仍亮著，失序體不會進入真實的房間。
3. **提示清單改成母親的筆記本**：按鍵打開才看得到，平常畫面上沒有文字，用環境引導。
4. **上二樓用樓梯限制**：廢墟裡樓梯塌了一半，聚光照著才踩得到；修好欄杆柱後樓梯永久完整。
