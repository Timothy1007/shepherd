# Case01〈第十七號門〉住宅生活化、家具配置與建模規格 v1

> **2026-11-15 使用者確認方向；供 Claude 後續建模使用。** 本文件為新增的場景美術／配置規格，不表示已建模、已改關卡或已通過 QA。只增補，不覆寫既有文件、程式、模型、動線、劇情及文案。
> 依據：`CASE01_INVESTIGATION_AND_LAYOUT_V2.md`、`case01_layout_v2.svg`、`CASE01_HOUSE_LEVEL_DESIGN_V0_1.md`、`CASE01_GAMEPLAY_DESIGN_V0_1.md`、`../design/COMMISSION_REALITY_AND_NARRATIVE_ADDENDUM_2026-11-14.md`。後續以實際遊戲場景的門、窗、樓梯、碰撞與尺寸為準。
> **美術定位**：英式老聯排屋／改衣店外殼 + 東亞移民母女的日常生活；經濟狀況不差、偏中產、有質感、收納相對整齊，**但生活痕跡濃厚**。不是豪宅、精品樣品屋、刻意髒亂或恐怖道具展覽。既有視覺參考方向是生活化的英式住宅、移民家庭廚房、改衣店與閣樓；本文件不複製第三方照片或要求逐圖還原。

## A. 不可破壞的前提

1. **格局不重畫**：一樓臨街改衣店 → 後方玄關走廊與樓梯 → 中段餐廳 → 後方 L 形加建廚房／側院；二樓前客廳、後母親舊房、浴室與平台；閣樓艾琳房；地下室可選。維持既有窗洞、門洞、謎題位置、回圈與垂直動線。不要照舊版「一樓客廳」的灰盒構想把客廳搬下樓。
2. **原規格**：實際建築參考寬 6.5m、深 15m，遊戲體感約 1.3 倍；不是要求所有家具等比放大 1.3 倍。先量現有 Unity 場景實際尺寸、玩家碰撞膠囊、攝影機高度及開門範圍，再決定家具尺度。
3. **正常生活先於謎題**：每個房間先滿足使用功能，故事物件藏在可信的日常陳設裡。東西要有放置原因；入口不堵、椅子可拉、櫃門可開、床可接近、冰箱可打開。
4. **兩代痕跡**：母親的物品偏耐用、修補、收納；艾琳的物品偏現代、工作與個人興趣；共同區域自然混合。不靠到處貼紅燈籠／中國字證明文化。
5. **不改主線**：外套吊牌、冰箱週日保鮮盒／豆腐、壁爐全家福、外婆供桌、舊縫紉機與頂針盒、艾琳研究牆／行李箱／童年碗、餐廳第二副碗筷及椅痕等原線索必須保留。其劇情內容、解謎、台詞不在本次更改。

## B. 走路、家具比例、互動的建模約束（建議起始值，須實測）

| 項目 | 建議淨空／尺寸 | 注意 |
|---|---|---|
| 主探索通道、玄關至樓梯及主要門前 | **≥ 1.1–1.2m 淨寬**；有空間可達 1.4m | 以玩家碰撞體、第一人稱轉向與未來移動端操作實測；不可只用視覺估計 |
| 次要通行、家具間通路 | **≥ 0.85–0.9m** | 僅在無須戰鬥、搬運或雙向通過處使用；過窄則調家具 |
| 互動物件前方站位 | **約 0.9–1.2m 可站立深度** | 冰箱、抽屜、門、衣櫃、書桌、供桌、線索檢視均需留空 |
| 開門／抽屜／椅子活動區 | **額外保留開啟與拉出範圍** | 門扇不得撞固定家具；抽屜拉出後仍可操作 |
| 轉角、樓梯口、需牽引／搬運處 | **優先約 1.4–1.6m 的局部轉身區** | 預留物件碰撞和攝影機視角，不把可拾取物件卡在牆角 |
| 餐桌 | 約 **1.3–1.6 × 0.75–0.9m**，4 人桌 | 不必正中；至少一側保留主要通道，椅子可正常拉開 |
| 沙發 | 約 **1.7–2.1m** 寬 | 配茶几時留通道；避免沙發、茶几與扶手椅塞滿房間 |
| 單人床／雙人床 | 約 **0.9–1.2 × 1.9–2m**／**1.35–1.5 × 1.9–2m** | 依角色房間需求與實測空間選擇，不強迫每房雙人床 |
| 工作檯／書桌／廚房檯面 | 深約 **0.55–0.65m** | 桌椅操作及抽屜站位另計 |

- 以上是**遊戲場景初始設計值，不是建築法規或已驗證的 QA 標準**；現場碰撞、可用空間與攝影機優先。
- 大件家具沿牆、窗邊、功能分區擺放；中間保持合理生活動線。小物集中在「檯面／架上／桌邊」形成密度，不在地上均勻散亂；以**疏密對比**避免「空」與「擠」。
- 以站立第一人稱檢視：重要物件可看清、可接近、可放大；不要為填滿畫面而擋窗、堵門、遮掉主要線索或讓視角貼家具。
- 互動分層：**A 劇情必需**（既有線索）、**B 生活互動候選**（開櫃、抽屜、查看、開燈、拿杯等）、**C 純環境物件**（杯子、書、盒、衣物等）。**B 不代表已決定實作**；先留碰撞與動畫空間。模型可用模組化套件重組，不要求每件小物獨立高精度。
- 在**正常生活版本**先合理配置；異域的毀損、位移、遮蔽與提燈狀態作為第二層，不可用「異域」為由讓正常入口長期堆滿障礙。若劇情需要阻路，應有明確異域態、可解除條件，與正常態區別。

## C. 分室配置（建模參考清單）

### 1F 改衣店（臨街）

- **功能與主家具**：櫥窗展示、人台、2–3 件展示服裝、接待／收銀櫃台、訂單本、取件衣架、試衣簾與鏡、裁布工作桌、縫紉機、熨斗／燙衣板、布捲與線架、分類抽屜、衣物籃。
- **牆面**：英文價目表／營業資訊、營業執照、布料色卡、掛鐘、舊掛曆、中英文工作便條；保持視覺層次，不貼滿。
- **生活痕跡**：母親保溫杯、老花眼鏡、椅背針織外套、常用剪刀、零碎鈕扣罐。收納有序，工作檯保留正在工作的痕跡。
- **A**：無名外套與多次塗改尺寸吊牌、櫃台後電箱；放在可信的待取件／工作區，不做正中央神壇式陳列。
- **B 候選**：翻訂單本、查看吊牌、拉試衣簾、檢視抽屜。**動線**：顧客從入口到櫃台、試衣區、後方住宅通路不可被人台或衣架阻斷。

### 1F 玄關、走廊、樓梯下方（優先修正）

- **功能與主家具**：窄鞋櫃、拖鞋與地墊、掛衣鉤、傘桶、鑰匙盤、郵件盤、玄關小鏡、頂燈；牆面電箱／開關、家用掛曆與少量中文提醒、電話答錄機（既有可選線索）。
- **梯下收納**：以現有梯下空間配置吸塵器、掃把、折疊梯、工具箱、備用燈泡、清潔用品、封閉櫃或既有可選儲藏室；儲藏門與開啟範圍要合理。原文件梯下的艾琳舊外套線索仍屬可選，不與店面核心外套混淆。
- **生活痕跡**：母親仍放著的室內拖鞋、艾琳的鞋，鑰匙、傘、包；不必全部做互動。
- **嚴禁**：正常態進門立刻有箱子／大櫃／雜物擋住；樓梯下收納溢出主要通道。先整理入口淨空再增加小物。

### 1F 餐廳（終章）

- **功能與主家具**：4 人木餐桌、4 椅、餐邊櫃／碗櫃、吊燈；桌上水壺、杯墊、面紙盒、調味瓶、餐墊、水果盤；碗筷、筷筒、陶瓷湯匙、茶葉罐、備用折疊椅。
- **牆面**：家庭月曆、掛鐘、少量生活照、可能的舊身高刻痕（是否作線索另議）；牆上原有椅背撞痕必須保留且可辨識。
- **A**：一副碗筷、第二副碗筷擺放位置、被推開的椅子、停在週日的日曆。第二副碗筷可由碗櫃／童年碗結合原謎題取用，**不可擅自改變既有取得條件**。
- **動線**：餐桌略偏一側，不堵廚房入口；椅子拉開後仍能通行；終章的互動站位與事件演出區預留淨空。

### 1F 廚房／後廚（L 形加建）

- **功能與主家具**：水槽、瀝水架、洗碗精／海綿、爐具與抽油煙機、炒鍋／湯鍋／鍋鏟、砧板與刀架、備餐檯、電鍋、熱水壺、微波爐、米桶、冰箱、吊櫃、乾貨櫃、垃圾／回收桶；後廚可放洗衣機或清潔工具（依實際空間）。
- **中西融合**：西式櫥櫃、磁磚、爐具與東亞家庭的米、醬油、乾香菇、麵條、陶瓷碗、保鮮盒；不必刻意加裝飾符號。
- **牆面**：防濺磁磚、掛鍋鏟鉤、手寫食譜、插座、便條；保留窗光與工作燈。
- **A**：冰箱每週日保鮮盒／豆腐、需要搬椅子的高櫃與凹痕、既有照片提示；冰箱內仍需有普通食材，線索才不突兀。
- **B 候選**：開冰箱／吊櫃、查看便條、移動椅子、檢視保鮮盒。**動線**：冰箱門完整開啟、玩家能站在高櫃前、椅子可牽引移動；不可讓廚房島台（若有）擠掉通道。

### 2F 客廳（臨街凸窗）

- **功能與主家具**：雙／三人沙發、單人扶手椅、茶几、電視櫃、書櫃／矮櫃、邊桌、地毯、窗簾、立燈；少量植物。
- **生活痕跡**：遙控器、面紙、馬克杯、報刊、眼鏡、毯子、抱枕、充電線；風格有不同年代但保持整潔。
- **牆面**：壁爐與其上全家福、其他年份照片、少量風景畫、掛鐘；外婆照片與供桌在安靜側角，包含香爐／供杯，**不把供桌硬塞進壁爐**。
- **A**：壁爐全家福缺失、供桌香煙、既有聚光觀察。確保視線與提燈照射範圍，不用額外家具擋住。
- **動線**：沙發與茶几距離自然，通往走廊及母親舊房的門／捷徑保持可走。

### 2F 母親舊房

- **功能與主家具**：床、床頭櫃、衣櫃、鏡子、小椅、摺好的被單、舊衣、梳子、收納盒、老花眼鏡；保留舊縫紉機及針線／布料／線軸／鈕扣盒。
- **牆面**：簡單風景畫、家庭照、掛衣鉤、舊掛曆；不刻意大量中國風圖案。
- **時間感**：母親已搬離，床鋪整齊、部分物件少量積塵；但艾琳維護過縫紉機，留下較新的使用痕跡。
- **A**：英文維修便條與中文註解、外婆頂針盒、門的異域迴圈。抽屜可打開且前方有站位。
- **B 候選**：查看衣櫃／針線盒／抽屜。不要把床或椅子堵住原本的門機關。

### 2F 浴室（小）

- **功能**：洗手台、鏡櫃、馬桶、浴缸或淋浴區、毛巾架、衛生紙、洗手乳、牙刷杯、牙膏、洗髮精、清潔用品、垃圾桶、浴室墊／洗衣籃。
- **牆面**：鏡前燈、毛巾鉤、磁磚、通風口；有正常照明與可辨識輪廓。
- **互動**：鏡子／關門的異域效果為既有可選方向；不強加大量劇情證據。**動線**：即使房間小，也要能轉身、開門、面向鏡子操作。

### 2F 樓梯平台與走廊

- **功能**：扶手、壁燈、少量家庭照片、窄壁掛架／畫、開關；避免落地大櫃擋住樓梯出口。
- **A**：既有「通回原處」異域門與通往閣樓的梯子／樓梯；保留可讀性及互動站位。
- **動線**：轉角、上下樓梯、門扇開啟區保持淨空；環境小物優先掛牆。

### 閣樓艾琳房

- **功能與主家具**：床、床頭燈、書桌與椅、電腦／檯燈、書架、文件夾、分類盒、衣櫃／掛衣桿、鏡子、洗衣籃、行李箱、個人裝飾與普通生活照片。
- **牆面**：僅一面牆的局部作研究區，貼舊街圖、檔案影本、地址記錄、便條；其餘保留生活照片、喜好、書架與空白牆面。不要四面都做陰謀牆。
- **A**：研究牆、打包到一半的行李箱、童年碗（放在有生活理由的收納盒／櫃內）、錄音／筆記線索；**艾琳是生活過的人，不是只為提供線索而存在**。
- **光與動線**：天窗月光照研究牆；斜屋頂下低矮處放收納，主要站立、移動與互動區位於足夠淨高的中央。研究牆前與行李箱周圍留站位。
- **可選**：屋簷下爬行儲藏區，放舊剪報等；不更改正式通關要求。

### 地下室（可選）

- **功能**：店面布料庫存、舊衣架、紙箱、縫紉機零件、工具架、鍋爐、清潔用品、外婆舊皮箱；管線、電表、手寫分類標籤。
- **空間**：實用倉庫而非刻意恐怖迷宮；異域「樓梯比正常長／多出不存在的房間」作獨立狀態，不把正常樓梯堆滿箱子。

### 後院／側院（可選）

- **功能**：垃圾與回收桶、晾衣架、花盆、戶外水龍頭、清潔工具、舊椅／待修小家電。
- **動線**：後門、窗戶與店面側門的連接須符合既有平面圖及可達性；不能為了回圈無根據硬開新門。

## D. 建模分批與驗收

**建議建模順序**（供 Claude 排工，不代表現在已執行）：
1. **先核對實際房屋尺寸／玩家碰撞／現有門窗與動線**，清掉正常態玄關的非合理阻擋；先以簡單幾何體確認主通道、家具尺度、可轉身與可互動站位。
2. 大件家具與空間功能：各房必需的床、桌、櫃、廚具、沙發、店面設備；保持英式房屋結構及東亞家庭混搭。
3. 中件與牆面：窗簾、畫框、掛鐘、掛曆、供桌、衣架、燈具、書架、掛鉤、照片；注意線索可讀性。
4. 小件與生活痕跡：杯、紙、衣、書、瓶罐、保鮮盒、線軸、拖鞋、清潔用品。**模組化、少量變體與有意義的聚集**，不要滿地均勻撒道具。
5. 對照正常態與異域態檢查遮擋、碰撞、提燈視野與關鍵道具；逐房 QA，再整棟走查。

**驗收檢查**：
- 從前門走到店面、玄關、樓梯、餐廳、廚房，**正常態不會被無理由的家具堵住**。
- 每個房間不用看提示也能從家具與用品看出用途；有東西方生活習慣的自然混合；看起來是**生活不錯、有溫度、有使用痕跡的中產家庭**。
- 重要劇情物件與原有謎題未遺失、未被遮擋、未改觸發；門、抽屜、冰箱、椅子等互動前方有站位。
- 走廊／樓梯／轉角能正常轉身，牽引物件不穿牆／卡住，視角不被近距離大件家具佔滿；小房間可略窄，但不犧牲基本可玩性。
- 家具尺度與玩家身高、門高、窗台、扶手一致；不能把真實家具和放大後房間等比放大造成巨人屋。
- 每間房有疏密變化：視線能落在地標與線索上，角落和檯面有生活細節，不是空白展間也不是堆滿貨的倉庫。
- **QA 場景**：實際開始製作／調整視覺素材時，依專案規則建立或更新隔離的 Case01 家具配置 QA，不污染正式對局與全域 UI；完成前不宣稱通過。

## E. 衝突及保留

- 舊文件有不同版本的一樓客廳／二樓客廳配置，**本次依已採用的 layout v2：二樓客廳**；不直接刪改舊文件。
- 「每房修好永久維持」與新補充的「核未解除前僅局部暫時穩定」存在語義衝突；本文件**不處理機制**，家具須支援正常態與異域態，待專項釐清。
