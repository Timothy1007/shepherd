# 卡牌標籤校準盤點

本盤點以 `docs/SPECIAL_CARDS_MASTER.md` 的正式標籤與 `docs/CARD_FACE_DESIGN_SYSTEM.md` 的 2026-10 校準定義交叉檢查。除下列待決項目外，其餘 38 張卡的正式標籤都可由新定義合理解釋。

## 待決項目

| 卡牌 | 現有標籤 | 問題 | 建議 |
|---|---|---|---|
| 在黎明前叩門 | 洞察｜新生 | 效果是「下一次因效果抽牌時多抽 1」，不查看、篩選或重排牌庫／棄牌資訊，因此不完全符合洞察的校準定義。 | 改為 **新生**；若希望保留洞察，需把洞察定義擴大為「所有抽牌增益」。 |
| 行向水深之處 | 洞察｜新生 | 洞察明確成立；新生是否成立取決於「冒險翻牌直到死亡」是否視為重新取得選擇，而非單純的牌庫探索。 | 保留 **洞察｜新生** 或收斂為 **洞察**，需確認設計意圖。 |
| 第二次生命 | 共鳴｜流轉 | 效果不連結其他玩家；主要是把「獲得火種」轉換成抽牌，並可能再得火種。 | 改為 **火種｜流轉**。 |
| 灰與燼 | 正式：群體｜熄滅；程式：群體｜熄滅｜蔓延 | 效果持續到本輪結束，但不會傳遞、擴散或延遲觸發；與蔓延定義不符。 | 程式標籤移除 **蔓延**，保留 **群體｜熄滅**。 |

## 已確認可維持的邊界案例

- 〈於水中重生〉：**流轉｜新生**。整手棄抽是手牌結構重置，同時重新取得選擇。
- 〈告別舊時代〉：**群體｜重構**。雖有手牌移動，但它強制重排整體玩家關係與出牌方向，不是自願流轉。
- 〈替罪羊〉：**應對｜共鳴**。核心是承接另一名玩家的災難結果，而不是免疫或解除災難。
- 〈劫後餘生〉：**火種｜流轉**。把火種與手牌在不同玩家的選擇中轉換，兩者都成立。
- 〈虛謊之舌〉：**應對｜重構**。它在指定時機改寫既有神蹟結果，符合時機與規則改寫兩層。
