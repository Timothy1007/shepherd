# 《牧羊人：荒野之歌》故事模式設計方向

更新：2026-09-15

## 模式定位

遊戲核心爭局系統共用，但外層目的不同：

- **故事模式**：探索世界、體驗事件、認識與收集卡牌。
- **牌位模式**：公平競技、牌組／卡牌理解、Meta 與爬分需求。
- **荒野／肉鴿探索**：可作為故事模式中的特殊探索區域，以同一套爭局核心提供隨機事件、Build、合作與競爭。

故事與荒野預設應支援 **1–4 名真人，不足席位由 AI 補齊**，避免故事內容依賴四名真人同時在線。

## 火種與微塵

### 火種

火種衡量「誰贏了這場爭局」。

- 個人競爭資源。
- 故事模式中可帶出爭局。
- 成為使徒及卡牌效果仍是主要取得／變動來源。

### 微塵（暫名）

微塵不是第二種貨幣，而是**本場事件的行動貢獻／推進動力**。

- 每張成功打出的牌具有固定微塵值。
- 物資牌基準值暫定為 1。
- 神蹟／災難依效果、使用難度與故事價值配置不同微塵值。
- 強效果不應必然同時具有高微塵，避免雙重優勢；允許低微塵甚至 0 微塵的純競爭牌，以及效果普通但高微塵的事件牌。
- 微塵在單場爭局／事件中累積，結束後清零，不作為永久帳號貨幣。
- 同一事件可同時追蹤「共同微塵進度」與「各玩家個人貢獻」。

核心定位：

> 火種衡量誰贏了爭局；微塵衡量誰為事件做了多少事。

## 故事事件

進入一場爭局時，可以同時存在：

1. **主要爭局目標**：例如 3 輪內成為火種最多的使徒。
2. **事件／支線目標**：例如遭遇盜賊，全體玩家在期限內共同累積 100 微塵。

事件失敗原則上不直接懲罰玩家，但會失去該事件獎勵、故事結果或後續分支。例如 92/100 時盜賊逃脫，玩家保留主線進度但無法取得擊敗盜賊的獎勵。

事件獎勵應兼顧共同完成與個人貢獻。避免單純依百分比切割所有獎勵，可採：

- 有參與：基礎獎勵。
- 達成一定貢獻門檻：額外素材／獎勵。
- 本場最高貢獻：關鍵貢獻獎勵。

具體數值後續平衡。

## 微塵事件不只等於 Boss HP

微塵是故事模式的統一事件互動介面，可以有不同關卡規則，例如：

- 限定輪數內累積指定微塵。
- 每輪必須產生最低微塵，否則觸發事件效果。
- 特定牌型產生額外／較少微塵，改變本場出牌價值。
- 玩家選擇將個人貢獻投入不同事件目標。
- 共同完成事件，但依個人貢獻決定額外獎勵。

因此故事模式可以形成「個人爭局勝負」與「共同事件目標」同時存在的合作競爭張力。

## 荒野／肉鴿方向

荒野可採節點式遠征，例如：

起點 → 爭局 → 隨機事件 → 賜福／強化 → 爭局 → 精英事件 → Boss

肉鴿強化原則：

- 強化只在**本次遠征**有效，遠征結束清除。
- 不永久修改卡牌基本數值，避免故事進度破壞牌位平衡。
- 可出現「本次遠征群羊微塵 +1」、「每場第一次使用神蹟時抽 1 張」等 Build 效果。
- 同時保留合作與競爭：玩家需要共同完成事件，但仍可競爭使徒、火種與最高微塵貢獻。

永久成長應以收藏、故事解鎖、角色、外觀及其他 Meta progression 為主；牌位模式不承接故事／肉鴿的局內數值強化。

## 後續待定

- 「微塵」是否為最終名稱。
- 各牌微塵定價公式與數值區間。
- 事件模板與難度曲線。
- 貢獻獎勵門檻。
- 故事模式火種的局外用途與經濟循環。
- 荒野遠征長度、節點類型與 Build 池。
