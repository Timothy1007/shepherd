# 提燈手感 QA v0.3（第三批：光的形狀＋聚光、音效、失序體與戰鬥測試場）

> 2026-11-12。灰盒原型，**不是正式美術**。接續 v0.2（`LANTERN_PROTOTYPE_V0_2_QA.md`）。
> 依使用者 v0.2 試玩回饋：光圈「太近」；射擊、牽引、復原都 OK，但要有怪物才知道好不好玩；戰鬥需要大空間跑跳。

## 這次做了什麼
1. **光的形狀**
   - 平常是**往前偏的蛋形**：身邊約 1 m 是真實，前方約 2.3 m，越遠越淡；側面與身後較短。另有一道往前的柔光，照亮範圍與真實範圍一致。
   - **按住 Space 聚光**：把提燈舉高，光變成**越遠越寬的錐形光束**，照到約 6 m。代價是身邊變暗、走路變慢（×0.6）。
2. **音效**：全部用程式合成，暫用，不是正式音效。
   - 穩定器：蓄力（音高隨蓄力上升）、射擊、撞擊。
   - 牽引：抓取、持續低鳴、放下、丟出。
   - 復原：持續施放的泛音、完成時的鐘聲；放對位置的提示音。
   - 其他：提燈開關、腳步、異域環境低鳴。
   - 失序體：3D 低鳴、攻擊前兆的尖嘯、撲擊、丟光球、被打中、消散。玩家受傷也有聲音。
3. **戰鬥測試場**（F6）：和住宅分開的 24×24 m、挑高 4 m 大廳。
   - 6 根柱子、3 段矮牆可以繞著跑、躲光球。
   - 9 個木箱、3 張椅子可以牽引來丟。
   - 4 盞冷色異域燈。
4. **失序體（第一隻）**
   - **外觀**：暗處幾乎是看不見的黑影，進到提燈光裡才看清楚輪廓。靠低鳴聲和胸口暗暗的核心光點找它。
   - **追擊**：速度 2.0 m/s。玩家走 1.7、快走 2.6，所以快走可以甩開。
   - **近身撲擊**：距離 2.6 m 內先出現**前兆 0.75 秒**（身體膨脹、核心變亮、尖嘯），接著往前撲 3.2 m，打中扣 25。撲完會喘 0.9 秒，這是破綻。
   - **遠程光球**：4.5–12 m，前兆 0.9 秒後丟出慢速光球（6.5 m/s、不追蹤），打中扣 15。橫移就能躲開，冷卻 4.5 秒。
   - **受傷**：生命 6。
     - 蓄力射擊 1–3 點，並暈眩 1–2.4 秒。
     - 丟物件打中 2 點，並暈眩 2 秒。
     - **暈眩或喘息中受到的傷害加倍**。
   - **死亡**：消散後那一區**永久恢復現實**；5 秒後在離你最遠的出生點出現下一隻。
5. **玩家**
   - 生命 100。受傷時畫面泛紅、鏡頭震動、有聲音。4 秒沒受傷後每秒回 10。
   - 生命歸零會倒下，不能移動。2 秒後回到戰鬥場入口、生命回滿，失序體重新出現在遠處。
   - 左下角是生命條。

## 怎麼玩
- 選單 `Shepherd/Prototype/提燈手感 QA`，按 **F6** 傳送到戰鬥場。
- **按鍵**：

  | 按鍵 | 功能 |
  |---|---|
  | F | 提燈開關 |
  | 按住 Space | 聚光 |
  | Q | 光圈大小 |
  | 1 / 2 / 3 或滾輪 | 射擊／牽引／復原 |
  | 左鍵 | 使用 |
  | 右鍵 | 牽引時蓄力丟出 |
  | F1–F4 | 住宅四個空間 |
  | F6 | 戰鬥場 |
  | F12 | 數值（含生命、失序體狀態） |

- **建議打法**：
  1. 先用提燈找到它。
  2. 看到前兆就退開或橫移。
  3. 趁它喘息或暈眩時打：蓄力射擊，或拿木箱砸。

## 測試（只跑提燈測試，依使用者要求不再重跑舊房子的全套測試）
- `LanternPrototypeTests` 共 15 項。新增 6 項：
  - 蛋形光與聚光錐形
  - 失序體追擊 → 前兆 ≥0.6 秒 → 撲中扣 25
  - 撲擊可以躲、光球可以橫移躲開、站著會被打中
  - 射擊暈眩 → 破綻加倍 → 消散成穩定區 → 重生
  - 玩家受傷、回血、倒下與重生
  - 暗處黑影與光裡清楚、音效存在
- `LanternPrototypePlayModeTests` 1 項。
- **舊房子、正式 Demo、戰鬥 Lab 的測試這一輪沒有重跑**：只改了提燈資料夾內的檔案，沒有動共用程式。
- 自動測試不代表手感驗收。

## 已知限制與還沒做的
- 失序體是方塊疊成的灰盒，**沒有正式造型與動畫**；移動是簡單的直線追擊加繞障礙，不會尋路繞過複雜地形。
- 只有一種失序體，一次只有一隻。
- 音效是程式合成的暫用版。
- 暗處的失序體很難看見，這是刻意的設計。如果試玩覺得太難，可以讓它的核心亮一點，或在暗處留一圈很淡的輪廓。
- 還沒做：提燈能量規則、聚光的代價（目前只會變慢）、手機操作、正式房子大小、正式美術。
