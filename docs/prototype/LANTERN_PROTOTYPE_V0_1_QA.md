## 這一段做了什麼
1. **專案改用 URP**（Linear、HDR、柔和陰影、SSAO、Forward+）。
2. **「顯示真實」shader**（`LanternReveal`）：
   - 光圈內顯示真實、光圈外顯示異域。
   - 三種物件：
     - 同一個東西兩種樣子（牆、地板、照片、門牌、日曆、畫）
     - 只存在於真實（衣帽架、第二副餐具、桌邊的椅子、站著的高櫃、綠葉）
     - 只存在於異域（不存在的紅門、倒掛的椅子、倒下的高櫃、枯枝）
   - 交界有一圈帶雜訊的光邊；光圈外的異域物件會輕微扭動；陰影也跟著消失或出現。
3. **異域自己的光**：冷色、會閃。走廊燈泡在真實裡其實是熄滅的；客廳立燈發紫光；亮房間是過曝的青白「日光」。
4. **亮房間驗證「不是照明，是顯示真實」**：在很亮的地方開提燈，光圈內的顏色、日曆數字（16→17）、地毯、枯枝→綠葉照樣改變。
5. **第一人稱身體**：
   - 右手提燈，畫在獨立的疊加鏡頭，不會穿進牆裡。轉頭和走路時燈會擺動。
   - 燈光會呼吸。開關提燈時，光圈平滑展開或收合。
   - 低頭看得到身體和鞋子；走路時鏡頭輕微晃動（可關閉）。
6. **空間**：三個相連空間，有轉角和隔牆，一進門看不到全貌（書櫃隔牆擋住客廳後方角落和通往亮房間的門）。

## 已知限制與還沒做的
- **全部是灰盒**：方塊、圓柱、程式畫的貼圖。手是一顆球加一段圓柱，提燈也很簡單，正式造型之後換。
- **提燈固定在鏡頭座標裡擺動**：低頭時燈不會依重力垂直往下垂，正式版要改。
- **光邊**是發光雜訊，正式的光邊效果（粒子、扭曲）之後再做。
- **還沒做**：
  - 第二段：蓄力攻擊、牽引、復原
  - 第三段：手機虛擬搖桿與按鈕
  - 提燈能量規則
  - 失序體
- 只存在於真實或異域的物件**目前沒有碰撞**，要等「開關光圈時能不能走過去」的規則定了再加。
- 舊卡牌戰鬥、正式 Demo 與其他 QA 都沒有改玩法；它們只是跟著專案換成 URP 算圖，畫面亮度會略有不同。
