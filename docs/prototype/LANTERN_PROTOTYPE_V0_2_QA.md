## 三種動作的規則（原型數值）
- **射擊**
  - 蓄力 1.1 秒滿格；有瞄準輔助（10° 內會鎖定練習靶），飛行中會輕微追蹤。
  - 撞擊點**短暫打開一小塊現實**：半徑 0.7–1.4 m，維持 3–5 秒，展開與收合都是漸變。
  - 打中練習靶時，靶會暈眩 1.2–2.6 秒，停止移動並噴出干擾粒子。
- **牽引**
  - 8 m 內可以抓取。物件被拉到面前 1.5–2.6 m 處浮著，用彈簧加阻尼的方式跟隨，會自己轉正。
  - 被拉太遠或卡住時會自動放開。
  - 丟出速度 6–15 m/s；對著練習靶丟會自動修正方向，打中一樣會讓它暈眩。
- **復原**
  - 持續施放 1.6 秒完成。物件會先抬起、再轉正、最後輕輕落定（倒帶感）。中途放開會以較慢的速度倒回去。
  - 完成後附近**永久變成穩定區**：提燈關掉也維持真實。

## 小謎題（灰盒）
1. **客廳隔牆後的角落**：倒下的高櫃 → 復原。
2. **廚房**：藍坐墊椅子 → 牽引到高櫃前地上的四個椅腳凹痕 → 「放對了」，附近亮起並變成穩定區（呼應 Issue #7）。
3. **廚房東牆**：異域裡是一面牆，真實裡是通往儲藏室的門洞。提燈靠近，或對牆射一發穩定能量，牆就暫時不存在，可以走過去。儲藏室裡有一張舊照片：女孩踩在椅子上拿高櫃上的罐子。
4. **亮房間**：會左右飄移的練習靶（簡化的失序體）→ 蓄力射擊，或丟木箱打中。
5. **廚房**：三個木箱可以牽引、丟出；倒下的凳子可以復原。

## 已知限制與還沒做的
- **全部是灰盒**：手、提燈、穩定器、練習靶都是方塊和圓柱。
- 提燈**低頭時不會依重力下垂**。
- 光線是一條會晃的線，還沒有正式的特效（粒子流、扭曲）。
- **聲音**：還沒有任何音效（蓄力、射擊、牽引、復原、撞擊）。
- 只存在於真實的物件（例如第二張椅子）**沒有碰撞**；只有異域牆會依「是否被照成真實」切換碰撞。
- **手機按鈕**是第三段。
- **提燈能量規則**、**失序體的攻擊與玩家受傷**都還沒做。
- 正式房子大小與「異域讓房子變大」的做法要另外討論。
