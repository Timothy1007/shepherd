# 第十七號門｜三種渲染即時切換 QA：啟動與操作

> 對應規格：`docs/CH17_RENDER_STYLE_SWITCH_QA_TASK.md`。2026-11-15 實作。
> 這是獨立的 QA 場景，不會改到正式探索場景（`LanternPrototypeQA.unity`）、全域畫質設定或其他房間。

## 啟動

1. 用 Unity 2022.3.18f1 打開專案 `unity/`。
2. 上方選單 **Shepherd → Prototype → Case01 三種渲染切換 QA（按 F6 切換 A／B／C）**。
   - 會自動打開 `Assets/Exploration/Scenes/LanternRenderStyleQA.unity` 並按下 Play。
   - 也可以手動在 Project 視窗打開這個場景再按 Play。
3. 進入後玩家站在一樓餐廳的起居區（靠走廊門），面向壁爐，提燈是放下的。
4. 如果滑鼠沒有鎖住，先在 Game 畫面點一下（Unity 編輯器的限制）。

> 第一次進場或第一次切到某個模式時，可能會頓一下（Unity 第一次編譯 shader）；之後切換是即時的。

## 操作

| 按鍵 | 功能 |
|---|---|
| **F6** | 循環切換 A → B → C → A |
| **按住 Alt** | 放開滑鼠，可以直接點畫面右上角的 **A／B／C** 按鈕；放開 Alt 回到鏡頭控制 |
| **U** | 隱藏／顯示右上角的模式標籤（隱藏時只留一行小提示） |
| WASD／滑鼠 | 走動、轉頭（和平常一樣） |
| F | 開／關提燈（光內是記憶態、光外是褪色態） |
| Space（按住） | 提燈聚焦 |
| E | 互動 |
| Esc | 放開滑鼠；點畫面恢復 |
| [ ／ ] | 滑鼠靈敏度 |

在這個場景裡，F6 原本的「傳送到戰鬥場」和 F11 的整體風格開關會停用（避免兩套設定互相覆蓋）；正式場景不受影響。

## 三種模式改了什麼

三種都用同一份場景、同一批模型和位置；切換不會重新載入場景，也不會移動玩家或改變提燈狀態。

| 模式 | Shader | 燈光 | 後製 |
|---|---|---|---|
| **A｜Cinematic Semi-Realistic**（自然寫實） | 手繪光照關閉（自然 PBR、完整貼圖細節）；繪畫材質層關 | 餐廳補光 1× | ACES、對比 +5、Bloom 0.3、暗角 0.12、無顆粒 |
| **B｜Painterly Semi-Realistic**（繪畫質感，優先候選） | 手繪光照 0.45（光階柔化、貼圖細節收成色塊）；**繪畫材質層開**：世界座標的顏料色差（冷暖輕微擺動）＋短筆觸的明度與粗糙度變化 | 補光 1.15×、略暖 | 暗部抬起、對比 -4、柔光 Bloom 0.55、淡紙感顆粒 |
| **C｜Stylized Cinematic**（風格化電影感） | 手繪光照全開（柔和色階、暗部偏冷）；繪畫材質層 0.45 | 吊燈／壁燈 1.3× 偏橘、補光 0.35×（暗部更深）、起居燈偏冷、環境光偏冷 | 冷暖分離、對比 +20、飽和 +14、Bloom 0.85、暗角 0.34 |

- 繪畫材質層只改表面顏色和粗糙度，不改法線和光照，所以體積、陰影、明暗漸層都保留。
- 餐廳以最新的美術版本為基底（第三版建築＋E1 材質＋E2 補光）。

## 已知限制（實話）

- **反射**：A 規格提到反射，但反射探針在目前的 Forward+ 設定下沒有生效（見餐廳美術實驗紀錄），所以三種模式都只有燈光造成的高光，沒有環境反射；壁爐上的鏡子仍是灰綠色亮面。
- **只在餐廳調過**：補光與燈光的模式差異只套在餐廳的燈；走出餐廳的其他房間只有 shader 和後製的差異。
- **效能**：同一台電腦、同一位置的離線渲染測量，三種模式每張約 6～10 ms，差異不大；這不是遊戲實際 FPS，正式效能要在 Play 模式看 Stats 視窗。

## 驗證紀錄

- EditMode：切換後 shader 參數、燈光、後製確實不同；切換不移動玩家／不改朝向；三種模式下提燈都是局部顯現（光外仍是褪色態）；還原後全部回到原值。
- 驗證截圖：選單沒有入口，由 `LanternRenderStyleQAEditor.CaptureFromCommandLine` 產生（3 個機位 × 褪色／提燈 × A/B/C）。
- **尚未由真人在 Play 模式實際走動切換**——請依上面步驟試玩後再決定正式渲染方向。
