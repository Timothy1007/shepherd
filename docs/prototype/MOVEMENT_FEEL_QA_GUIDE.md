# 第十七號門｜第一人稱移動手感 QA：說明與操作

> 2026-11-16。只調整玩家移動速度、加減速與鏡頭晃動；不改場景、家具、碰撞、謎題、提燈、相機 FOV 或劇情。
> **2026-11-16 使用者試玩後採用 A｜慢速探索為正式參數**：步行 1.5 m/s、快走 2.4 m/s、加速 3.33 m/s²、減速 8 m/s²、只平滑速度大小、步伐式晃動、腳步聲每 0.7 m。舊版（1.9／3.0／加減速 7／時間式晃動）保留在 QA 的「舊版」按鈕當對照。

## 啟動

1. Unity 2022.3.18f1 打開 `unity/`。
2. 選單 **Shepherd → Prototype → Case01 移動手感 QA（F6 切換 A／B／C）**（開啟 `Assets/Exploration/Scenes/LanternMovementQA.unity` 並 Play）。
3. 起點：走廊靠店面那端、面向北；餐廳門和廚房門已經打開。滑鼠沒鎖住就先點一下 Game 畫面。

| 按鍵 | 功能 |
|---|---|
| **F6** | A → B → C 循環 |
| **0** | 舊版參數（對照用） |
| **B** | 鏡頭晃動開／關（沿用提燈 QA 原本的按鍵） |
| **Shift**（按住） | 快走 |
| **按住 Alt** | 放開滑鼠，點右上角按鈕 |
| U | 隱藏標籤 |

右上角會顯示目前預設、步行與快走速度、晃動狀態、**目前速度、上一次起步到 95% 的時間、上一次放開後滑行的距離**。

建議路線：走廊 → 推開的餐廳門 → 餐桌旁 → 壁爐前 → 廚房門 → 廚房 → 回走廊 → 樓梯上平台。每組都走一次，特別注意起步、停下、轉彎和穿過門口。

## 原本的架構與參數（查證結果）

- 控制器：`Scripts/FirstPersonController.cs`（CharacterController；身高 1.8 m、半徑 0.35 m、可跨 0.35 m 小階）。提燈原型由 `LanternPrototypeQA` 每格呼叫 `Player.Step`。
- 單位：Unity 1 單位＝1 公尺；速度是 m/s。房屋有 1.3 倍的體感放大，但移動速度沒有跟著放大。
- 提燈原型原本的值（採用 A 之前）：步行 **1.9 m/s**、快走（Shift）**3.0 m/s**、加減速 **7 m/s²（加速和減速同一個值）**、眼高 1.62 m、垂直 FOV 62°（F5 可切換）。
- 鏡頭晃動：`LanternRig.Tick`，預設開（B 鍵切換）。

## 漂浮感的實際原因

1. **加速和減速同一個值（7 m/s²）**：放開方向鍵後還會滑行，步行約 0.26 m、快走約 0.64 m，像在冰上。
2. **整個速度向量用 MoveTowards 追目標**：一邊走一邊轉頭時，實際移動方向落後鏡頭方向，會有一點側滑。
3. **鏡頭晃動跟時間走，不跟步伐走**：1.9 m/s 時一次上下約 0.87 秒，換算一步約 1.65 m，步子又大又慢，像飄著；停下來時相位還在空轉；腳步聲每 0.8 m 一次，又跟晃動對不上。

## 修正方式（A 已成為正式參數）

| 項目 | 做法 |
|---|---|
| 起步 | 加速度＝步行速度 ÷ 0.45 秒（約 0.4～0.45 秒到速，不是瞬間） |
| 停止 | 減速度另外設定＝max(步行 ÷ 0.2 秒, 快走 ÷ 0.3 秒)：放開後約 0.2 秒停住 |
| 轉向 | 只平滑「速度大小」，方向直接跟著鏡頭（轉頭不側滑）；往反方向時先煞住再走。滑鼠轉向本身沒有任何平滑或延遲 |
| 鏡頭晃動 | 步伐式：一步 0.7 m，上下約 ±0.8 cm、左右約 ±0.5 cm、沒有翻滾；相位跟走過的距離走，停下來就停；可用 B 關閉 |
| 腳步聲 | 每 0.7 m 一次，和晃動對齊 |
| FOV | 不變（不做跑步時的 FOV 變化） |

| 預設 | 步行 | 快走 | 加速度 | 減速度 |
|---|---|---|---|---|
| A｜慢速探索 | 1.5 m/s | 2.4 m/s | 3.33 m/s² | 8.0 m/s² |
| B｜平衡探索 | 1.9 m/s | 3.0 m/s | 4.22 m/s² | 10.0 m/s² |
| C｜較快探索 | 2.4 m/s | 3.8 m/s | 5.33 m/s² | 12.67 m/s² |
| 舊版（對照） | 1.9 m/s | 3.0 m/s | 7 m/s² | 同加速度 |

## 驗證

- EditMode：沒有 QA 時正式參數＝A；A／B／C 的穩定速度、起步時間（0.2～0.6 秒）、放開後滑行（< 0.3 m）、滑鼠轉向同一格生效、轉頭後不側滑；三組都能穿過餐廳門與廚房門的固定路線並走上樓梯。提燈原型 EditMode 64 項、PlayMode 1 項全過。
- 互動距離、碰撞體、房間尺寸、家具位置、提燈與記憶顯示都沒有改動；舊的其他測試組沒有重跑。
