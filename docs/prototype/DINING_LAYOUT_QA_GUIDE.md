# 餐廳空間構圖 QA（A 現況／B 構圖改造）：配置說明與操作

> 對應規格：`docs/level/CASE01_DINING_SPATIAL_DEPTH_QA_PLAN.md`。2026-11-15 實作第一輪（只有一個改造版本 B）。
> 獨立場景，不影響正式探索場景、渲染 A/B/C QA、其他房間、提燈玩法、相機與既有互動。

## 啟動

1. Unity 2022.3.18f1 打開 `unity/`。
2. 選單 **Shepherd → Prototype → Case01 餐廳空間構圖 QA（F6 切換 A／B）**（自動開啟 `Assets/Exploration/Scenes/LanternDiningLayoutQA.unity` 並 Play）。
3. 一進去就站在**走廊門內側、面向西**（「入口第一眼」的機位），提燈放下。滑鼠沒鎖住就先點一下 Game 畫面。

| 按鍵 | 功能 |
|---|---|
| **F6** | A（現況）⇄ B（構圖改造） |
| **G** | B 的光照引導開／關（A 永遠不亮；用來分開看「只改擺設」和「加光照引導」） |
| **按住 Alt** | 放開滑鼠，點右上角的 A／B／光照引導按鈕 |
| U | 隱藏標籤 |
| WASD／滑鼠、F（提燈）、E（互動） | 和平常一樣 |

A／B 的玩家身高、FOV、起點、時間與環境光、畫質完全相同；切換不重載場景、不移動玩家。

## 俯視配置（方位：北＝廚房、東＝走廊、西＝共用牆）

```
            北牆（廚房門 X1.4–2.6，月曆，身高線）
   ┌──[壁龕櫃]─────────────────────────────────┐
   │  ▓壁柱▓ 爐台      [ 餐 桌 ]           碗 │
   │  ▓壁爐▓ ← 次焦點① （主生活區）          櫃 │
   │ [暖氣片＋B:家庭照]                         │
   │══短牆═══ B:門簾 ═════橫樑════ B:門簾 ═短牆═│
   │                                         門│← 入口（走廊門）
   │  盆栽   B:扶手椅↙   │B:書櫃（背對入口） │
   │  B:茶几   ← 次焦點②  │                     │
   │ [電視櫃]  電視上方原本的照片（不動）        │
   └───────────────────────────────────────────┘
            南牆（店面後牆）
```

- **入口第一眼**：前景＝B 的書櫃背面（左前方擋住半個起居角）；中景＝門簾框住的開口與餐桌一角；背景＝壁爐與壁龕（發現點）。
- **主焦點**：餐桌（吊燈）。**次焦點①**：壁爐＋壁爐架相框＋壁龕牆上的家庭照（B＋光照引導時有一盞射燈）。**次焦點②**：南側電視角（扶手椅、茶几檯燈）。**次焦點③**：北側廚房門與月曆（B＋光照引導時廚房透出冷光）。
- **路徑**：門口 → 起居區 → 開口 → 壁爐前走道（約 1.6 m）→ 廚房門；或 開口東側 → 碗櫃前；書櫃與扶手椅之間約 1.2 m 通往電視前。

## B 改了哪些東西、為什麼

| 物件 | A（現況） | B | 生活／建築理由 |
|---|---|---|---|
| 矮書櫃 | 貼南牆 | 轉 90°，從南牆伸出約 1.1 m，背板朝入口、書朝扶手椅 | 隔出看電視的角落；坐在扶手椅伸手就拿得到書。進門時成為前景遮擋，走過去才看見電視角 |
| 扶手椅＋拖鞋 | 西側、與牆平行 | 往角落中間收、斜對電視 | 一個人看電視的位置；不再沿牆等距排列 |
| 小茶几（含檯燈） | 西牆邊 | 扶手椅與電視之間的西側 | 放老花眼鏡、報紙、茶，伸手可及 |
| 兩張家庭照 | 電視上方 | 壁爐南側壁龕的牆上（暖氣片上方），一高一低 | 壁爐成為家庭記憶的焦點；電視上方原本的劇情照片不動 |
| 門簾（新增） | — | 橫樑下一根銅桿、兩片綁在短牆邊的布簾 | 英國舊屋在打通的開口掛簾子擋風保暖；框住看向用餐區的畫面，走動時產生前後視差 |
| 壁爐架射燈（新增，可關） | — | 天花板一盞窄角暖光，照壁爐架與相框 | 光照引導：把視線從餐桌帶到壁爐 |
| 廚房透光（新增，可關） | — | 廚房門內側一點偏冷的光 | 光照引導：提示北邊還有路 |

**沒有動**：門洞、橫樑與短牆、壁柱與壁爐、壁龕櫃、暖氣片、餐桌與四張椅子（含被推開的那張）、碗櫃、月曆、桌上那頓飯、身高線、獎狀、盆栽、電視櫃、電扇、材質、Shader、後製、相機、提燈。
