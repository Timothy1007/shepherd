# 風格測試 v1（A／B）

> 2026-11-13。方向：參考《冤罪殺機》的風格化半寫實（借表現手法，不借設計語言；見 `docs/GAME_POSITIONING_V0_1.md`）。
> 同一批素材、同一個畫面：**A＝原樣**，**B＝風格化**。遊戲中按 **F11** 切換（預設 B）。

## B 做了什麼
| 層 | 內容 |
|---|---|
| 材質（shader 全域開關 `_ShepStylize`） | 貼圖取較模糊的層級（細節少一點、像色塊）；法線變淡；真實（家）的顏色飽和一點、暖一點，廢墟維持褪色；亮暗分成柔和的色階、暗部微冷；朝上的面略亮、朝下略暗；邊緣一點暖色勾邊；保留燈光本身的顏色 |
| 全畫面油彩濾鏡（`LanternPaint.shader`，Kuwahara） | 把畫面整理成筆觸般的色塊、邊緣保持清楚；很淡的描邊與畫布起伏 |
| 調色（提燈 QA 自己的 Volume） | 暗部微冷、亮部偏暖；對比與飽和略高；Bloom；暗角 |
| 霧 | 淡淡的冷色霧，讓遠處退後 |

## 實話
- B 比 A 柔和、有手繪的筆觸感，冷暖對比也比較像我們要的招牌。
- **但離《冤罪殺機》還有一大段距離。**那個風格最主要來自**手繪的貼圖和刻意設計的形體**（誇張一點的比例、清楚的輪廓、每件物品都是美術畫過的），不是後製能補的。後製和著色器只能把「不同來源的模型統一成同一種調子」。
- 所以：風格化的「處理層」我已經能做；要真正到位，還是要風格化的模型和貼圖（素材包、AI 生成、委託美術或混合）。
- 油彩濾鏡在手機上比較吃效能，正式版要做品質選項。
