# 提燈 QA v0.9a（街區與巷子入口＋光的分工＋推門量表）

> 2026-11-13。規則見 `docs/level/CASE01_GAMEPLAY_DESIGN_V0_1.md` 第 8 節。

## 這次做了什麼
| 項目 | 內容 |
|---|---|
| **到達的轉場** | 一開始黑屏，浮出地點字卡（暫定：「車停在街口。第十七號門｜某條街，晚上九點」），再淡入街上 |
| **街區** | 16 號（米白灰泥）與 18 號（紅磚）兩棟聯排屋；亮著暖光的窗、電視藍光的窗、窗裡走動的人影；窗台花盆；對街的咖啡店（OPEN 霓虹）、雜貨店、樓上公寓的窗；四盞維多利亞式街燈；紅色電話亭；垃圾桶 |
| **街上可以互動的** | 18 號的對講機（「沒有 17 號啦」）、社區公告欄（尋物啟事：袖口有手縫字的外套）、信箱（16、18 之間被撬掉的空位）。文字暫定 |
| **巷子** | 16 號和 18 號之間的窄巷：濕石板、積水、晾衣繩、木箱、水管、牆燈。巷底是死路，一面普通的磚牆，只有門牌在 16 和 17 之間閃 |
| **入口** | 舉起提燈（F），牆在光裡變成第十七號的門（門框只在光裡出現）；走進去之後門封起來 |
| **光的分工** | 屋內每間房都有自己的光：異域裡冷色、會閃的燈（看得清路）；店面櫃台上一盞會閃的暖色小燈泡（地標）；後門外的燈光；廚房窗外的月光。提燈負責照出不存在的東西，不再是唯一的光源 |
| **推門量表** | 對準餐廳的門時，準心下方出現呼吸量表：指針來回擺動，亮的那段＝可以推；指針在亮的那段時按住 E。第一次會有一句提示 |

## 怎麼玩
選單 **Shepherd → Prototype → 提燈手感 QA** → 街上 → 走進 16 號和 18 號之間的巷子 → 巷底按 F 舉起提燈 → 走進門。
F1 重新開場、F2 直接到店面、F11 風格 A／B。

## 實話與限制
- **街上還沒有真的路人**：沒有人物模型，現在的「活人感」靠亮著的窗、人影、對講機和店。路人、貓需要人物模型（Tripo＋Mixamo 的流程，之後做）。
- **沒有環境音**：電視聲、車聲、人聲還沒做（需要音效素材，之後一起列清單）。
- 建築都是方塊，對街離得遠、偏暗。
- 店面、餐廳、廚房還沒有謎題與目標（下一步：樣板角落）。
