# 廚房空間改造 QA（A 現況／B 改造）：配置說明與操作

> 2026-11-15。以餐廳 B 方案的空間品質為基準。獨立場景，不影響正式探索場景、餐廳 B、其他房間、提燈、相機與既有互動。
> 程式：`unity/Assets/Exploration/Scripts/Lantern/LanternKitchenLayout.cs`（B 的內容）、`LanternKitchenLayoutSwitch.cs`（QA 切換）。

## 啟動

1. Unity 2022.3.18f1 打開 `unity/`。
2. 選單 **Shepherd → Prototype → Case01 廚房空間改造 QA（F6 切換 A／B）**（開啟 `Assets/Exploration/Scenes/LanternKitchenLayoutQA.unity` 並 Play）。
3. 起點：廚房門內側（從餐廳進來的門），面向北（後窗）。滑鼠沒鎖住就先點一下 Game 畫面。

| 按鍵 | 功能 |
|---|---|
| **F6** | A（現況）⇄ B（改造） |
| **L** | B 的「生活細節」開／關（預覽之後褪色態比較空曠的樣子） |
| **按住 Alt** | 放開滑鼠，點右上角按鈕 |
| U | 隱藏標籤 |
| WASD／滑鼠、F（提燈）、E（互動） | 和平常一樣 |

## 尺寸與現有開口（不變）

- 室內 4.95 m（東西）× 6.25 m（南北）。
- 北牆：後窗（水槽上方）。東牆：東窗（看側院）、後門（往側院）。南牆：往餐廳的門（門往餐廳那側開，不會掃到廚房家具）。

## B 的建築調整與理由

| 調整 | 做法 | 理由與結構關係 |
|---|---|---|
| 斜天花板 | 靠主屋約 3.05 m → 後牆約 2.65 m（平均約 2.85 m），兩根外露椽木 | 廚房是後加建的單層附屋，屋頂從主屋後牆往後下降（單斜）；室內天花板跟著斜。後窗頂 2.45 m、後門頂約 2.62 m 都在天花板下。**地板不改（不做往下一階）**。附屋外觀目前仍是原本的平屋頂，等做側院時再改成斜屋頂外觀 |
| 爐灶凹槽 | 西牆（和 16 號共用的牆）上一根 1.55 m 寬、0.42 m 深的煙囪壁柱，中間是凹槽，瓦斯爐和抽油煙機放進去；凹槽內貼磁磚、上方一條層板 | 附屋原本的燒煤爐灶有自己的煙囪，貼在共用牆上、直接往上穿出附屋屋頂（屋頂上有一根小煙囪）。它和主屋餐廳的壁柱在同一面共用牆、相隔約 2 m，互不相連；主屋後牆不受影響 |
| 後窗下與東北角 | 單純的下櫃＋檯面（2026-11-16 依回饋：原本的落地食物櫃看不出用途，改成一般櫃子） | 以這個尺寸做成儲藏小房間會擋到後門與 K2 前方；一般下櫃最直覺 |

## B 的家具群組（2026-11-16 依試玩回饋修改）

| 群組 | 內容 | 生活關係 |
|---|---|---|
| 煮飯區（西牆） | 凹槽南側：備料台、掛勺子的橫桿、碗盤架；凹槽裡：瓦斯爐；凹槽北側：**水槽（從後窗下移過來）**、緊接著切菜與電鍋的台面；上方吊櫃、防濺磁磚 | 洗菜 → 切菜 → 下鍋一條線 |

| 東窗下 | **留空**（窗邊小桌與凳子拿掉：有飯廳，廚房不需要第二張桌子） | 留給未來的空間揭露 |
| K1 冰箱 | 原位（靠餐廳門東側），米袋在冰箱旁 | 從餐廳進來的右前方前景 |
| 生活細節 | 牆上的舊鍋爐與銅管、後門邊的掛鉤、圍裙、購物袋、雨鞋、碗盤架上的碗盤、水槽旁洗好的碗筷 | 日常痕跡 |

**拿掉**：天花板晾衣架（一般廚房不會有）、窗邊小桌與兩張凳子（B 時既有的凳子不顯示）、落地食物櫃。
**A 專屬（B 換掉）**：灰盒流理台與檯面、灰盒爐子、灰盒吊櫃與縫線、灰盒餐桌、凳子。
**移到 B 的位置**：水槽、抽油煙機、炒鍋、掛勺橫桿與勺子、電鍋等小物、微波爐（依模型實際大小放在檯面上）、碗筷、米袋、廚房的冷色燈。
**不動**：冰箱（K1）、高櫃與餅乾鐵盒（K2）、垃圾桶、所有門窗。
## 視覺焦點與層次（入口往北看）

- 前景：右前方的冰箱、左前方的爐灶凹槽。
- 中景：左邊的水槽與切菜台面、凹槽裡的暖燈（主焦點）。
- 背景：後窗與下櫃（日光）、K2 高櫃、後門。
- 次焦點：K2 高櫃頂的餅乾鐵盒、東窗、後門外的側院。

## 未來的雙狀態與空間揭露（這次只預留）

- B 的物件依用途分成五組（`LanternGraybox.KitchenGroup`）：Structure（斜天花板、壁柱、燈）、Fixtures（流理台、水槽、爐子、櫃子、鍋爐）、Narrative（K1 冰箱、K2 高櫃、餅乾鐵盒，永遠不隱藏）、Life（小物、碗筷、碗盤、鞋與圍裙）、Memory（空的群組，留給之後只在記憶態出現的物件）。
- `SetKitchenGroupVisible(group, on)` 可以單獨開關一組；QA 的 L 鍵就是關掉 Life，預覽褪色態可能的空曠程度。
- 隱藏門／隱藏樓梯：這次沒有新增。刻意保持空的地方：東窗下的地板與牆面（小桌拿掉後空出來）、東牆南段（窗南側到冰箱之間）、K2 高櫃前方的地板。
