# 提燈原型｜滑鼠與鏡頭控制 手動測試

## 這次修了什麼

- **根本原因**：專案用舊 Input Manager（`activeInputHandler: 0`），視角本來就是吃相對位移（`Mouse X`／`Mouse Y`），但游標鎖定只在「開場」和「按 Esc 後點畫面」兩個時機設定。
  Unity 編輯器在**按 Esc、切換視窗、點到 Game 視窗外**時會自己把游標解鎖，程式卻還以為是鎖著的（`cursorFree` 仍是 false）：
  - 游標其實已經在螢幕上自由移動，碰到螢幕／視窗邊緣後 `Mouse X` 就變成 0 → **轉到一半卡住**。
  - 因為程式以為還鎖著，「點一下畫面重新鎖定」也不會觸發 → 只能停止 Play 重來。
- **修正**（只改滑鼠、游標，沒動場景、移動、碰撞）：
  - 新增 `LanternCursorLock`：唯一管理 `Cursor.lockState` 的地方，每個影格核對實際狀態，對不上就立刻重新鎖定。
  - `OnApplicationFocus`：失去焦點放開游標、不轉視角；回到視窗自動重新鎖定。點回視窗的那一下不會變成射擊。
  - 剛鎖定的那一格不吃滑鼠位移（避免游標跳回中央造成的視角大跳動）。
  - Esc：近看中＝放下東西；筆記開著＝關筆記；其他＝放開滑鼠，畫面中央顯示「滑鼠已放開｜點一下畫面繼續」。
  - 滑鼠靈敏度：`[` 降低、`]` 提高（0.3～3.0，每次 0.1），存在 PlayerPrefs。預設 1.0＝原本試玩過的手感。
  - 水平用 `Mathf.Repeat` 連續 360°；垂直 ±80°；鏡頭直接套用視角，沒有加平滑或慣性。

## Play 模式實測步驟

開 `Assets/Exploration/Scenes/LanternPrototypeQA.unity` 場景按 Play，**先點一下 Game 視窗**讓它拿到焦點。

1. **原地連續轉多圈**：不要走動，滑鼠一直往右拖（拿起滑鼠放回再拖也可以），轉 3 圈以上；再往左轉 3 圈。
   - 預期：一直順順地轉，不會在某個角度停住，也沒有游標出現。
2. **滑鼠碰到螢幕邊緣**：用力往同一個方向拖，讓實體滑鼠「應該」早就超出螢幕。
   - 預期：視角繼續轉，不會停。
3. **上下看**：往上推到底、往下推到底，反覆幾次。
   - 預期：到大約仰望天花板／看腳邊就停住，不會翻過去；往反方向推馬上有反應。
4. **開關介面後再轉**：
   - 按 Tab 打開筆記 → 轉一轉（應該照常能轉）→ 按 Tab 或 Esc 關掉 → 再轉。
   - 對著可以拿起來看的東西按 E → 滑鼠會轉物件 → 按 E 或 Esc 放下 → 再轉。
   - 預期：關掉後視角立刻能轉，游標沒有跑出來。
5. **Esc 放開滑鼠**：沒有開任何東西時按 Esc。
   - 預期：游標出現，中央顯示「滑鼠已放開｜點一下畫面繼續」，移動滑鼠不轉視角。點一下畫面 → 游標消失，可以繼續轉；這一下**不會**開槍。
6. **切換視窗後恢復**：Alt+Tab 切到別的程式，再切回來（或在編輯器裡點一下 Project 視窗，再點回 Game 視窗）。
   - 預期：回來後不用停止 Play，視角就能繼續轉；點回視窗的那一下不會開槍。
7. **靈敏度**：按 `]` 幾次、`[` 幾次，畫面上會顯示目前倍率。
   - 覺得太快或太慢請回報大概的倍率（例如「0.7 剛好」），之後可以改成預設值。

有任何一步不符合預期，請告訴我是第幾步、當時在做什麼（開著什麼介面、是不是剛切過視窗）。
