> 2026-11-13。依 `docs/level/CASE01_INVESTIGATION_AND_LAYOUT_V2.md`（已確認：17 號是樓下改衣店、樓上住家；英式聯排屋＋後方 L 形加建＋東亞室內；使用者提的開場）。
> 這是**灰盒**：看空間大小、動線、開場的感覺。家具多半還是方塊，二樓以上暫時封住；舊房子仍保留（F3），舊測試不受影響。

## 怎麼玩
- 選單 **Shepherd → Prototype → 提燈手感 QA**，進入後直接站在**新版房子的門外**，提燈先放下。
- 門牌在 16 和 17 之間閃。按 **F** 舉起提燈，被木板釘死的門在光裡變成開著的門，走進去。
- 進去之後，門在身後封起來（回不去）。

| 按鍵 | 功能 |
|---|---|
| F1 | 新房子門外（重建、重新開場） |
| F2 | 新房子店面 |
| F3 | 舊房子玄關 |

## 已知限制
- 灰盒：店面、餐廳、廚房的東西大多是方塊；需要的模型（人台、衣架、縫紉機、供桌、門、廚房家電等）之後列清單給你同意。
- 室內很暗（沒有電、異域狀態）；電箱、線索、影子殘影、安全據點還沒搬到新房子。
- 二樓、閣樓、地下室還沒蓋。
- 側院在主屋的陰影裡，月光照不到，偏暗。
