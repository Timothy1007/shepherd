# 《牧羊人：荒野之歌》世界觀與敘事聖經（工作版 v0.1）
更新：2026-11-06｜範圍：Unity 3D 探索／敘事版｜狀態：**工作文件，不代表全部定案**

> 目的：讓編劇、遊戲設計、Claude Code 與後續 ChatGPT 對話共享同一套詞彙。此文件不取代 `docs/UNITY_BATTLE_V0.1_SPEC.md` 的戰鬥規則。遇到衝突，戰鬥以該規格及正式 Core 為準；劇情草案不得偷偷升格成世界觀定律。

## A. 設定來源與信心等級
- **已確認／沿用的設計方向**：使用者先前討論並保留的核心共識。
- **Demo 決策**：為第一個可玩切片採用，未必等同正式版序章。
- **候選／待審**：本次敘事提案；不可寫成世界的客觀真相。
- **留白**：尚無定案；不能自行補成正式設定。

## B. 已確認的世界觀基礎
1. **類型與氣質**：現代黑暗都市奇幻；偏英倫都市、都市日常與超自然異常共存，風格化半寫實，而非純中世紀或純寫實恐怖。
2. **失序與異域**：世界各地出現異域，現實規律受到干擾或扭曲。一般人未必明白其全貌，相關組織與調查者掌握較多資訊。
3. **起源保持謎團**：不同勢力對失序有不同解釋；官方對外版本可以存在，但不能把任何一派解釋直接寫成真相。
4. **牧羊人**：並非人人能成為；是一種需要門檻與歷程的引領者／調查者身分，負責調查異域，嘗試引導現實恢復常態。『表面恢復』可能留下更深問題。
5. **實／續／繫**：學者為觀測與應用提出的三種干預分類（結構 Structure、過程 Process、關係 Relation），不一定是世界真正的本體架構。
6. **印與術式**：元素可組合成術式，作為戰鬥與世界觀的技術語彙。Unity 戰鬥 v0.1 使用燃素、基體、擬合劑；學派暫稱實在論、過程哲學、關係論，**尚未定正式名稱**。
7. **失序敵人**：以人形／擬人化異常為主，避免以動物作為主要敵人的視覺語言。失序體的來源、被擊敗後的存在狀態仍需要進一步設計。
8. **事務所與同伴**：事務所是主角長期據點（家），未來有同伴及關係發展，而非一次性任務選單。

## C. Demo 已採用的產品方向（不是宇宙定律）
- 事務所第一人稱開場：玩家已加入，醒來／收到案件通知／接委託。
- 門口互動後**淡出載入**小街區；不製作完整城市步行路網。
- 街區第一人稱調查；進入戰鬥後以第三人稱戰術鏡頭展示角色與術式；結束返回探索。
- 使用既有 Graybox 佔位場景與角色；先不替換正式 3D 主角，不做全域藝術重構。
- 任務狀態跨 Scene 保留；同一事務所未來可以重複返回，不因章節而複製。
- 第一個案件使用暫名**〈第十七號門〉**；核心體驗是：先見矛盾 → 調查求證 → 異域顯現 → 介入／戰鬥 → 處理核 → 留下懸念。

## D. 〈第十七號門〉目前只是候選設定
下列均屬 **[候選／待審]**，僅供 Case01 示範、關卡驗證：
- 某條街的 17 號在地圖／住戶記憶／門牌間出現矛盾。
- 異域具有讓人重返原路、街燈異常、門牌出現／消失的表現。
- 一把刻有 17 的鑰匙作為「核之載體」；**尚未定義核普遍等於物件、執念或矛盾**。
- 核的解除透過正確位置與校正儀式，不是打死最後一名敵人即自動結案。
- 事務所最後回報「地址不存在」，調查紀錄卻留下一段未曾寫下的句子。
- 首位同伴在 Demo 以通訊／文字協作，不做跟隨 NPC；姓名、性別、背景皆未定。

## E. 設計禁區與未決事項
1. **不要**推定每個異域都有可見實體邊界；可有漸變、封閉、局部或未可見邊界。Case01 的「街道折返」是此案現象，不是通用機制。
2. **不要**推定每個異域都有可拾取的水晶核；「核」的本質、分類、可否複數、如何消失尚未確立。
3. **不要**將「牧羊人維護的常態究竟是真是假」提前當作已揭露的主線真相。只可作伏筆與假說。
4. 牧羊人正式任命方式、主角進事務所的經歷、同伴人設、城市／勢力正式命名、官方解釋，全部**留白**。
5. 不要復活舊版羊／糧／錢、耕耘／守望／收割作為現行 Unity 戰鬥系統。
6. 不得因劇情需要改動 v0.1 傷害／AP／共鳴／承接／敵方攻擊等核心數值。
7. 本文件不等於遊戲最終劇本；任何由候選變為已確認的變更，都須明記決策日期、依據與受影響文件。

## F. 對話與敘事的呈現規範（Demo）
| 情境 | 表現 | 移動 |
| --- | --- | --- |
| 遠端搭檔通訊 | 畫面下緣簡短字幕＋姓名，不遮擋操作資訊 | 多數可移動 |
| NPC 面對面交談 | 保留 3D 視角，局部對話面板與少量選項 | 對話中暫停移動 |
| 調查物件 | 準星互動提示、短段觀察文字、獲得線索回饋 | 互動時短暫停住 |
| 案件／委託 | 可翻閱的任務文字與進度，重要線索保留 | 查看面板時暫停 |
| 戰鬥 | 現有第三人稱戰術 HUD 與事件回饋 | 戰鬥鎖定探索 |

原則：少量關鍵文句、用環境揭示異常；第一人稱探索不固定貼大型 2D 半身立繪；重要資訊不能只靠一閃而過的字幕傳達。
