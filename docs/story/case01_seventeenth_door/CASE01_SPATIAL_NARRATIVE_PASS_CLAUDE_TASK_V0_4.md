## 1. 玩家想要的情感曲線
第一印象是「這是一棟有人生活過的英倫住宅」→ 發現房間與記憶不一致 → 燈光變冷、物件蒙塵、凌亂逐漸浮現，像被現實遺忘 → 戰鬥、核修復 → 空間幾何關係穩定，**但家仍是一棟無人的舊房**。
「核修復」只修正異域所維持的異常秩序，**不會讓歷史傷害、母女裂痕、失蹤事件全部倒帶**。H3 可讓危險的錯接停止、部分物件恢復自然物理位置，但不恢復 H0 的照明與完整生活表象。H3 的餐具缺席、空相框、合照淡影與 FP-001 殘留繼續成立。

## 2. 自我對話／劇情提示：第一章以主角為主，不常駐同伴報答案（P0）
- 現有 `Case01Flow.cs` 回應的 `Radio`、`Case01Texts.Companion`、`Case01HouseQA.Handle()` 與 `Case01Hud.ShowRadio()` 要查清：**Case01 本章的自動提示以主角短句優先**，將原本「替玩家解題」的同伴無線電改成主角內心/低聲自語；**不要在全域刪除 Radio 架構**，未來事務所與其他案件仍可使用同伴。
- 可選少量同伴的「聯絡存在感」作為候選，但本輪默認**第一章房屋內沒有常駐遠端解謎員**。若目前文案與正式劇情硬衝突，列出衝突而非把秘密寫死。
- 使用對話框或低位字幕，標示「主角」／內心獨白，不冒充 NPC 通訊。每次 1–2 句，**約 2–5 秒**、可略過且可在日誌中找到重要線索；不要遮住準心、E 互動、面板、戰鬥、核校正選項。與 FP-001 自動檢視不能同時搶焦點。
- 事件優先，只在**首次達成特定因果狀態**觸發，或階段首次回訪，不能玩家反覆穿門就重播同一句；允許少量階段新句。不依房間座標每幀觸發，避免 F1/F2/F3/F4/F5 跳轉與解謎反覆進門重播；按事件 ID 去重。必要時設短 cooldown／隊列，戰鬥／轉場／檢視／結算時暫緩或清除。
- 重要線索採「觀察 → 玩家疑惑 → 自行比對 → 低強度提示」；先顯示矛盾再說答案。遇到無進展可給逐層提示，不要一進核就直接報「選 △」。

## 3. 空間記憶殘響／母女虛影（P0/P1）
目的：讓玩家**短暫看見/聽見這裡曾有人的生活**，不只是恐怖 Jump Scare。虛影是異域中的「記憶殘響／痕跡」的表現，**不能當成證明事件一定發生過或角色仍活著的實況錄影**。對白保持含蓄，不揭露艾琳真相、人工失序組織、第一次校正被隱瞞決策。
設四個可獨立開關的預設片段；**正常移動可略過，不能長時間鎖住鏡頭**。畫面可為半透明剪影/光影/殘像，初版簡單模型 silhouette＋淡出，不用正式人物模型；允許先以可讀字幕/音源與場景痕跡實作。若無可商用真人語音，不可偷用未授權合成聲或冒稱已錄音：先用程序音／占位音色＋字幕，清楚標示尚無角色配音。
| 場所 | 演出與對白候選 | 節奏 |
|---|---|---|
| 玄關（第一次進屋，H0） | 門口兩個生活剪影。一位略帶不耐：「鞋子別又堆在門口。」另一位笑：「我等會還要出去呢。」 | 約 3–5 秒，明亮自然，不恐怖 |
| 餐廳（H0 或餐具改寫前） | 母親整理兩套餐具：「今天會回來吃飯吧？」女兒略停頓：「……我會盡量。」消失後留空位 | 約 4–6 秒，不強制暗示母女爭吵是失序原因 |
| 女兒臥室／書房（H1 或 H2） | 女兒站書桌/書架前翻資料：「這份舊圖……明明還畫著十七號。」 | 約 3–5 秒，證據與異常互相呼應；避免直接說出最終解法 |
| 樓梯平台／第三扇門附近（H2） | 遠處模糊聲「艾琳？」；沒有回答，或被電流雜音吞沒；主角一句「……是剛才的聲音？」 | 2–4 秒，只做情感懸念 |
演出觸發與禁則：
- 以 Case01 專屬事件 flag 管理一次性演出；每片段調用對應定位，不改 NPC 真實行為、戰鬥與 FP-001。
- 隱約聲音必須有獨立可調音量，停 Play/失焦暫停；提供字幕、靜音時仍保留線索；不要高頻閃爍造成不適。
- 若玩家看向其他方向，不要硬轉鏡頭追虛影；可以讓片段留短暫殘痕或日誌記錄，不形成錯過必拿線索的 softlock。
- 這些片段為**候選生活片段**，不得把所有句子推斷為正史真相；不強行賦予核有意識、母女亡魂或「失序體=女兒」。

## 4. H0→H3 視覺衰敗，H3 不回暖（P0，覆蓋舊 v0.3）
- H0：暖木、有人居住的外觀；不改家用材質美術基調。
- H1：第一次回餐廳（餐具由二變一）後，**全屋基調開始變冷**，但程度分房：餐廳/客廳更先受到影響；亮度降低，暖燈有局部失溫，桌布/書櫃等既有異變照舊；少許灰塵痕跡。
- H2：樓梯錯接與二樓深入調查後，**一二樓普遍冷清**；暖燈失效或不合常理，窗邊冷光增強，牆角有低強度積塵、紙張散落、簡單剝落/污痕，保留所有可互動物、門框標示可讀。不得無來源堆滿血跡、巨大裂縫、黴菌迷宮。
- H3：核已校正，**空間穩定**，停止有害的閃光/錯位/噪聲，但**燈色/環境光保持冷白或中性偏冷、室內舊化與無人痕跡仍在**；物件物理位置可恢復正常但不回復「兩個人正在此生活」的假象。FP-001、空白相框、缺茶杯、餐桌一副等殘留保留。
- 避免不必要的全屋瞬間硬切；階段切換可隨房間轉場漸變 0.5–2 秒。F6 藝術 QA / F1–F4 跳轉直接正確重建，無狀態殘留。降低閃爍模式仍有效。
- 先改 `Case01HouseQA.UpdateLights()/ApplyVolumes()` 與 `Case01Palette` 使用邏輯；**檢查目前 H3 會恢復暖光的各處**，不可只改單一光源而主光／室內燈／材質 emissive 還在回暖。

## 5. 失序門的「訊號故障」視覺語言（P0）
目前有第三扇門、夾層的 △/○/□/17 與出口、異常中庭裂口，各自透過 `Case01HouseBuilder.Portal()` 與材質/封口顯示；玩家主要抱怨**不正常連接時那種紫色發光門框＋整片紫色膜**。
- 只改**失序作用中的 portal**：外框輕微破訊／斷續橫向位移、黑灰/冷白/少量去飽和紫色的 glitch；中間是可見的**電視雪花噪點、掃描線、間歇畫面撕裂**，像現實影像接收失敗，非固定紫色平面。
- 可以用 Built-in 管線相容 shader、少量 procedural noise / scrolling UV、門框 shader 或 mesh 偏移做；**不依賴外部影片、不全畫面加噪點**。保留 △/○/□/17 記號、提示與碰撞可讀。
- 門應表現路由狀態：未啟動／錯接／已錨定／成功校正各有差別；校正後失序故障停止，仍可從物理門框辨認路線；不要讓所有普通房門都變故障門。
- 與 Portal 的 `Crossed()`／路由完全解耦：門材質不決定傳送；不能關上實際可走的 portal、不能引入雙向重複傳送。
- 噪點強度提供降低動態/閃爍 fallback，音效輕微電流失真，可調音量；避免高頻刺耳/光敏閃爍。

## 6. 一樓平面與樓梯：**真實幾何調整候選，不是只換道具**（P0 實驗 QA）
玩家試玩感受：一樓是四個方形房間且互相貫通，太容易直接走透，缺乏轉角與探索；提出兩個具體候選：**堵掉餐廳↔玄關的直接開口**，**樓梯改成由另一側上行（上行方向反轉）**。
現有 `Case01HouseBuilder.cs` 用 XZ 方格建造：一樓四區 Kitchen / Entrance / Living / Dining，入口在南側 Entrance；樓梯井約 x=8.8–10，z=1.0–4.6，`BuildStairs()` 沿 z 逐階抬升；二樓 Landing / Study 與第三扇門和錯接 Portal 有固定位置。**不可只簡單旋轉樓梯 mesh**；會撞上樓板、欄杆、碰撞斜坡、上樓抵達區、標記門、虛影點位、相機轉場與 QA 到達點。
先做 **Case01FloorplanV04 QA（獨立變體／mode toggle）**，提供：
- 一樓餐廳與玄關間不再直通：用有碰撞的牆體封口，保持各房至少一條合法路線；避免封掉正式前門/餐桌主調查點。
- 樓梯真實反轉上行方向（或提供 2 個變體 A 真反向、B 半轉角/遮擋）。**最終偏好以玩家提出的反向樓梯為優先實驗，不得以僅加櫃子作替代並宣稱已完成**；需要若干樓梯井／二樓平台結構微調可做，但不得擴建房屋、偷加房間。
- 檢查一樓正常路徑「玄關→生活區→餐廳→二樓」不繞冤枉路；異常錯接首次由書房到餐廳仍能迅速感知。保留誤接從書房到餐廳的功能，但不能利用傳送 bypass 密閉牆造成無法回來。
- 保障所有 `RoomVolume`、Portal plane / arrival pose、StairRamp、roof/ceiling cut、相機、光源、Hotspot 與 F1–F4 / F5 / F6 QA 在新布局中有效。
- 新舊布局可切換 A/B 實測；**沒有人工試玩確認前，正式一般 QA 維持現行格局**。
- 提供簡易俯視圖／實際第一人稱截圖和各路線長度比較（不可臆造米數）；驗收要看方向感、視線遮擋、回訪負擔，不是單純難走。
