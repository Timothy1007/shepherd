依據：`CASE01_WHOLE_HOUSE_ANOMALY_REDESIGN_V1_0.md` 第 9 節「沉浸品質優先」。
狀態：**已實作，EditMode／PlayMode 自動化測試通過；尚未經真人試玩**。自動化測試不能代表步行手感、明暗與美術品質已合格。

## 1. 入口與範圍

- Unity 選單：**`Shepherd/Case01/沉浸式住宅探索 QA`**
  - 開啟獨立場景 `Assets/Exploration/Scenes/Case01ImmersiveHouseQA.unity`，直接進 Play。
  - 場景裡只有一個 `Case01ImmersiveHouseQA` 元件，其餘在 Play 時生成。
- 其他選單：
  - `沉浸式住宅 QA 重建場景`：場景壞掉時用。
  - `沉浸式住宅 QA 實機截圖`：沿實際路線走一趟，輸出 1920×1080 與 1280×720 截圖到 `Temp/Case01ImmersiveHouseCapture/`。
- 範圍：前門 → 玄關 → 客廳 → 樓梯 → 二樓走廊，全部連續可走，是同一棟 Phase 1.9 R3 住宅。
  - 英式連棟住宅：面寬 10 m、一樓天花 2.8 m、樓梯 14 階（每階高 21.4 cm、深 27.9 cm）。
  - 門洞 1.0～1.1 m，門板貼合。
  - 其他房間（餐廳、廚房、書房、臥室）仍是 Phase 1.8／1.9 的品質，本輪沒有加工。
- 本 QA 停用：H 階段切換（F3）、夾層與中庭（M／K）、1.8 對照（F2），只看正常狀態的住宅。

## 2. 操作

| 鍵 | 功能 |
|---|---|
| WASD／滑鼠 | 走、看 |
| Shift | 快步（同段速度 ×1.45，不是跑） |
| E | 開門／拿起合照／放回 |
| **1／2／3** 或 **F6** | 慢走 1.2／正常步行 1.5／較快步行 1.8 m/s |
| **F** | 手電筒開關 |
| **X** | 手電筒強度（弱／中／強） |
| **L** | 環境亮度（暗／標準／亮） |
| **B** | 鏡頭步態開關 |
| **P** | 合照：正常 ↔ 異常候選 |
| **R** | 場景重置（回前門內、手電筒關、合照放回且回到正常版本、門回到初始；速度與亮度保留） |
| **F12** | 除錯資訊：速度、實際速度、FOV、眼高、手電筒、亮度、檢視狀態、位置、FPS |
| F1 | 回前門 |
| F4 | 聲音 |
| F5 | 垂直 FOV 55／60／65／70 |
| F7 | 眼高 1.58／1.65 |
| F9 | 光影新／舊 |
| F10 | 門全開 |
| Esc | 釋放滑鼠 |

**檢視合照時**：滑鼠傾斜、滾輪放大（1～3.5×）、放大後按住左鍵拖曳移動、空白鍵翻面、P 切換版本、E 或右鍵放回。

正常遊玩時畫面只有中央一個小點，沒有 QA 標題或面板。

## 3. 實際設定

- **步行**：三段 1.2／1.5（預設）／1.8 m/s，都是候選值。
  - 加減速 6 m/s²，約 0.25 秒到達步行速度，放開按鍵後也在約 0.25 秒內平順停下。
  - 測試量到的穩定步速誤差在 ±0.06 m/s 以內。
- **鏡頭步態**：
  - 依實際速度推進，約每 0.75 m 一步；上下 8 mm、左右 4 mm、側傾 0.25°。
  - 起步與停下時約 0.25 秒淡入淡出，停下後完全靜止。B 可以關閉。
  - Phase 1.8 的舊步態在本 QA 停用。
- **視角與碰撞**：
  - 垂直 FOV 55°、眼高 1.58 m（候選，可切換）。
  - 鏡頭近裁切面 5 cm；角色膠囊半徑 0.35 m、高 1.8 m。
  - 測試全程檢查鏡頭不在任何碰撞體內。
- **手電筒**：
  - 聚光燈掛在第一人稱鏡頭上，方向等於視線；角度 54°、射程 9 m。
  - 有程式產生的光斑貼圖（中心亮、柔邊、淡淡的反光碗環）。
  - 柔和陰影（只有這一盞投影，偏移已調整避免閃爍）。
  - 強度三段：1.3／2.1／3.0。
  - 照到 1.1 m 內的表面時自動降到 35%，近看紙張和照片不會過曝。
  - 手上有手電筒模型（金屬筒身、橡膠握紋、玻璃鏡片），開燈時鏡片微亮；開關有聲音；檢視物件時自動收起。
- **室內光源**：吊燈大幅調暗，主光改由生活燈具提供。
  - 玄關：門上方透進來的冷光、電話桌小燈。
  - 客廳：壁爐火光、閱讀檯燈。
  - 樓梯：中段東牆一盞壁燈（有陰影）。
  - 二樓走廊：兩盞壁燈。
  - 每盞壁燈還有一個牆面暖色光暈。
  - 環境亮度三段：0.65／1.0／1.35 倍。

## 8. 測試（batchmode，S:\hc 副本）

- `Case01ImmersiveHouseTests`（EditMode，7 項）：
  1. 場景與資產：模型全部載入、不是 Primitive、材質有貼圖、尺寸合理、壁燈在室內那一側；預設無除錯面板、無 QA 標題。
  2. 三段步速、起步加速、穩定步速、平順停下、Shift 快步；FOV 與眼高。
  3. 鏡頭步態幅度 ≤ 1.2 cm、停下後靜止、可以關閉。
  4. 手電筒：方向等於視線、光斑貼圖、柔和陰影、近距離收光、不照到檢視台、三段強度；環境亮度切換。
  5. 合照：拿起、檢視中不能走、佔畫面約 72%、放大 3.5×、拖曳、翻面、背面手寫、異常版本（世界中也跟著換）、放回後恢復行走。
  6. 實際行走（每一步都檢查鏡頭不在牆或家具裡）：前門 → 玄關 → 開客廳門 → 客廳 → 拿起並放回合照 → 樓梯 → 二樓走廊 → 回一樓玄關。
  7. F2／F3 停用、R 重置、F12 除錯、Phase 1.9 QA 不受影響。
- `Case01ImmersiveHousePlayModeTests`（PlayMode，1 項）：真正的 Update 迴圈裡，從前門走進玄關、開手電筒、走進客廳、E 拿起合照（不能走）、E 放回、恢復行走；只有一個玩家與聽者。

## 9. 尚未達到成品品質的地方（請真人驗收時特別看）

1. **合照裡的人物**是風格化人偶（Skin 修改器、簡化五官），姿勢偏僵硬。看得出兩個人與互動，但不是成熟美術水準的角色，需要正式的角色模型或手繪插畫。
2. **牆面、地板、天花**仍是 Phase 1.8 的貼圖與牆段；踢腳線、門框線腳、天花線板沒有全面加工；牆紙和地板的細節與磨損不足。
3. **樓梯本體**仍是方塊踏階（加了長毯與欄杆），沒有正式的踏板凸緣與樓梯側板。
4. **客廳主要家具**沿用 v0.6，沒有重做；電視沒有畫面，書本與文件沒有可檢視內容（本輪只做合照）。
5. **光照**是即時燈，沒有烘焙或間接光，也沒有後製（色調、景深）。暗部可能偏灰或偏黑，要在不同螢幕上檢查。
6. **小物件**（鞋、大衣、信、杯子等）是程序模型，近看細節有限；大衣是布片，沒有布料模擬。
7. **生活陳設的位置**依既有家具的外框自動放置，可能有幾公分的懸空或貼合不準，需要真人近看調整。
8. **音效**是合成佔位級。
9. 沒有實機錄影。
