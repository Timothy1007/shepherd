## 1. 本輪目標與允許修改
**明確授權重新設計**：住宅主體的一／二樓邊界、長寬、牆線、房間比重、門窗位置、玄關與樓梯區、走道、可走距離、家具群組、第一人稱室內移動參數；同時重新布局必要線索位置，使探索不是瞬間完成。

**限制與兼容**：
- 維持《第十七號門》的劇情順序、案件關鍵角色、異域機制、H0→H3、第三扇門、錯接、夾層、中庭、戰鬥／核校正的邏輯與互動 ID；可以重新布局觸發位置、Hotspot 幾何及路線，不能斷流程。
- H0 是「有人居住的正常假象」，H2/H3 是破舊冷清的真相；H3 不回暖。
- 住宅新版本需與街區第十七號外立面自洽。若遊戲尺寸與街區外觀衝突，選擇①同步調整立面相對比例與 16/18 號接壤、②明確利用失序世界觀建立可驗證的內外空間差異；**在 H0 普通居民住宅階段不要不加說明地變成外小內大的魔法豪宅**。
- 不要僅 `transform.localScale *= 1.3` 放大一切，更不要縮小玩家；門高、階梯、把手、櫥櫃、天花、互動距離要由人類尺度錨點控制。
- 保留目前 Phase 1.6 A/B/C QA 作為可重現基線；新正式版 **先在獨立 1.7 QA 完整實作**，在真人認可後才設定為 Demo 預設；這是新的實作流程，不是禁止正式重構。請把新平面做成可日後接正式 Demo 的完整房屋生成方案，避免重做兩次。
- 不要改 Web 卡牌 UI／舊 V2；保留正式遊戲戰鬥卡牌與其他既有 QA。

## 2. 第一優先：把「像站在模型裡」拆成可測根因
在同一組房間與固定視點測：
1. **游標真正相對轉向**：完整追蹤 LegacyCase01Input、HouseQA、DemoSlice、Game View Focus/Cursor.LockState，探索時可無限連續水平 360°，UI / Esc/Alt-Tab 可靠釋放和恢復。不要只調高 sensitivity；若未修，所有體感測試皆不可信。
2. **眼高與鏡頭**：眼高以目前 1.65m 為基準，可比 1.58／1.65／1.72m；垂直 FOV 55/60/65/70，可比不同解析度；留意 FOV 不是人眼水平可見度，別用「人眼只有60度」當依據。記錄相機離牆/家具透視和撞到門洞的感受。
3. **室內自然步速**：基準 3.5m/s、候選 1.8／2.2／2.6m/s；Shift 可提供明顯較快但非瞬間穿屋的速度；**候選只是待驗收值**，勿直接當正式常數。可在 QA 即時切換，UI／劇情／戰鬥轉場不應受影響。檢查角色滑動、加速/減速、腳步回饋（如果有）與行動暫停。
4. **視覺尺度錨點**：先檢查 Unity 世界單位、CharacterController、門洞淨高／淨寬、桌面（約 0.7–0.8m）、廚房台面（約 0.85–0.95m）、門把（約 0.9–1.1m）、樓梯、天花；數字只是可用起點，按實際美術調整。禁止讓玩家被縮小後屋子看似變大。
5. **行走時長與內容密度**：測量從玄關走到餐廳、廚房、二樓書房、第三扇門以及回程的「真人手控秒數／腳本距離」，分開記錄路長、轉彎、互動次數和是否有值得停下觀察的視覺焦點。

## 3. 真正重設計：不是在 10×10 盒子裡搬家具
必須至少產出兩個**空間尺度不同、完整可走動**的候選新格局：
- **R1｜長形連棟住宅（推薦第一個先實作）**：放寬原有 10×10 外框限制，試建例如約 **9–11m 面寬 × 13–16m 縱深** 的遊戲平面（具體長寬由現有街區與窗/樓梯關係校正，不是要求固定尺寸）。考慮更接近前廳—中段餐廳—後段廚房的**縱深分段**，保留合理側廊/樓梯安排；避免像在一個 10×10 正方形切格子。不要讓英國排屋街面荒謬地變得過寬；可對比分窄立面與沿深度延伸、使用立面/內部尺度折衷的版本。
- **R2｜空間節奏強化版**：以 R1 為基礎，加入**錯位門洞、局部狹→寬過渡、小轉角、視線終點、二樓分段走廊和房間進出特徵**；不靠增加全屋面積來製造全部效果。每條額外路線要有生活理由、互動或視覺收穫，不做為了加長時間的空走廊。
- **對照組 O**：目前 Phase 1.6 使用者玩過的版本（可用 B/C 舊 QA）維持可訪問，便於做原版 vs 新版對照。

**房間功能與節奏**：玄關是導入與第一個觀察點；客廳有前後景與合照／日曆等線索；餐廳不是從客廳一眼看完；廚房有工作區、遮擋與冰箱紙條；樓梯經過壓縮/轉身，引導上樓；二樓平台不是站住就看完書房與第三扇門；書房、臥室各自有不同進入節奏，提供有目的的探索與回頭路。所有 H0 時都要像有人生活，H2/H3 敘事性老化使相同房間重新被理解。

**禁止的偷工**：整棟一次 Scale 1.2、全屋門洞統一變寬、光靠狹窄門洞延長路程、把互動物件放得離玩家更遠、全套複製相同房間、用低畫質或暗光掩蓋沒內容、只以 FOV 60/70 差異回覆已解決。

## 4. 要有真正探索的「前 5–8 分鐘」可玩切片
時間長度是**初步設計目標而非硬湊時數**：用真人步行探索、觀察與互動自然形成的流程，不能用慢移動/強制等待假裝內容。
在新 R1/R2 QA 內放入以既有 CASE01 敘事為基礎的最小探索：
- 玄關發現第一個生活異樣或日常細節；有至少兩個可觀察線索但只一個明確主導方向。
- 進客廳觀察環境、合照／日曆等既有關鍵物件；線索不是瞬間一眼全部看到。
- 餐廳／廚房在轉角與生活群組內發現餐具異常、紙條、茶杯等既有功能。
- 上樓發現分段書房、臥室與第三扇門的差異，並有一個可引導玩家回訪的環境暗示（遵守原劇情階段）。
- 所有既有觸發仍照原本流程，不要偷偷新增正式案件線索/更動事件時間點；新增僅作**QA 可互動的環境引導/觀察物**，需可移除。
- 測試時自由移動、可停下觀察、可重訪，不固定鏡頭導覽，不用 F1 瞬移代替正常探索，不卡關；設計 2–3 個可選的非必需觀察點，但不要用大量重複按 E 充數。
