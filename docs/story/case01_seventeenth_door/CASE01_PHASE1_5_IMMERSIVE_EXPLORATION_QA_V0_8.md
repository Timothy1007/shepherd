## 0. 最新真人試玩回饋與本輪定位
使用者實際試玩 Phase 1 v0.7 方案 A 後確認：
- 住宅、事務所、街區貼圖材質初步統一，但**其他房間相對客廳仍過空、沒生活感**；事務所和街區仍非常簡陋，街區像無人空城。
- **整棟住宅感覺很小、站在一處就能看出多數格局，像站在縮小模型中；希望像一個真人真正走進住宅、轉過門框與轉角才陸續發現空間**。合理的英國連棟民宅，不要求豪宅；有必要才局部改尺度。
- 房間與房間都偏亮、亮度相近，缺少視覺引導與探索動機；H0 可以有正常人生活的溫馨**假象**，H1/H2 逐步揭露早已荒廢的真實房屋，H3 校正後**不得回暖**，應偏暗、破舊且冷清。重要線索仍須能看清楚。
- 鏡頭轉向非常難受：滑鼠移到螢幕邊緣仍轉不了足夠角度；**這是優先 P0 的輸入/游標問題**，不是要求玩家熟悉操作。
- 屋內從第三扇失序門邊緣**仍可能透出街道燈光**（Phase 1 背板仍不足），需針對近距／斜角實證與修正。
- **街道路牌文字超出牌面／穿模**；不能僅靠改大小後假裝修好，須從不同距離/解析度/角度驗證。
- 住宅方向尚算容易辨認，但**欠缺吸引玩家主動調查的環境暗示**。
- 主線邏輯／戰鬥／校正已跑通初版，這一輪目標是**可試玩的沉浸式體驗 A/B QA 與兩項確定影響體驗的 Bug 修復**，不是立刻推翻整個住宅、全面重建街區或改戰鬥 UI。

## 1. P0｜滑鼠轉視角／游標鎖定（正式 Demo 與獨立 QA 都要修）
**完成目標：在 Windows Unity 編輯器 Game View Play 與（如有建置）Standalone，正常探索時滑鼠可不間斷地左右轉超過 360°，不會在螢幕邊緣停住；玩家能自然看上下但限制 pitch；WASD 繼續移動。**

先追蹤 `ExploreInput` 與 `ICase01InputSource` 的實際來源及 `Input.GetAxis(Mouse X/Y)`／`Input.mousePosition` 等路徑，檢查是否採用了絕對位置差而非相對滑鼠增量、Game View focus、UI 互動、Escape、Alt-Tab、點擊重新捕捉、場景切換、戰鬥返回、F 鍵 QA 切換、視窗大小／高 DPI 相關狀態。**不要先假設單純提高 LookSensitivity 就能修好。**

要求：
1. 自由探索預設相對滑鼠轉向，鎖定/隱藏游標，直到使用者主動釋放、面板需要游標或視窗失焦；釋放時提示「點擊畫面恢復視角」，點擊 Game View 能重新捕捉（不要吃掉不必要的互動）；在 UI 面板需要點擊時按既有方式可釋放。
2. 避免 HouseQA 與 DemoSlice 搶游標狀態，避免因錯誤 `Cursor.lockState` 造成鼠標碰邊；在失焦/回焦、轉場/戰鬥結束重抓游標時測試。Editor Game View 有特殊 focus 行為，必要時說明一次點擊操作。
3. 滑鼠敏感度提供**獨立 QA 可切換值**（如 0.65×、1×、1.4×，或實際合適的比例），可採暫存選項但不可無意間永久改全遊戲。FOV 不應更改滑鼠的正常工作原理。
4. 加至少 EditMode 的 input/rotation/lock state 回歸測試與可操作 QA 說明；**自動化測試不能完全驗證 Windows 游標碰邊，請明列真人/Standalone 驗收**。不要打破 UI 點擊、戰鬥互動或降低閃爍功能。

## 2. P0｜失序第三扇門仍透出街燈 + 街道路牌文字破框
**門**：在最新 v0.7 方案 A 的二樓平台、FOV 多種值、正面/側面/貼近、H1/H2、降低閃爍狀態進行截圖。檢查 `Portal` 膜、void 背板、RenderQueue/ZWrite/雙面剔除/alpha/邊緣羽化、Layer 29/30 切換、玩家相機 culling mask；分辨是門膜邊緣有洞、背板過小、從斜角看穿、背板和外景深度順序錯誤、還是燈光洩漏。修到**不該看到現實街燈或屋外建築**，但門本身敘事性的 glitch 視覺、可通行、hotspot、碰撞和 H 階段開關都保留。不能用大型有碰撞的黑牆封路；不破壞窗外正常街景。
**路牌**：`Case01DemoAreas.cs` 中 `StreetSign` 及 `Case01Hud.WorldLabel` 的文字尺寸/換行/牌板幾何關係，**先重現文字實際超出牌面**，修成玩家貼近、遠距和斜視角都沒有超框、Z fighting、反面穿透、文字與底板斷層。以實際牌板世界尺寸/Canvas 或 Text bounds 對齊；可分兩行、縮字或擴板，但須符合街區真實尺度與可讀性；門牌 16/17/18、郵遞名冊、TAXI 字樣一起跑「板面文字」回歸檢查（發現明確 Bug 才修，不要無限制改版）。
兩項都要前/後對照截圖 + 渲染/版面/互動測試。

## 3. P1｜建立**獨立、真正可走動**的「沉浸式住宅比較 QA」
**不更動正式 Demo 預設 Original / v0.5 A、不直接覆蓋住宅主線**。請用新 Unity 選單（例如 `Shepherd/Case01/Phase 1.5 沉浸式空間 QA`）啟動單獨的 QA；可以重用現有 House Builder、v0.6/v0.7 美術及 Hotspot，只對 QA 實例應用 A/B 參數和臨時修飾，離開/切換須完全還原，不能污染正式 Demo 或其他 QA。

### 3.1 真正的人體視角（優先：不要先把房子放大）
- QA 中可切換垂直 FOV 55°/60°/65°/70°，使用**同一個眼高、同一個人物站位與同一個朝向**比較，螢幕右上方小字標示目前值；可獨立比較 1.55/1.65/1.70m 眼高的可能性，但保持玩家碰撞/移動尺度穩定。60° 可作測試基準，**不是最終強制值**。
- 同樣檢查走速、停止/轉向時的視覺感、家具表面位置是否貼合成人比例、通道寬度；不可只通過縮小玩家 CharacterController 偷出走道。
- 可以比較少量柔和加減速/鏡頭位移平滑或極低 head-bob，但要有「完全關閉」選項（減少暈眩）；**不要用電影式不穩定搖晃**強迫沉浸。
- 測視角時**不可同時改模型比例和光照**，以免無法判讀是哪個因素造成改善。

### 3.2 空間遮蔽、密度與局部比例
- 提供可按鍵切換的原版 v0.5 A 布局與「沉浸版」**可實際走動**佈置（原版為基線；沉浸版優先不改總外框）。避免站在玄關一眼同時看穿客廳、餐廳及廚房；使用合理門框、牆段、視覺轉折、櫃體/層板/日常家具群組，形成**探索的逐步揭露**，但不把房子變成迷宮。
- 在廚房：工作三角（流理臺、爐、備餐）、牆掛/廚具／台面組合；餐廳：餐具、椅位與櫃旁生活痕跡；書房：工作桌、書籍與調查資料；艾琳臥室：生活、個性、收納。選各房 2–4 個有意義的 **asset clusters**，不堆無用雜物，且讓玩家看到生活故事。
- 10×10m 是目前的**程式固定外框**，但「感覺小」不一定是要加大；先提供 FOV/遮蔽/生活密度組合之後再提供「局部比例 B」的定性比較。若確實需要更大或延展空間，**額外做獨立選項／QA 變體**，包含調整外框/牆段/樓梯/可達性/外牆與街道立面的同步方案及成本評估，**不得在此輪擅自放大正式住宅**。
- 維持英國普通連棟住宅合理尺度、保留樓梯與門洞動線、Hotspot/證據、生活與不可能空間的對比。可以讓**失序空間**展現非現實延展感，但一般住宅優先真實可信，避免變成豪宅。
- 6:3:1 是視覺**主次**啟發式，非硬性面積公式。六維：構成、燈光、色彩、地編、資產形體、資訊密度；每房記錄一個主要焦點、次焦點、陪襯區，不要全畫面平均亮/平均密。
- QA 需能在**同座標、同眼高、同角度、同 FOV、同 H 階段**保存 screenshot 與 A/B 比對，並能自由移動調查。不同選項不可相互覆寫彼此，顯示哪些目前啟用。

### 3.3 光線引導與 H 階段——不是把全屋均勻調暗
- H0 生活化但不過曝、溫暖燈光集中在主要生活區；H1 異樣開始，局部光源掉亮或改色；H2 **失序假象瓦解，真實荒廢感**，多數暖燈失效，保留窗外冷光、局部可讀性與關鍵物件聚焦；H3 物理關係校正但房子仍冷清、髒舊、不回暖。
- 不同房間有不同光線/注意力重心：玄關吸引視線去客廳；客廳重點落在家居生活/合照；餐廳強調餐具異樣；二樓書房鼓勵注意調查資料；第三扇門周圍營造不自然差異。**不能改謎題順序或透過燈光提前暴雷**。
- QA 支援開關「原照明／新引導照明」與 H0/H2/H3 比較，至少同角度截圖。保留曝光與線索可辨識度：不是純黑畫面。避免強制切 URP/HDRP、後期體積光、大量新 shader，維持 Built-in pipeline 現況；主要從既有 Light、Intensity、Range、Shadow、材質 emissive 及現有 `Case01Mood` 介面作**QA 局部變體**，正式遊戲不變。
- 目前只做**環境引導**與測試，不新增永久任務箭頭、滿屏發光框、調查 HUD 重排、全新謎題或玩家自動提示機制（留 Phase 2/3）。

## 4. P1｜街區與事務所現實感：有限量、但務必看得見的改善
玩家回饋街區像空無一人的模型盒，事務所亦簡陋。這輪**不重建全區**，先做獨立 QA 與以下能明顯改善可信度的最小垂直切片：
- 街區選**站在十七號對街向門口觀望的一小段範圍**：完善路牌比例與字樣、街燈與光源關係、建築下層的生活痕跡（門墊、雨水痕、排水管、郵箱、窗簾、垃圾桶/停放單車等可重複模組；控制密度）、路面/人行道與外牆的比例和明暗，遠景要有分層、透視/霧或遮擋，避免封閉空盒感。
- 空街不一定要塞 NPC；可透過亮窗、遠處車聲/動靜、生活道具暗示有人居住。若要人物，**不擅自新增 NPC AI、對話或戰鬥**，可先以靜態/遠景 QA 方案評估。
- 事務所選一個主要視角：工作桌、案件板、閱讀燈，調整物件組合與前後景，讓觀者立即知道這是調查事務所；保留案件板與所有對話。
- 此次視覺升級可先只存在獨立 QA（特別是需重新排列的部分）；街道路牌穿模／游標控制**確定 Bug**可直接修到正式 Demo。不要改已定版的一般 HUD 或戰鬥。
- 與已有 `Case01AreaArt` v0.7 重用：不複製另起一套平行場景、不使用無商用授權素材，建立新舊對照截圖。
