## 3. P1｜模型與場景美術「品質拉齊」，不是電影級精修
**本輪客廳 v0.6 是階段性下限，不是最終品質**。優先提升遠低於其水準的主場景焦點，達到生活邏輯可理解、形體非純方盒、主要材質一致。不要重做客廳或換一套主題，客廳可只修阻塞/遮擋。

| 場景 | 主工作 | 本輪最低驗收（不追求參考圖極致） |
|---|---|---|
| 1F 玄關 | 鞋櫃、掛衣、椅/傘架、正面掛畫，堵住玄關→廚房開口 | 一眼能理解入口與去向、門洞不被擋、家具不是浮箱 |
| 1F 廚房 | 成排檯面、水槽龍頭、爐具冰箱、上櫃；刪孤立單人圓桌 | 合理備餐順序，無不明用途展示桌／不擋路 |
| 1F 餐廳 | 餐桌至少兩座、餐邊櫃、餐具「二→一」事件 | 不像祭壇，不強制放大相框正對餐桌，保留互動 |
| 2F 書房 | 內嵌層板書架、桌上地圖/手記分組、檔案盒 | 書不只是黏在方塊外表，所有線索仍可調查 |
| 2F 艾琳臥室 | 床、床頭櫃、衣櫃、桌面生活/工作物件 | 不只是孤床；物件有明確生活用途，不揭露女兒結局 |
| 2F 走廊／儲藏室 | 修門框比例與動線，上鎖文案劇內化 | 不出現「QA 未開放」等出戲文字 |
| 異常夾層／遭遇 | 缺陷模型/光照/碎片外殼連續性 | 形成前不可黑方塊閃現、形成後進戰鬥不切回黑佔位；若已修復先驗證不再重做 |
| 事務所 | 接案桌、案件板、文件櫃、燈具、出入口 | 一眼像調查工作場所，不能只是幾張方桌 |
| 街區 | 16/17/18 門牌與住宅立面、路燈、路面、建築輪廓、少量道具 | 不像空盒子走廊；有明確地標和可辨認的 17 號位置，不過早洩漏室內 Portal |

- 不需要每個茶杯都有高模；優先 3–5 個各場景最醒目的主家具或建築模組。可重用 v0.6 Blender 腳本/模型／材質系統（**必須避免直接把客廳沙發/壁爐複製到每間房**）；不得使用未獲商業授權的資產。
- 善用 `tools/blender/case01_living_room/` 與 `Case01Palette/Case01ArtSet` 已存在架構；使用 Blender 直接程序建模可行，**沒有 Blender MCP 也能做**。保持內部模型風格統一，正確匯入 FBX / PNG / `.meta`；避免新增一堆高維持成本的自動生成單次模型。
- **基礎光照統一**：相近木材和布料在各場景不出現極端不同的色相/亮度，室內光源與實體燈具位置合理；H0 溫和有人味，H1/H2 漸冷衰退，H3 不回暖；事務所/街區遵循同一世界的陰晴冷暖。但此輪**不做**全域 volumetric fog、AO 烘焙工程、改渲染管線、強制 HDRP/URP、高級 PBR 細節或大幅動畫重作。
- 如果現有模型已明顯達到「客廳 v0.6 基準」，只核對即可，不要為了完成任務重造。進度優先**橫向拉齊，不是垂直追極致**。
