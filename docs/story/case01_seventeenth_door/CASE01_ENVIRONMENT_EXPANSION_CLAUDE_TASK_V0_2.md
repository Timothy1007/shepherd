## 2. 範圍內：房間裝飾與可觀察線索
只在現有空間增加生活痕跡，不改牆、樓板、門、樓梯、portal、角色 spawn、戰鬥區域、camera：
| 區域 | 裝飾擴充（可用低面數組件／可靠現有素材） | 玩家可發現的交互 |
| --- | --- | --- |
| 一樓客廳 | 書架及不同顏色書本、閱讀燈、毛毯、衣架／外套、植物、茶几雜物、生活相框 | 書中便箋、朋友寄來的卡片或相框；至少 1 個可調查生活細節 |
| 一樓餐廳 | 餐具櫃、托盤、餐墊、兩人份茶具、布巾、收據／購物清單、小櫃子 | 既有兩副餐具／合照功能保留；另增 1 個簡短生活線索 |
| 一樓廚房／玄關 | 調味罐、碗盤架、茶葉盒、雨傘、鞋櫃上的鑰匙盤、掛鉤 | 可以簡單開關／檢視一個物件，無需所有道具發光 |
| 二樓臥室 | 床頭小燈、衣物、書、旅行路線紙、工作邀請信、私人明信片 | 至少 2 個短線索，區分艾琳的個人願望和研究，而不將她變成純受害者 |
| 二樓書房 | 檔案盒、文件夾、分色檔案標籤、舊照片、書架、地圖、筆記、小型修復工具 | 原有三項關鍵線索**完全保留**；額外 1–2 項非必要調查內容 |
| 二樓樓梯／儲藏門外 | 壁燈、掛畫、地毯、紙箱等少量可辨參照物 | 樓梯錯接前後可觀察的裝飾差異，但**不改△／○／□ 修復玩法** |

**內容原則**：每房用少量不同尺寸、朝向、材質與不完全整齊的物件，避免全部長方體堆疊或重複一模一樣。增加幾種圓柱、薄片、書冊、框架等形狀，讓第一人稱近看有層次。通道不受阻、物品不能穿牆漂浮、字體可讀、碰撞適當；可用程式生成，避免引入不明授權外部素材。
**調查類別**：生活細節可用簡短文字，但不應每件物件都只開大片文字框；優先將環境中「動作會改變物件」的操作留給真正可操作物件。不鼓勵將每個裝飾做成強調互動提示的 hotspot。

## 3. 範圍內：至少三階段的環境異變
以已存在的 Case01Flow／Session 檢查點做事件驅動，**不要隨機每秒切換**，不可破壞舊門／戰鬥狀態。
- **H0 初入住宅**：保有日常與溫暖的居家細節，讓玩家熟悉物件位置。
- **H1 餐具矛盾發生後**：除了原本二副變一副，也讓客廳／餐廳至少 2–3 個裝飾發生安靜變動（書少一兩本、椅子移位、照片框空白、桌上布巾不見等），玩家回訪可發現；重要原始觀察寫入日誌。
- **H2 二樓發現艾琳研究／路徑錯接後**：二樓書房／樓梯至少 2–3 個可見差異（同一本書重複、文件重新排列、燈／相框位置改變、額外紙箱出現），讓玩家察覺空間與紀錄已互相影響。主線關鍵互動點不能因裝飾消失而遺失。
- **H3 核局部修復後**：燈光／飾物大體穩定，但保留至少 1–2 項與起始房屋不同的殘留（例如原合照的第二人影依舊缺席、空白相框留下）。**讓玩家可以再走過已探索區域、觀察差異**，不要立即鎖死整場遊戲或只用結束畫面擋住操作。
- 音效：**保留現有空間異變擠壓音效／觸發點**；可以給重大的 H2 事件搭配不同層次輕微音效，但不要每件安靜異變都播放同一驚嚇音，否則會失去未知感。
- 每個變化都應**可在實際 Scene 中目視驗證**，不是只改日誌字串。可列一份具體 `old state → new state` 配置清單。
- 狀態切換需重播可重設、讀取 QA checkpoints 時建立相容場景，不能一跳 F2/F3/F4 就擺設錯亂或永久消失。

## 4. 範圍內：核完成後出現可收藏證物
