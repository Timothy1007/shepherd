# CASE01｜室內材質／燈光／失序體形成演出｜Claude Code Art Pass v0.3 實作規格

## 0. 使用者真人試玩回饋
- v0.2 已玩過；**音效關掉後恐怖感顯著下降**，應保留氛圍但提供調整驚嚇音效的空間。
- 目前家具有形體，但物體表面材質／貼圖／燈光／畫面精細度仍很像 primitive 原型，需要可見的視覺升級。
- 木質溫馨室內**不是錯誤方向**：維持「有人生活過的家」的情感，再用 H0–H3 一步步侵蝕正常感。避免整棟直接改成純鬼屋／廢墟。
- 失序體目前是兩個黑色方塊人佔位；希望在異常夾層加入散落書籍、照片、紙張，**由環境物逐步聚集成失序體**，有音效／短音樂演出；**暫時不追玩家**。
- 核修復新機制**另有 `CASE01_CORE_CORRECTION_REDESIGN_V0_3.md`**，此 Art Pass 不得私自改修復規則。

## 1. 現有實作核對與安全界線
必讀 `docs/CURRENT_HANDOFF.md`、`CASE01_ENVIRONMENT_EXPANSION_CLAUDE_TASK_V0_2.md` 與以下 Unity 實作：
- `Case01HouseBuilder.cs`：`Materials()` 透過 `ArenaArt.Mat(Color, ...)` 新建近乎純色材質，`BuildMezzanine()` 的核心與光源；房間主要用 Runtime Primitive。
- `Case01HouseDecor.cs`：`Materials()` 同樣用 `ArenaArt.Mat`；程式生成生活家具、H1/H2/H3 可見物件與 FP-001。
- `Case01HouseQA.cs`：自有方向光、`RefreshWorld()` 更新核、夾層與屋內光色；`Animate()` 有閃動與浮動；`Defense`／`EnteringBattle` 與既有音效觸發點；`OnDestroy` / RenderSettings 還原。
- `Case01Flow.cs`：不得為了視覺變更改寫戰鬥或核條件。
- 先檢查 `unity/Packages/manifest.json`、`unity/ProjectSettings/GraphicsSettings.asset`、`QualitySettings.asset`，判定**實際** Built-in 或 URP。不可憑猜測直接換 URP、加不相容 Post Processing。
- 現有 QA Scene 於 Play 時生成世界；新增材質資產必須在 Runtime 正確引用，不能只改場景 Inspector 卻沒在 QA 顯示。

**本任務限定 Case01**：不動 AnomalyStreetDemo、CombatLab3D、卡牌系統、戰鬥渲染／全域 UI、室內房間牆門樓梯通路與出生點；維持 Scene、F1–F4、H0–H3 與 FP-001 功能。所有第三方貼圖／音效須有明確來源、可商用授權與 attribution；缺授權就用自製或程序生成資產。

## 2. 視覺指導：一個英倫都市舊家，不是恐怖遊樂園
基調：現代英倫城市裡帶舊式維多利亞細節的連棟住宅；非古堡、非純中世紀、非東亞公寓。造型化半寫實／乾淨的遊戲概念美術：**控制細節、保留讀圖性**；不要追求過曝照片擬真。主要材質區分：溫潤但陳舊的木地板／深色木家具、髒白或褪色的石灰漆壁、少量壁紙、黃銅、陶器、玻璃、織物、舊紙。
- H0：日常暖光、可辨認的木紋／布料／紙張，像家而非完美展間。
- H1：生活物件被改寫，不把全屋直接調成冷色；局部影子/反光/光色略微不合理。
- H2：書房和樓梯局部壓迫、錯接走廊與夾層顯著異常；保留玩家能看清記號與線索的照度。
- H3：大部分溫暖照明恢復，**相框空白、餐具缺席與照片淡影仍然存在**；避免「全部復原」錯誤敘事。

## 3. 材質優先級與交付標準
### P0：大面積 + 近景重點，必須完成
1. 地板：明顯但不高頻的木板方向／接縫，避免拉伸；木紋需沿板方向且在房間比例合理。
2. 牆面、踢腳線、門框、樓梯：可分辨漆面、舊木、修補痕，適度 roughness 區分；門框記號 △○□ 仍清晰。
3. 客廳書架／餐桌椅／床／書房桌：材質有木、布、紙的差異，近看不再全部是無紋單色。
4. FP-001：正反面可清楚閱讀，背面「週日。兩個人。」及撕角**保持**，其拾取／旋轉／收藏行為不動。
5. 核與夾層：具有材質分層（暗色本體、裂隙光、局部失真），避免只靠均勻高亮紫色方塊。
最低要求：真正可重用的 Material assets（或明確受控的 runtime cache）與可驗證的 Albedo+Roughness/Smoothness 差異；可自製程序紋理／噪聲貼圖與簡單 normal/detail，別只是把所有顏色調亮。節制貼圖：512–1024 px 常用，重要近景可 2048，按使用距離決定；重複木紋避免肉眼可見平鋪與接縫。
### P1：視情況追加
黃銅反光、金屬邊緣、陶器釉面、紙張粗糙邊緣、磨損標籤，布簾和衣物更好的形狀/法線；不是每本書都要獨特高清封面。優先提升「整體相信這是房子」，而非製作一件極高模道具。

### 實作要求
- 優先建立 Case01 專用 material palette / loader，避免 `HouseBuilder` 與 `HouseDecor` 分別大量複製 `ArenaArt.Mat`。保留既有 public 參照、碰撞體與 interactivity；逐步替換渲染 Renderer，而不是重造連接結構。
- 使用相容當前 render pipeline 的 shader / texture import setting；避免全專案 shader 改動、粉紅材質或把貼圖設到不存在屬性。
- 素材資產放在 `unity/Assets/Exploration/Case01Art/`（可依專案習慣細分 Materials, Textures, Audio, Effects；包含 .meta）；若採程序產生，腳本與重建說明須納入版本管理。
- 針對 H0/H1/H2/H3 的材質／照明狀態，避免上一階段殘留材質覆蓋或修改共用材質導致全部物件同時異常。檢查 shader/material lifetime，不在每幀創造新 Material。
- 保持 1080p 與 720p 可清楚辨識互動物件；失序光效不遮擋線索文本。

## 4. 光照升級（獨立 Case01）
- 先保有局部床頭暖光、桌燈、壁燈與既有方向光；讓光源與實際可見燈具位置吻合，避免無來源的大面積均勻光。
- 加入溫和方向對比：客廳／餐廳溫暖、書房略偏中性、樓梯與夾層偏冷；不要整屋一鍵灑上藍紫霧。
- 陰影／AO／接觸暗部依現行 pipeline 和效能實做；**不要全開每顆燈的即時陰影**。需要可關閉或低品質 fallback。
- H1～H2 允許低頻、局部光色反常和陰影滲透；不可高頻閃光、強烈 Bloom、頻繁全畫面白閃。可設定降低閃爍／降低驚嚇強度，預設不造成刺眼。
- 不強制 URP 遷移、不強制 HDRP；若管線根本缺少功能，用基礎 shader、light、少量自製 mesh/VFX 取得效果。
- 渲染狀態退出 Play、跳 F1 QA 後要恢復；不要讓 Unity Editor 停止 Play 後殘留有音效、post effect 或環境光更動。

## 5. 失序體「由環境凝聚」的獨立形成動畫（本 Art Pass 可做）
本案定位：失序體是異域阻止玩家干預核的具象化反制，**不是艾琳或瑪格麗特的亡魂**。物件被力場吸走形成身體，只是它使用了環境碎片，不代表它由那些人物變成。
視覺位置：原本的夾層／異常中庭遭遇點，**不可擋住核、△/○/□ 或通道**；可在中庭近景演出，將夾層中的照片/書本以幻影/碎片對應投影到遭遇區，避免改動原物件或破壞既有調查。使用者希望夾層看得見散落書籍與照片，也要加到室內佈置。
演出 3–6 秒（可跳過／QA 可快速觸發），分四拍：
1. 地上的舊書、照片、紙張輕震／書頁翻動（環境聲，不突然炸響）。
2. 紙片、相框碎影、灰塵向不見的重心漂移，形成環繞的軌跡。
3. 兩個佔位失序體由碎片「聚合人形→陰影凝實」；暫無正式模型時用分片粒子/網格圍成人形 silhouette，**不能只讓兩個黑方塊從地板升起**。
4. 最後有一次低頻結構扣合聲／短音樂轉折，現身完成後接入既有遭遇與戰鬥鏡頭。
- 優先兩個個體清楚各自成形，避免玩家誤會是一個 Boss；不更改敵人數量、數值、AI、牌組。
- 避免高成本透明粒子堆疊、全螢幕噪點與強制長不可跳過演出。動畫開始/結束需精確配合 `Case01HouseQA` 中的 Defense→Courtyard→Encounter 流程；不可同時觸發兩次、不在 F1 reset 留殘留物。
- **不做第一人稱追逐**，不偷偷提前開戰；進入 CombatArenaView 仍依既有遭遇判定。
- 可增添短 ambient loop，但需確認來源與合法使用。**音量分級**：環境/效果/音樂分別可調或最低限度 Case01 區域音量參數；靜音不阻擋觸發與完成；當 Application 未聚焦、離開 Play/退出場景時停止 Case01 AudioSource／不得從 Editor 外背景偷偷發聲。避免自行聲稱此前聲音來自 Claude，應做可證明的音源管理。

## 6. 任務拆分：兩次可提交的增量，不要一次翻整個關卡
**A — 材質 + 光線（先做）**
- 完成地板、牆、門、木家具、布料、紙張、核的材質辨識度；H0/H1/H2/H3 保有既有異變。
- 有完整材質/貼圖資產與 Unity .meta；截圖比較同角度 H0/H2/H3，檢查 720p 調查可讀性。
- 可以正常跑完整住宅 QA；不因大面積材質更動碰到碰撞、傳送與 FP-001。

**B — 失序體凝聚演出（A 穩定後）**
- 夾層加入少量散落照片／書／紙張，不覆蓋熱區；開始演出才吸附／生成幻影碎片。
- 形成動畫 + 局部音效 + 短音樂 / 可調音量 + QA 可跳過。
- 僅本案／此遭遇有效，後續正式失序體模型有明確替換掛點；不改戰鬥規則與卡牌特效。
