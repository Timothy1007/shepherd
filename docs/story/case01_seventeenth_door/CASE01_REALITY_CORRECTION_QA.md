- 起點在前門內，可以走「玄關 → 走廊 → 餐廳 → 廚房門」進入；按 **P** 直接站到廚房門口（餐廳那一側）。

## 2. 試玩流程（約 5～8 分鐘）

1. 從餐廳推開廚房門走進去。廚房是局部的失序區域：
   - 有低沉的嗡聲，高櫃旁有一盞冷光。
   - 手上出現黃銅校正器，畫面中央出現準星。
   - 正常區域沒有準星、沒有校正鍵。
2. 靠隔牆的高櫃倒在通往後廚的拱口前，櫃門鬆開、罐子散了一地。這是真的碰撞，走不過去。按 E 可以調查。
3. **左鍵（短按）校正**：要瞄準櫃子才有效，沒對準會有嘶聲、鏡片閃紅、櫃子不動。
   - 命中時鏡片往前一推，發出光束和一圈暖色漣漪，櫃子轉回直立、顏色回暖。
   - 拱口的碰撞同步打開，可以走進後廚。
4. 校正時間預設 5 秒（可以在 3～8 秒之間調），最後 1.5 秒櫃子會顫動、發出吱呀預警，然後倒回去。
   - **安全規則**：有玩家站在倒下的路徑上時，櫃子不倒，繼續顫動，等玩家離開。
   - 有椅子在路徑上時，椅子會被推到旁邊。
   - 立起時擺動路徑上有人，櫃子只會晃一下、不會立起，也不會把人頂開。
5. **線索**：
   - 後廚牆上釘著一張舊照片（E）：女孩踩在那張藍坐墊的椅子上，伸手拿高櫃最上層的罐子。
   - 高櫃旁的地板有四個磨亮的椅腳凹痕和拖動的刮痕（E）。
   - 線索可以重看。
   - 被關在後廚時，可以從後廚這一側隔著拱口再校正一次回來，不會軟鎖。
6. **右鍵牽引**那張藍坐墊的椅子（窗邊，4 m 內瞄準）：
   - 椅子浮起、跟著視線繞著你轉，不會從身上穿過；滾輪調整遠近（1.0～2.2 m）。
   - 牆和家具會擋住它，不穿模。
   - 地上的框顯示落點：紅＝放不下、綠＝可以放、金＝對準凹痕。
   - 再按右鍵放下，Q 取消（椅子回到拾起的地方）。
   - 走出廚房，或被擋住超過 1.2 秒，會自動放下或歸位。
7. 椅子放在凹痕上之後再校正一次：高櫃局部穩定，不再倒下，拱口保持暢通。
   - 嗡聲退去、冷光回暖、凹痕亮一下，樓上傳來一次敲擊。
   - 之後可以繼續在後廚走動。
8. **R** 隨時重置謎題：櫃子倒下、椅子回到窗邊、牽引中也可以。

## 6. 真人檢查清單（請在 Play 裡確認）

- [ ] **視角**：FOV 55° 和眼高 1.58 m 在廚房、後廚、拱口的空間感；轉頭平順、不暈；F5／F7 對照。
- [ ] **家具比例**：高櫃 2.1 m、拱口 1.2 m 寬、餐桌與通道的間距，和第一人稱身高相比是否可信。
- [ ] **材質與光影**：廚房的冷光、校正後的回暖，H0 是否太暗或太平。
- [ ] **音效**：校正、落空、立起、預警、倒下、牽引低鳴、放下、拒絕、局部穩定、樓上敲擊，音量和方向感。
- [ ] **門洞與碰撞**：廚房門、拱口；鏡頭不穿牆、不穿門、不穿家具；倒下的櫃子不能跨過。
- [ ] **滑鼠**：鎖定時轉頭不會撞到螢幕邊界；Esc 釋放後點畫面恢復；恢復的那一下不會誤觸校正。
- [ ] **互動手感**：瞄準是否清楚、命中回饋夠不夠（光束、漣漪、手上的鏡片），牽引跟手程度、遠近、落點框是否好懂。
- [ ] **重試**：超時、放錯位置、離開區域、被關在後廚、按 R，都能恢復，沒有軟鎖。
- [ ] **文字量**：不靠滿畫面文字也能理解「櫃子倒了 → 校正 → 照片／凹痕 → 搬椅子 → 穩定」。

## 7. 測試（batchmode，S:\hc 副本，Unity 2022.3.18f1）

- `Case01CorrectionTests`（EditMode，8 項）。每一步都斷言玩家沒有和櫃子或椅子的碰撞重疊。
  1. 正常區域沒有校正、牽引、準星、手上的校正器，失序區域才有；FOV 55°、眼高 1.58 m。
  2. 倒下的櫃子真的擋住拱口；沒瞄準會落空；冷卻；命中後碰撞改變，可以走進後廚。
  3. 超時倒回；站在倒下路徑上時不倒，離開後才倒；立起的路徑上有人時不立起、不推人；校正時間可調。
  4. 牽引：沒瞄準拾取不到；椅子繞著玩家轉；不穿牆；Q 回到原處；離開區域時自動放下，椅子留在廚房；區域外右鍵無效。
  5. 落點檢查：和家具重疊時拒絕放下、保持牽引。
  6. **完整流程（真實行走，真的開門）**：堵塞 → 調查 → 校正 → 進後廚看照片 → 超時 → 從後廚側校正回來 → 看凹痕 → 牽引椅子繞過餐桌 → 放上凹痕 → 校正 → 局部穩定（10 秒後仍穩定）→ 兩向可通行 → 椅子鎖定 → 重置。
  7. 椅子留在倒下路徑上時被推開，之後仍然拿得到（不軟鎖）。
  8. 重置與重試；F3 重建後切片只有一份；F2 切到 1.8 時沒有切片；Phase 1.9 QA 不受影響；所有新音效都不是無聲。
- `Case01CorrectionPlayModeTests`（PlayMode，1 項）：在真正的 Update 迴圈裡跑完整條「堵塞 → 校正通過 → 超時安全回復 → 牽引放置 → 再校正穩定 → 可通行」。
  - 走路、轉頭、E 都走真實的輸入管線。
  - 滑鼠左右鍵在測試裡無法模擬，改直接呼叫同一個處理函式。

## 9. 未解問題

- 櫃子用既有的 Bookcase 模型當「高櫃」，椅子用既有的餐椅模型加一個坐墊。外觀可信，但不是專為這個場景做的模型。
- 校正的視覺是光束、暖色漣漪和材質回暖，沒有更細的局部恢復特效。
- 音效是程式合成的佔位級。
- 倒下和立起是剛體轉動動畫，沒有物理模擬或灰塵粒子。
- 牽引的椅子固定浮在離地 14 cm，不跟視線上下移動。這是刻意簡化，請真人評估是否自然。
- 沒有做過真人試玩，沒有手感調整。校正時間 5 秒、牽引距離、瞄準輔助角度都要試玩後再定。
