## 4. 新客廳：實際內容

**建築**
- 有厚度的牆（共用牆／前牆／內牆分開）。
- 壁爐凸牆加兩側凹室。
- 上下拉窗：窗框、上下兩扇、窗格條、窗角凸耳、窗台板、窗洞側板、黃銅窗扣。
- 四片嵌板門，往室內半開，有門套線、門頭線、黃銅門把與鉸鏈。
- 線腳與天花：
  - 踢腳線（S 形斷面）
  - 掛畫線
  - 天花線板（凹弧）
  - 天花圓花（車削加 16 片葉飾）
- **地板一塊一塊建**：14 cm 板寬、長度不一、錯縫、板縫，每塊取不同的木紋位置。
- 門外一小段走廊：磁磚地與樓梯起步，從門縫看得到。

**壁爐**
- 木製壁爐架（壁柱、托架、三層線腳層板）。
- 鑄鐵爐膛（拱形開口、爐罩、爐柵），炭塊微光並會跳動。
- 兩側原創花形釉面磚、磁磚爐床、黃銅擋板。
- 上方是鍍金斜邊鏡。

**家具與陳設**
- 三人座天鵝絨沙發：捲邊扶手、分開的坐墊與靠墊、車削木腳。
- 翼背粗呢扶手椅。
- 橡木茶几：車削腳、下層擱板。
- 邊桌加陶瓷百褶燈罩檯燈；黃銅落地燈。
- 凹室矮櫃加四層書架，書本一本一本建，高度、厚度、平放疊書各不相同。
- 電視櫃與薄型電視。
- 16 片鑄鐵柱式暖氣片（含閥門）。
- 帶褶窗簾與黃銅窗簾桿。
- 原創紋樣地毯（含流蘇）。
- 兩幅掛在掛畫線上的油畫（有掛繩）。
- 壁爐架上的座鐘、燭台、花瓶、合照相框。
- 毛線籃、抱枕、格紋毯、報紙、馬克杯、眼鏡盒、盆栽。

**材質（PBR）**
- 26 組材質，每組都有 albedo、法線、金屬／光滑度三張貼圖：
  - 地板、壁紙、舊漆、天花、木作漆
  - 深色木、橡木
  - 天鵝絨、粗呢、亞麻、格紋、窗簾布、燈罩布
  - 地毯、釉面磚、爐床磚
  - 書脊圖集、陶瓷、鑄鐵、黃銅、鍍金、暖氣片漆、葉片
  - 兩幅油畫
- 全部用 numpy 原創生成，沒有複製任何品牌或既有紋樣。

**光照（Unity 實際做法）**
- 全部是即時燈，有柔和陰影，可以開關：
  - 檯燈、落地燈、壁爐
  - 窗外街燈：鈉燈般的暖橘斜照，窗格影子落在室內
  - 月光
  - 走廊燈
  - 天花吊燈（預設關）
- 燈具本身不投影，避免燈泡在燈罩裡把牆打成鋸齒大陰影；燈罩用自發光表現亮度。
- 環境光分三個方向：天花偏冷、牆面中性、地面偏暖。
- 房間中央有一個即時反射探針。
- 鏡頭上掛了本 QA 專用的畫面後製：曝光、近似 ACES 的色調映射、暖亮部與冷暗部的分離色調、暗角、顆粒。
- **專案維持 Gamma 色彩空間**：改成 Linear 會影響其他場景，所以沒有改。
- **為什麼沒有用烘焙光照**：我試過 Unity CPU 烘焙（只烘環境光加環境光遮蔽），但 10 個物件有 UV 重疊造成黑斑；燈也必須保持即時才能真的開關。所以預設不烘焙，保留實驗選單 `全屋重製 QA 重建場景（實驗：烘焙環境光）`。

**合照**
- 相紙 2048×1536，可以拿起、放大、翻面（背面鉛筆字「海邊，週日下午」）。
- 內容是母女在海邊的背影，手牽手站在潮線邊。
- **這是暫用影像**：人物仍是 Blender 風格化人偶（遠景、背影、做舊）。看得出是兩個人與互動，但**不是正式的家庭照片美術**，正式版需要委託插畫或授權攝影。檢視標題也寫明「暫用影像，待正式美術」。

## 7. 尚未達標與限制（請真人驗收時特別看）

1. **合照**是暫用影像，風格化人偶在遠景背影；正式版需要插畫或授權攝影。
2. **建模方式限制**：
   - 所有模型都是 Blender Python 程序建模（方塊、倒角、車削、拉伸、布片）。
   - 沒有雕刻、沒有手工 UV 拆分、沒有 bake 出來的法線細節。
   - 沙發、扶手椅的形體與縫線、布料皺褶仍偏簡化，不到手工建模美術師的水準。
3. **貼圖**：程序生成，沒有掃描或手繪；木紋與壁紙在近距離仍可看出規律。
4. **光照**：沒有烘焙間接光（見第 4 節），暗部的層次靠環境光，比 Blender 參考圖平。沒有 SSAO、沒有屏幕空間反射；Built-in 管線加 Gamma 色彩空間的限制。
5. **其他八區尚未製作**，等客廳通過驗收再依同一產線擴建。玄關目前只有門外的一小段可見佈景，不能走進去。
6. 門扇固定半開，不能開關；窗簾不會動。
7. 缺少的工具與素材：
   - 專業建模／雕刻的人力或授權的高品質家具模型
   - 授權照片或插畫
   - 掃描材質庫
   - 後處理套件（Post Processing Stack 或 URP／HDRP）
   - 若要烘焙高品質光照，需要可以處理 UV 重疊的手工 lightmap UV
