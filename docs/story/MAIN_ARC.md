# 《牧羊人：荒野之歌》跨案件主線設計（MAIN ARC）
版本：v0.1｜2026-11-06｜定位：**長篇敘事架構；內容多屬候選，未揭露真相不得寫死**

## 1. 已採用的敘事原則
- **獨立案件 + 跨案件回聲 + 長期謎團**三層並行。每個案件有自己的目標、衝突與階段性結果；部分人物／物件／事件可跨案件重新得到意義。
- 案件的類型、節奏與氛圍**依故事改變**：懸疑、驚悚、感情、都市冒險可以混搭，避免機械套公式。
- 玩家能收集少量**有敘事用途的遺留證物**，在事務所收藏／調查檔案中重看，某些在未來案件提供補充訊息、特殊對話、線索或可選路徑。
- 主線不可因漏撿隱藏證物而永久卡關；必需的劇情情報要可由其他方式補回。
- 伏筆不是隨意放神祕符號：每個伏筆至少記錄**首次呈現、玩家此時能合理理解的意義、可能回收方向、是否已決定答案**；未決答案不應寫成已知真相。
- 異域起源、官方解釋真偽、牧羊人所謂的「恢復常態」是否代表真相：**仍是保留問題**，不為了第一案提前定案。

## 4. 角色長線
- 主角加入事務所的前史**可於正式版前置或回憶揭露**，Demo 不必先做。
- 事務所是持續回訪的家與同伴據點，不應每一章複製一個全新事務所。
- 同伴可以分別對同一證物提出不同觀點；但同伴個性、姓名、關係線未確定之前，請勿先創作為正式背景。

## 5. 收集／揭露的敘事設計
1. **調查線索**：本案中用於推理與解鎖，不一定進行跨案件攜帶。
2. **遺留證物**：少量永久收集，具有穩定 ID、來源、可查看的文本，可能在後續關卡讀取。
3. **主線伏筆**：可以是對白、畫面、檔案缺口，不一定要成為可收集道具。
4. 每次回收先解答玩家原有的一個問題，再提出更有根據的新問題；避免無止境懸念堆疊。
5. 回訪變化需要**已完成案件／發現新事實**等條件，而不是隨機時刻改寫收藏品。

## 6. 未來寫作來源與版權原則
