## 1. 兩層玩法循環（方向共識）

- **委託層**：事務所接委託 → 前往委託地點／異域 → 調查與行動 → 處理委託的核心問題、解除或處置異域 → 返回事務所，整理證物、後續與主角記憶線索 → 下一委託。每案有自己的情感核心與相對完整的收束。
- **現場層**：觀察異常 → 理解該異域的規律 → 使用能力暫時干預 → 利用環境變化達成當前目標；可重複、組合。
- **設計目標**：目標明確、解法不必唯一。例如「抵達二樓」可透過恢復局部樓梯、探索隱藏通道，或在物理規則允許時利用可移動物件。這些是**候選解法**，不是 Case01 已確認的三條正式路線。
- 自主性來自**一致且可預測的能力／環境規則**，不是要求開發者窮舉所有解法；需設定可作用物件、範圍、時長、碰撞、負重、關卡邊界與防軟鎖。先以小型獨立玩法原型驗證，**不直接改現有 Case01 流程**。
- **現學現賣**：安全觀察／初次理解 → 立即使用 → 條件變化 → 與舊能力組合 → 不提示的自主運用。避免把關卡做成「發光物件＝按指定鍵」的固定答案。
- 各委託可有不同場景規模與主題（室內、街區、較開放區域），但應共享核心操作規則；不必每案重做一套小遊戲。

## 2. 失序、真實、穩定與核（重要設定澄清）

- **失序不等於幻覺或無形混亂**：異域可能有可觸碰、可進入、能造成後果的穩定結構，但其存在／運作不符合正常世界的秩序。
- 區分：**真實**（是否存在或曾存在）、**穩定**（狀態能否持續）、**秩序**（是否符合正常世界的規律）；三者不可互換。
- **牧羊人的局部干預是暫時性的**。提燈可觀測被遮蔽／不同的狀態，穩定器等工具可使局部失序短暫穩定或呈現某狀態；不等於永久解除異域。提燈所見也**不可直接宣告為唯一真相**。
- **核仍存在時，異域仍在**；解除核與局部穩定是不同層次。核解除後異域消失，正常秩序回歸。每案的核、解除條件及現實恢復後的樣貌依案件而定，不把 Case01 的結果套用所有委託。
- 世界觀採**B 為目前操作基礎**：失序也有實在性與自身規律；**C 為長期可探索的謎**：人類所認為的正常秩序是否唯一真實，暫不下定論。
- **能力設計候選**：提燈（觀測）、穩定器（局部短暫穩定／既有射擊、復原等功能）、牽引（操控物件）；既有擬態錨定、聚光保留。延遲、連結、轉移等只屬討論候選，**未批准加入能力樹或改寫既有工具機制**。應先釐清穩定、復原、錨定的分工，避免功能重疊。

## 3. Case01〈第十七號門〉新增敘事方向

- **核心主題不變**：東亞移民母女「擰巴的愛」，說不出口的牽掛與真實存在的傷害；理解不等於必須原諒，愛不自動消除傷害。
- **人物真實性方向**：母親與女兒艾琳傾向**確實存在過、共同生活過**，不採「其實根本沒有女兒」作為優先反轉。母女記憶／認知可能出現偏差，但不是所有線索都作假；具體失序成因尚未定案。
- **委託起點**：母親來委託時已察覺記憶混亂，正在逐漸遺忘與女兒有關的過去。她想確認女兒及過往是否真實，並尋找其下落。
- **玩家調查所得**：應能逐步找到足以支持「艾琳確實存在過」的生活痕跡與證據；**不能因此宣稱已知道艾琳現在在哪裡**。
- **艾琳失蹤伏筆**：透過她主動調查地址、檔案矛盾的筆記、話語與少量生活細節**隱約提示異常**；不明說她失蹤的機制、去向或是否與調查有因果關係。短期內不向玩家揭露完整答案；不要讓她的所有生活物件都變成陰謀線索。
- **Case01 結局空間**：解除維持異域的核後，第十七號門及內部空間消失，街上 16 與 18 號之間**回到原本的一堵牆**；不是把房子永久修好留在正常城市。母親仍可保有記憶與物證所帶來的確認／慰藉；其記憶恢復程度及異域內物件如何帶出，待劇本與規則核對。
- **結案選擇**：玩家可選擇如何向母親交付不完整的調查結果——坦誠說明已知與未知、先交付有意義的證物／心理慰藉、或傾聽後再交代。**這是回應方式與資訊呈現的選擇，不預設善意必須說謊**；也可評估隱瞞資訊的選項及後果，但未定案。選項應受已找到的證據約束，不能無證據替艾琳發言。
- **完成不等於所有謎團解開**：異域可解除、委託可結案，艾琳的下落仍未明；玩家的結案表述與後續回聲可有差異，但目前不指定多重正式結局。
- **主角長線**：在一個個以愛、友誼、信任、遺憾等不同人際主題為核心的委託中，逐步觸及／拼湊自己的過去；避免機械式「每案一塊記憶碎片」。後續委託的主題尚未批准為正式章節。
